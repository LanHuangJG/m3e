App Bar 应用栏

m3e-app-bar 组件是一个醒目的界面组件,在应用屏幕顶部提供对关键操作、导航与上下文信息的一致访问。 

import "@m3e/web/app-bar";
 用法

本节提供该模块组件的用法示例与配置指引。

结构解析

m3e-app-bar 组件为顶级导航与上下文信息提供结构化布局。它暴露以下具名插槽:

  • leading —— 通常是一个导航控件,例如返回箭头或菜单按钮。位于应用栏的起始端。
  • title —— 当前视图或上下文的主要标签。通常是简短、醒目的标题。
  • subtitle —— 可选的次级标签,在标题下方提供额外的上下文或层级信息。
  • trailing —— 一个或多个对齐到应用栏末端的操作按钮。常见示例包括搜索、书签或更多(overflow)菜单。

<m3e-app-bar>
  <m3e-icon-button slot="leading" aria-label="Back">
    <m3e-icon name="arrow_back"></m3e-icon>
  </m3e-icon-button>
  <span slot="title">Top 10 hiking trails</span>
  <span slot="subtitle">Discover popular trails</span>
  <m3e-icon-button slot="trailing" aria-label="Bookmark" variant="tonal">
    <m3e-icon name="bookmark" filled></m3e-icon>
  </m3e-icon-button>
</m3e-app-bar>
 尺寸

有三种尺寸变体:small(默认)、medium 与 large。使用 size 特性控制应用栏的尺寸。

 居中

centered 应用栏可确保其主要内容 —— title 与可选的 subtitle —— 始终在可用水平空间内保持视觉居中,无论 leading 或 trailing 插槽中元素的数量或尺寸如何变化。

这是通过布局对称而非等距实现的。标题区域锚定在容器的中心,两侧图标的数量或宽度可以变化,而不会使标题的位置发生偏移。

<m3e-app-bar centered>
  <!-- Content omitted for brevity -->
</m3e-app-bar>
 滚动效果

m3e-app-bar 可以通过 for 特性附着到一个可滚动容器上,该特性引用容器的 id。这在应用栏与其内容区域之间建立了一种滚动契约。当用户滚动时:

  • 应用栏的背景会抬升 —— 通常表现为阴影或表面色调 —— 以表示与内容分离。
  • 当滚动位置回到顶部时,抬升效果会被移除,恢复为扁平的视觉层级。

这种行为增强了上下文的清晰度,提示内容正在滚动,同时保持应用栏作为稳定锚点的作用。

<div id="scrollContainer">
  <m3e-app-bar for="scrollContainer">

 无障碍

默认情况下,应用栏会被赋予 ARIA role="banner",将其标识为用于品牌、导航或上下文身份的站点级地标区域。该角色告诉辅助技术:应用栏是该页面或应用的顶级标题。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/app-bar.js"></script>

此外,你还必须使用一个 import map 来引入更多依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",
      "@lit/reactive-element/": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/",
      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
