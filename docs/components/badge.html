Badge 徽标

m3e-badge 组件是一种紧凑的视觉指示器,用于表示计数、在线状态或强调,可附加到图标、按钮或其他组件上。 

import "@m3e/web/badge";
 用法

本节提供该模块组件的用法示例与配置指引。

尺寸

徽标有三种尺寸变体:small、medium(默认)与 large。使用 size 特性控制徽标的尺寸。

10 10 10 
<m3e-badge size="small">10</m3e-badge>
<m3e-badge size="medium">10</m3e-badge>
<m3e-badge size="large">10</m3e-badge>
 锚定

m3e-badge 可以通过 for 特性锚定到另一个元素上,该特性引用目标元素的 id。这会建立语义与视觉上的关联,使徽标即使在布局变化时也能跟踪其锚点。

使用 position 特性控制摆放位置。这些取值定义了徽标相对于其锚点出现的位置:

  • above-after(默认)—— 位于锚点上方,对齐到其末端边缘(LTR 为右,RTL 为左)
  • above-before —— 位于锚点上方,对齐到其起始边缘(LTR 为左,RTL 为右)
  • below-before —— 位于锚点下方,对齐到其起始边缘
  • below-after —— 位于锚点下方,对齐到其末端边缘
  • before —— 与锚点同行,放在其之前(LTR 为左,RTL 为右)
  • after —— 与锚点同行,放在其之后(LTR 为右,RTL 为左)
  • above —— 居中于锚点上方
  • below —— 居中于锚点下方

这些位置是双向文本感知的,会自动适配从左到右与从右到左的布局。即便在响应式变化中,它们也能保持富有表现力的锚定与清晰的布局。

Button 按钮 AA AB BB BA BE AF A B 
<m3e-button id="btn" variant="filled">Button</m3e-button>
<m3e-badge for="btn" position="above-after">AA</m3e-badge>
<m3e-badge for="btn" position="above-before">AB</m3e-badge>
<m3e-badge for="btn" position="below-before">BB</m3e-badge>
<m3e-badge for="btn" position="below-after">BA</m3e-badge>
<m3e-badge for="btn" position="before">BE</m3e-badge>
<m3e-badge for="btn" position="after">AF</m3e-badge>
<m3e-badge for="btn" position="above">A</m3e-badge>
<m3e-badge for="btn" position="below">B</m3e-badge>
 无障碍

默认情况下,徽标不会被赋予 ARIA 角色,表示除非被显式引用或标注,否则它们在无障碍树中被视为中性的非语义元素。

把徽标附加到交互元素上时,请使用 aria-describedby。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/badge.js"></script>

此外,你还必须使用一个 import map 来引入更多依赖。

生产构建请使用压缩版文件,以获得最佳加载性能。
