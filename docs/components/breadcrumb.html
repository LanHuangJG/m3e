Breadcrumb 面包屑

m3e-breadcrumb 与 m3e-breadcrumb-item 组件协同工作,展示一条层级化的导航路径。 

import "@m3e/web/breadcrumb";
 用法

本节提供该模块组件的用法示例与配置指引。

结构解析

要创建面包屑路径,请把条目放入一个 m3e-breadcrumb 元素中。每个 m3e-breadcrumb-item 代表导航层级中的一级,从最宽泛的层级开始,到最具体的层级结束。最后一个条目会自动被视为当前层级,而靠前的条目则描述通向它的路径。

Dashboard Reports Annual 
<m3e-breadcrumb>
  <m3e-breadcrumb-item>Dashboard</m3e-breadcrumb-item>
  <m3e-breadcrumb-item>Reports</m3e-breadcrumb-item>
  <m3e-breadcrumb-item>Annual</m3e-breadcrumb-item>
</m3e-breadcrumb>
 链接

面包屑条目也可以通过 href 特性指定 URL,表现得像链接。你还可以像原生 a 标签一样指定 target 与 rel。面包屑的最后一项不支持链接,因为当前层级不可交互。

Web API Web Components 
<m3e-breadcrumb>
  <m3e-breadcrumb-item href="https://developer.mozilla.org/en-US/docs/Web" target="_blank">Web</m3e-breadcrumb-item>
  <!-- Additional items omitted for brevity -->
</m3e-breadcrumb>
图标

使用 icon 插槽在条目标签之前渲染一个图标。对于纯图标条目,只需把图标放入默认插槽。使用 item-label 为纯图标条目的内部按钮提供无障碍标签。

使用 m3e-icon 时,当前面包屑条目中的图标会自动填充。

Reports Annual 
<m3e-breadcrumb>
  <m3e-breadcrumb-item item-label="Dashboard">
    <m3e-icon name="dashboard"></m3e-icon>
  </m3e-breadcrumb-item>
  <m3e-breadcrumb-item>
    <m3e-icon slot="icon" name="analytics"></m3e-icon>Reports
  </m3e-breadcrumb-item>
  <m3e-breadcrumb-item>
    <m3e-icon slot="icon" name="calendar_month"></m3e-icon>Annual
  </m3e-breadcrumb-item>
</m3e-breadcrumb>
 自定义分隔符

使用 separator 插槽提供自定义的视觉分隔符。通过插槽传入的元素会被克隆到每个条目的 shadow root 中,替换默认分隔符。

/ Dashboard Reports Annual 
<m3e-breadcrumb>
  <span slot="separator">/</span>
  <m3e-breadcrumb-item>Dashboard</m3e-breadcrumb-item>
  <!-- Additional items omitted for brevity -->
</m3e-breadcrumb>
 换行

面包屑默认不换行。当水平空间有限时,最后一项会以省略号截断。如果你希望面包屑改为换行,请使用 wrap 特性。

Lorem ipsum dolor sit amet Consectetur adipiscing elit sed do Tempor incididunt ut labore et dolore Magna aliqua ut enim ad minim veniam Quis nostrud exercitation ullamco laboris nisi ut aliquip 
<m3e-breadcrumb wrap>
  <!-- Items omitted for brevity -->
</m3e-breadcrumb>
 密度

面包屑能感知密度,并会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整垂直间距。默认密度尺寸为 4dp。面包屑支持最低到 -3 的负密度档位,每一档将视觉高度减少一个密度单位。无论视觉尺寸如何,面包屑条目都保持 48x48dp 的最小触控目标,以确保可靠的无障碍体验。

下面展示如何为面包屑应用密度。

<m3e-breadcrumb class="density-3">
  <!-- Items omitted for brevity -->
</m3e-breadcrumb>
<!-- Additional breadcrumbs omitted for brevity -->

.density-3 {
  --md-sys-density-scale: -3;
}

 无障碍

面包屑被赋予 ARIA role="navigation",表示该组件代表一个导航地标。在内部,面包屑把条目组织在一个列表中,每个条目通过 ARIA role="listitem" 暴露,以便辅助技术将其识别为面包屑路径中的一步。每个面包屑条目把其插槽内容封装在一个带 role="button" 或 role="link" 的元素中,具体角色取决于是否设置了 href 特性。

分隔符带有 aria-hidden="true",以确保它们始终对辅助技术隐藏。

当禁用时,面包屑条目会在内部按钮或链接上应用 aria-disabled="true",向辅助技术传达该条目存在但不可操作。

当设置了 current 时,条目变为不可交互,并且只暴露 role="listitem"。不会渲染内部按钮或链接,也不会应用交互角色。该组件会把 current 的值反映到包含插槽内容的内部包装元素的 aria-current 上。如果没有显式提供 current 值,最后一个面包屑条目会自动获得 aria-current="page",以表示用户当前所在的位置。current 特性接受与 ARIA aria-current 特性相同的取值,包括 page、step、location、 date、time 与 true。

对于纯图标条目,使用 item-label 特性为条目的内部按钮或链接提供无障碍名称。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/breadcrumb.js"></script>

此外,你还必须使用一个 import map 来引入更多依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",
      "@lit/reactive-element/": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/",
      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
