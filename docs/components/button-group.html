Button Group 按钮组

m3e-button-group 组件把多个按钮排布成一个统一、富有表现力的布局。

import "@m3e/web/button-group";
 用法

本节提供该模块组件的用法示例与配置指引。

变体

有两种外观变体:standard(默认)与 connected。使用 variant 特性更改外观。

标准

标准按钮组会在相邻按钮之间添加交互。

 
<m3e-button-group>
  <m3e-icon-button>
    <m3e-icon name="arrow_back"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button>
    <m3e-icon name="arrow_forward"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button width="wide" variant="filled">
    <m3e-icon name="add"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button>
    <m3e-icon name="picture_in_picture"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button>
    <m3e-icon name="more_vert"></m3e-icon>
  </m3e-icon-button>
</m3e-button-group>

标准按钮组可以包含文本按钮。

Start Directions Share 
<m3e-button-group>
  <m3e-button variant="tonal">
    <m3e-icon slot="icon" name="play_arrow"></m3e-icon>Start
  </m3e-button>
  <m3e-button variant="tonal">
    <m3e-icon slot="icon" name="directions_car"></m3e-icon>Directions
  </m3e-button>
  <m3e-button variant="tonal">
    <m3e-icon slot="icon" name="share"></m3e-icon>Share
  </m3e-button>
</m3e-button-group>

标准按钮组可以包含混合的按钮类型,并支持窄与宽两种图标按钮宽度。

Play 
<m3e-button-group>
  <m3e-icon-button variant="filled" width="wide">
    <m3e-icon name="fast_rewind"></m3e-icon>
  </m3e-icon-button>
  <m3e-button variant="filled">
    <m3e-icon slot="icon" name="play_arrow"></m3e-icon>Play
  </m3e-button>
  <m3e-icon-button variant="filled" width="wide">
    <m3e-icon name="fast_forward"></m3e-icon>
  </m3e-icon-button>
</m3e-button-group>
 连通

连通按钮组的行为与标准组类似,区别在于它们不会影响相邻按钮,并会填满可用空间。

Start Directions Share 
<m3e-button-group variant="connected">
  <m3e-button variant="tonal" toggle>Start</m3e-button>
  <m3e-button variant="tonal" toggle>Directions</m3e-button>
  <m3e-button variant="tonal" toggle>Share</m3e-button>
</m3e-button-group>

图标按钮也会伸展以填满可用空间。

 尺寸

有五种尺寸变体用于控制按钮之间的间距: extra-small、small(默认)、medium、large 与 extra-large。使用 size 特性控制间距。要让按钮尺寸统一,请把每个按钮的 size 设为与按钮组相同的尺寸。 

<m3e-button-group size="large">
  <m3e-icon-button size="large">
    <m3e-icon name="arrow_back"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button size="large">
    <m3e-icon name="arrow_forward"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button size="large" width="wide" variant="filled">
    <m3e-icon name="add"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button size="large">
    <m3e-icon name="picture_in_picture"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button size="large">
    <m3e-icon name="more_vert"></m3e-icon>
  </m3e-icon-button>
</m3e-button-group>

无论尺寸如何,连通按钮组的按钮间距始终保持一致。

Start Directions Share 
<m3e-button-group size="large" variant="connected">
  <m3e-button variant="tonal" size="large" toggle>Start</m3e-button>
  <m3e-button variant="tonal" size="large" toggle>Directions</m3e-button>
  <m3e-button variant="tonal" size="large" toggle>Share</m3e-button>
</m3e-button-group>
 选择

包含切换按钮的按钮组同时支持单选与多选模式。使用 multi 特性允许多个切换按钮同时被选中。 

<m3e-button-group multi>
  <m3e-icon-button variant="tonal" toggle>
    <m3e-icon name="format_bold"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button variant="tonal" toggle>
    <m3e-icon name="format_italic"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button variant="tonal" toggle>
    <m3e-icon name="format_underlined"></m3e-icon>
  </m3e-icon-button>
</m3e-button-group>
 密度

按钮组中的按钮与图标按钮都能感知密度,并会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整垂直间距。默认密度尺寸为 4dp。按钮支持最低到 -3 的负密度档位,每一档将视觉高度减少一个密度单位。无论视觉尺寸如何,按钮都保持 48x48dp 的最小触控目标,以确保可靠的无障碍体验。

 无障碍

默认情况下,按钮组被赋予 ARIA 角色 group,表示一组彼此相关的界面元素被归组在一起。对于包含一个或多个切换按钮的单选组,按钮组会被赋予 ARIA 角色 radiogroup,而按钮会被赋予角色 radio。

请始终通过 aria-label 或 aria-labelledby 为每个按钮组提供无障碍标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/button-group.js"></script>

由于 @m3e/button 与 @m3e/icon-button 是依赖项,你还需要为它们引入 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/button.js"></script>
<script type="module" src="/node_modules/@m3e/web/dist/icon-button.js"></script>

此外,你还必须使用一个 import map 来引入更多依赖。 

<script type="importmap">
  {
    "imports": {

生产构建请使用压缩版文件,以获得最佳加载性能。
