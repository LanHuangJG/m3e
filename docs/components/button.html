Button 按钮

m3e-button 组件是一个语义化、富有表现力的界面基础元素,供用户交互以执行某个操作。 

import "@m3e/web/button";
 用法

本节提供该模块组件的用法示例与配置指引。

变体

按钮有五种外观变体: elevated、filled、tonal、outlined 与 text(默认)。使用 variant 特性更改外观。

Elevated Filled Tonal Outlined Text 
<m3e-button variant="elevated">Elevated</m3e-button>
<!-- Additional variants omitted for brevity -->
 形状

按钮有两种形状:rounded(默认)或 square。使用 shape 特性控制按钮的形状。

Square Elevated Square Filled Square Tonal Square Outlined Square Text 
<m3e-button variant="elevated" shape="square">Square Elevated</m3e-button>
<!-- Additional variants omitted for brevity -->
 尺寸

有五种尺寸变体,可用于增加或减弱强调: extra-small、small(默认)、medium、large 与 extra-large。使用 size 特性控制按钮的尺寸。

Extra Small Small Medium Large Extra Large 
<m3e-button variant="tonal" size="extra-small">Extra Small</m3e-button>
<!-- Additional sizes omitted for brevity -->
 图标

使用 icon 插槽在按钮标签之前渲染一个图标。此外,使用 trailing-icon 插槽在按钮标签之后渲染一个图标。虽然不是必须的,但下面的示例使用来自 @m3e/icon 的 m3e-icon 组件,通过 Material Symbols 呈现图标。

Send Open 
<m3e-button variant="tonal">
  <m3e-icon slot="icon" name="send"></m3e-icon>Send
</m3e-button>
<m3e-button variant="tonal">
  Open<m3e-icon slot="trailing-icon" name="open_in_new_window"></m3e-icon>
</m3e-button>
 切换

使用 toggle 特性控制按钮是否可用于二元选择,并使用 selected 特性控制选中状态。点击时会发出可取消的 beforeinput 事件,随后发出 input 与 change 事件。要取消选择变化,请在 beforeinput 期间调用 preventDefault。

Elevated Toggle Filled Toggle Tonal Toggle Outlined Toggle 
<m3e-button variant="elevated" toggle>Elevated Toggle</m3e-button>
<!-- Additional variants omitted for brevity -->

此外,你可以使用 selected 与 selected-icon 插槽,在选中时指定替代的标签与图标。使用 m3e-icon 呈现图标时,按钮被选中后图标会自动填充。

Start Stop 
<m3e-button variant="filled" toggle>
  <m3e-icon slot="icon" name="play_arrow"></m3e-icon>
  <m3e-icon slot="selected-icon" name="stop"></m3e-icon>
  Start
  <span slot="selected">Stop</span>
</m3e-button>
禁用

使用 disabled 特性禁用按钮。默认情况下,被禁用的按钮无法通过键盘聚焦。你可以使用 disabled-interactive 特性支持 禁用控件的可聚焦性 以提升其可发现性。

Disabled Disabled Interactive 
<m3e-button variant="filled" disabled>Disabled</m3e-button>
<m3e-button variant="filled" disabled-interactive>Disabled Interactive</m3e-button>
 类型

使用 type 特性控制按钮的行为。默认情况下,type 为 button。你可以把它改为 submit 或 reset,以便在点击时提交或重置其父级表单。提交表单时,可以用 name 与 value 特性指定提交的值。

链接

按钮也可以通过 href 特性指定 URL,表现得像链接。你还可以像原生 a 标签一样指定 target、rel 与 download。

Google 
<m3e-button variant="tonal" href="https://www.google.com" target="_blank">
  Google<m3e-icon slot="trailing-icon" name="open_in_new_window"></m3e-icon>
</m3e-button>
 密度

按钮能感知密度,并会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整垂直间距。默认密度尺寸为 4dp。按钮支持最低到 -3 的负密度档位,每一档将视觉高度减少一个密度单位。无论视觉尺寸如何,按钮都保持 48x48dp 的最小触控目标,以确保可靠的无障碍体验。

下面展示如何为 extra-small 与 small 尺寸的按钮应用密度。

Density -3 Density -2 Density -1 Density 0
Density -3 Density -2 Density -1 Density 0 
<m3e-button variant="filled" size="extra-small" class="density-3">
  <m3e-icon slot="icon" name="stars"></m3e-icon>
  Density -3
</m3e-button>
<!-- Additional buttons omitted for brevity -->
 
.density-3 {
  --md-sys-density-scale: -3;
}
/* Additional classes omitted for brevity */
 无障碍

默认情况下,按钮被赋予 ARIA 角色 button,表示它们是可点击、会触发操作的元素。

图标插槽带有 aria-hidden="true",以确保图标始终对辅助技术隐藏。

当使用 disabled 或 disabled-interactive 特性禁用时,会使用 aria-disabled="true" 向辅助技术传达按钮已禁用。如果通过 disabled-interactive 禁用,则保留 tabindex,以表明按钮仍然可交互。

当指定了 href 时,会使用 ARIA 角色 link 而非 button,以表明该按钮提供了指向某个资源的交互引用。此外,组件会呈现一个对辅助技术隐藏的内部 a 标签,用于调用原生浏览器特性,例如上下文菜单选项与工具提示。

对于切换按钮,即使处于禁用状态,也会使用 aria-pressed 来表示选中状态。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/button.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",

      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
