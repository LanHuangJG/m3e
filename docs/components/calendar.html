Calendar 日历

m3e-calendar 组件提供一个结构化的界面,可在月、年、多年视图中导航与选择。它支持单日期与范围选择,强制最小/最大/禁用日期等约束,并暴露样式钩子用于高亮特殊日期状态。 

import "@m3e/web/calendar";
 用法

本节提供该模块组件的用法示例与配置指引。

日期字符串处理

不同浏览器对日期字符串的解析并不一致,尤其是那些形似 ISO 日期但不含时间或时区的字符串。为了在各种环境下都有可预期的行为,m3e-calendar 采用一套一致、贴合标准的解析模型,而不依赖浏览器内置的 Date.parse() 规则。

当 m3e-calendar 收到日期字符串时,会自动判断该值是否属于可安全、无歧义解析的 ISO-8601 格式:

  • yyyy-MM-dd —— 本地日期(不含时间与时区)
  • yyyy-MM-ddTHH:mm:ss —— 本地日期与时间
  • yyyy-MM-ddTHH:mm:ssZ —— UTC 日期与时间
  • yyyy-MM-ddTHH:mm:ss±HH:mm —— 带明确时区偏移的日期与时间

符合上述格式的字符串会被转换为本地 Date 对象,不会出现意外的时区偏移,从而避免“仅日期的值被按 UTC 解析后漂移到前一天或后一天”的问题。如果字符串不符合这些 ISO 兼容格式,解析可能不明确或不受支持。为获得最可靠的结果,请使用上面列出的格式。

日期选择

设置 date 特性以定义当前选中的日期。监听 change 事件,以便在用户选择新日期时作出响应。 

<m3e-calendar id="calendar" date="2026-01-01"></m3e-calendar>
<div id="selected-date"></div>
 
const calendar = document.querySelector("#calendar");
const selectedDate = document.querySelector("#selected-date");
selectedDate.textContent = "Selected Date:" + toLocaleDateString(calendar.date);
calendar.addEventListener("change", () => {
  selectedDate.textContent = "Selected Date:" + toLocaleDateString(calendar.date);
});
 起始日期

默认情况下,日历打开时定位到已选日期;未设置则定位到今天。你可以用 start-at 特性指定 m3e-calendar 初始显示的日期。 

<m3e-calendar start-at="2026-01-01"></m3e-calendar>
 初始视图

start-view 特性可设置日历首次打开时显示的视图,可选 month、year 或 multi-year;默认打开 month 视图。 

<m3e-calendar start-view="multi-year"></m3e-calendar>
 日期范围

要选择一段日期范围而非单个日期,使用 range-start 与 range-end 特性。设置 range-start 会让日历进入范围选择模式。当用户选择晚于当前 range-start 的日期时,date 与 range-end 都会更新为该值。如果用户选择早于 当前 range-start 的日期,范围会被重置,date 与 range-start 都会设为新选中的日期。 

<m3e-calendar range-start="2026-01-01" range-end="2026-01-09" start-at="2026-01-01"></m3e-calendar>
 最小与最大日期

使用 min-date 与 max-date 禁用日历上早于/晚于对应值的全部日期,并阻止用户把日历翻到包含最小/最大日期的月或年之外(取决于当前视图)。 

<m3e-calendar start-at="2026-04-01" min-date="2026-01-01" max-date="2026-04-30"></m3e-calendar>
 禁用日期

使用 blackoutDates 属性指定一个函数,用于判断某个日期是否被禁用、无法被用户选择。 

<m3e-calendar id="blackout-dates"></m3e-calendar>
 
document.querySelector("#blackout-dates").blackoutDates = (date) => isWeekend(date);
 特殊日期

使用 specialDates 属性指定一个函数,用于判断某个日期是否以高亮样式展示。你可以用 --m3e-calendar-item-special-container-color、 --m3e-calendar-item-special-color、--m3e-calendar-item-special-ripple-color、 --m3e-calendar-item-special-hover-color 与 --m3e-calendar-item-special-focus-color 这些 CSS 属性来设置特殊日期的样式。 

<m3e-calendar id="special-dates" start-at="2026-04-01"></m3e-calendar>
 
document.querySelector("#special-dates").specialDates = (date) => isHoliday(date);
 国际化

m3e-calendar 使用公历,所有日期格式化均由浏览器基于当前区域设置的 Intl API 处理。

无障碍

日历具备完整的无障碍支持,为辅助技术暴露清晰的语义。头部包含导航控件,每个控件都有可通过特性自定义的无障碍标签。日历网格以 role="grid" 实现,每个日期单元格使用 role="gridcell" 并包含带 role="button" 的可聚焦元素。选中的日期与范围边界用 aria-pressed 标示,今天则用 aria-current="date" 标记。每个单元格包含一个视觉隐藏、跟随区域设置的完整日期字符串供屏幕阅读器朗读,可见文本只显示日数字。星期表头使用缩写标签,但同时包含视觉隐藏的全名(如“星期一”),确保朗读清晰无歧义。

  • previous-month-label —— 跳转到上一月的按钮的无障碍标签。
  • next-month-label —— 跳转到下一月的按钮的无障碍标签。
  • previous-year-label —— 跳转到上一年的按钮的无障碍标签。
  • next-year-label —— 跳转到下一年的按钮的无障碍标签。
  • previous-multi-year-label —— 跳转到上一个 24 年区间的按钮的无障碍标签。
  • next-multi-year-label —— 跳转到下一个 24 年区间的按钮的无障碍标签。
原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/calendar.js"></script>
