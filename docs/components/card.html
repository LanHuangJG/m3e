Card 卡片

m3e-card 组件是一个灵活、富有表现力的容器,用于在一个视觉上独立于背景的表面上呈现统一的主题——文本、媒体与操作。 

import "@m3e/web/card";
 用法

本节提供该模块组件的用法示例与配置指引。

结构解析

m3e-card 组件为结构化内容块提供模块化布局。它暴露以下具名插槽:

  • header —— 渲染卡片的头部区域。通常用于标题、图标或引导性上下文。
  • content —— 渲染带内边距的内容区域。适合正文、表单字段或结构化信息。
  • actions —— 渲染操作区域。用于与卡片意图对齐的按钮、开关或交互控件。
  • footer —— 渲染页脚区域。适合元数据、免责声明或次要操作。
  • (default) —— 渲染卡片默认内容,不带内边距。用于通栏布局或自定义组合。

<m3e-card>
  <m3e-heading slot="header" variant="display" size="small">Card Header</m3e-heading>
  <div slot="content">Card Content</div>
  <div slot="actions">

  </div>
  <div slot="footer">Card Footer</div>
</m3e-card>

你可以通过给插槽元素添加 end 特性,更改 actions 插槽的水平对齐方式。

Card Content
Action 
<m3e-card>
  <m3e-heading slot="header" variant="display" size="small">Card Header</m3e-heading>
  <div slot="content">Card Content</div>
  <div slot="actions" end>
    <m3e-button variant="filled">Action</m3e-button>
  </div>
</m3e-card>

使用默认插槽时,m3e-card 不会添加任何内边距。

 内联

默认情况下,卡片渲染为块级元素。使用 inline 特性让卡片与周围内容同行渲染。

Inline
 
<m3e-card inline>
  <div slot="content">Inline</div>
</m3e-card>
 方向

默认情况下,卡片为纵向排列。使用 orientation 特性把方向改为 horizontal 或 vertical(默认)。

Horizontal
 
<m3e-card class="image-card" inline orientation="horizontal">
  <img slot="header" src="[YOUR IMAGE URL HERE]" />
  <div slot="content">Horizontal</div>
</m3e-card>
 可操作

使用 actionable 特性把卡片配置为可操作表面,让用户把整张卡片作为单一交互目标进行交互。这种模式非常适合导航、选择或触发上下文相关的行为。

Outlined Actionable
Elevated Actionable
 
<m3e-card variant="filled" actionable>
  <div slot="content">Filled</div>
</m3e-card>

 禁用

使用 disabled 特性禁用可操作的卡片。默认情况下,被禁用的卡片无法通过键盘聚焦。你可以使用 disabled-interactive 特性支持 禁用控件的可聚焦性 以提升其可发现性。

Disabled
Disabled Interactive
 
<m3e-card variant="filled" actionable disabled>
  <div slot="content">Disabled</div>
</m3e-card>
<br />
<m3e-card variant="filled" actionable disabled-interactive>
  <div slot="content">Disabled Interactive</div>
</m3e-card>
 链接

可操作的卡片也可以通过 href 特性指定 URL,表现得像链接。你还可以像原生 a 标签一样指定 target、rel 与 download。

Google
 
<m3e-card actionable href="https://www.google.com" target="_blank">
  <div slot="content">Google</div>
</m3e-card>
 无障碍

默认情况下,卡片不会被赋予 ARIA 角色,表示除非被显式引用或标注,否则它们在无障碍树中被视为中性的非语义元素。

可操作的卡片被赋予 ARIA role="button",表示它们是可点击、会触发操作的元素。

当使用 disabled 或 disabled-interactive 特性禁用时,会使用 aria-disabled="true" 向辅助技术传达该可操作卡片已禁用。如果通过 disabled-interactive 禁用,则保留 tabindex,以表明卡片仍然可交互。

当指定了 href 时,会使用 ARIA 角色 link 而非 button,以表明该可操作卡片提供了指向某个资源的交互引用。此外,组件会呈现一个对辅助技术隐藏的内部 a 标签,用于调用原生浏览器特性,例如上下文菜单选项与工具提示。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/card.js"></script>

此外,你还必须使用一个 import map 来引入更多依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",
      "@lit/reactive-element/": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/",
      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
