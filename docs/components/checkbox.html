Checkbox 复选框

m3e-checkbox 组件让用户从一组选项中选中一个或多个。

import "@m3e/web/checkbox";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

复选框可以是独立、预先勾选或不确定状态。点击时会发出可取消的 beforeinput 事件,随后发出 input 与 change 事件。要取消勾选状态变化,请在 beforeinput 期间调用 preventDefault。 

<m3e-checkbox></m3e-checkbox>
<m3e-checkbox checked></m3e-checkbox>
<m3e-checkbox indeterminate></m3e-checkbox>
 标签

使用 label 元素为复选框关联标签。

 
<label><m3e-checkbox></m3e-checkbox> Checkbox 1</label>
<m3e-checkbox id="chk2"></m3e-checkbox>
<label for="chk2">Checkbox 2</label>
 表单关联

该组件以 表单关联自定义元素 (FACE)的身份参与表单提交,把自身状态贡献给表单数据。name 特性定义该组件的值在表单中提交时使用的键。当处于勾选且未禁用状态时,会提交 value(默认为 "on")。

该组件把 disabled 状态视为仅属性(property)控件。在运行时禁用它时,不会向 DOM 中生成 disabled 特性。

禁用

使用 disabled 特性禁用复选框。关联的标签会自动呈现为禁用样式。 

<label><m3e-checkbox disabled></m3e-checkbox>Disabled Checkbox 1</label>
<m3e-checkbox id="chk3" disabled></m3e-checkbox>
<label for="chk3">Disabled Checkbox 2</label>
 必填

使用 required 特性控制复选框是否必须勾选。invalid 事件会在表单提交且该元素未通过约束校验时触发。处于无效状态时,标签会自动呈现相应样式。


Submit 
<form>
  <label>
    <m3e-checkbox name="accepted" required></m3e-checkbox>I accept the Terms and Conditions
  </label>
  <br />
  <m3e-button variant="filled" type="submit">Submit</m3e-button>
</form>
 密度

复选框能感知密度,并会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整垂直间距。默认密度尺寸为 4dp。复选框支持最低到 -3 的负密度档位,每一档将视觉高度减少一个密度单位。无论视觉尺寸如何,复选框都保持 48x48dp 的最小触控目标,以确保可靠的无障碍体验。

下面展示如何为复选框应用密度。与每个复选框交互,观察密度如何影响其状态层。 

<label>
  <m3e-checkbox class="density-3"></m3e-checkbox>
  Density -3
</label>
<!-- Additional checkboxes omitted for brevity -->

.density-3 {
  --md-sys-density-scale: -3;
}
/* Additional classes omitted for brevity */
 无障碍

复选框被赋予 ARIA role="checkbox",使其语义身份与原生复选框控件对齐。这确保屏幕阅读器与辅助技术能正确理解其行为。

该组件通过 aria-checked 管理并反映其状态:

  • aria-checked="true" → 已勾选
  • aria-checked="false" → 未勾选
  • aria-checked="mixed" → 不确定

当通过 disabled 特性禁用时,会使用 aria-disabled="true" 向辅助技术传达该复选框已禁用。在运行时禁用它时,不会向 DOM 中生成 disabled 特性。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/checkbox.js"></script>

此外,你还必须使用一个 import map 来引入更多依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",

      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",

生产构建请使用压缩版文件,以获得最佳加载性能。
