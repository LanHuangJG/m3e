Chips 芯片

@m3e/web/chips 模块提供富有表现力、可访问的芯片组件,用于操作、输入、过滤与建议。 

import "@m3e/web/chips";
 用法

本节提供该模块组件的用法示例与配置指引。

非交互式芯片

使用 m3e-chip 组件呈现一个非交互式芯片。你可以选择把芯片嵌套在 m3e-chip-set 中,它提供芯片之间的默认间距。

Confidential Draft Finance Presentation 
<m3e-chip-set>
  <m3e-chip>Confidential</m3e-chip>
  <m3e-chip>Draft</m3e-chip>
  <m3e-chip>Finance</m3e-chip>
  <m3e-chip>Presentation</m3e-chip>
</m3e-chip-set>
 变体

所有芯片类型都支持两种外观变体:outlined(默认)与 elevated。使用 variant 特性更改芯片的外观。

Outlined Elevated 
<m3e-chip>Outlined</m3e-chip>
<m3e-chip variant="elevated">Elevated</m3e-chip>
 方向

使用 m3e-chip-set 的 vertical 特性可以将芯片垂直堆叠。

Confidential Draft Finance Presentation 
<m3e-chip-set vertical>
  <m3e-chip>Confidential</m3e-chip>
  <m3e-chip>Draft</m3e-chip>
  <m3e-chip>Finance</m3e-chip>
  <m3e-chip>Presentation</m3e-chip>
</m3e-chip-set>
 图标

m3e-chip 为两个图标提供插槽。使用 icon 插槽在芯片标签之前呈现图标,使用 trailing-icon 插槽在其后呈现图标。以下示例虽非必需,但使用了来自 @m3e/icon 的 m3e-icon 组件,通过 Material Symbols 呈现图标。

Finance 
<m3e-chip>
  <m3e-icon slot="icon" name="finance"></m3e-icon>
  Finance
</m3e-chip>
 辅助芯片

使用 m3e-assist-chip 执行可跨多个应用的智能或自动化操作。

Outlined Assist Elevated Assist 
<m3e-assist-chip>Outlined Assist</m3e-assist-chip>
<m3e-assist-chip variant="elevated">Elevated Assist</m3e-assist-chip>
 图标

m3e-assist-chip 提供单个插槽 icon,用于在芯片标签之前呈现图标。此芯片类型不支持尾部图标。

Finance 
<m3e-assist-chip>
  <m3e-icon slot="icon" name="finance"></m3e-icon>
  Finance
</m3e-assist-chip>
 禁用

使用 disabled 属性禁用辅助芯片。默认情况下,禁用的芯片无法通过键盘聚焦。你可以使用 disabled-interactive 特性支持 禁用控件的可聚焦性,以提高其可发现性。

Disabled Disabled Interactive 
<m3e-assist-chip disabled>Disabled</m3e-assist-chip>
<m3e-assist-chip disabled-interactive>Disabled Interactive</m3e-assist-chip>
 类型

使用 type 特性控制辅助芯片的行为。默认情况下,type 为 button。你可以将其改为 submit 或 reset,以便在点击时提交或重置其父表单。提交表单时,你可以使用 name 与 value 特性指定一个值。

链接

辅助芯片也可以通过 href 特性指定 URL 来表现得像链接。你还可以像原生锚点标签一样指定 target、rel 与 download。

<m3e-assist-chip href="https://www.google.com" target="_blank">

 过滤芯片

Outlined Elevated 
<m3e-filter-chip-set>
  <m3e-filter-chip>Outlined</m3e-filter-chip>
  <m3e-filter-chip variant="elevated">Elevated</m3e-filter-chip>
</m3e-filter-chip-set>
 图标

m3e-filter-chip 为两个图标提供插槽。使用 icon 插槽在芯片标签之前呈现图标,使用 trailing-icon 插槽在其后呈现图标。

选中时,过滤芯片的图标会被替换为对勾图标。

  </m3e-filter-chip>

</m3e-filter-chip-set>
 选择

过滤芯片同时支持单选与多选模式。使用 m3e-filter-chip-set 的 multi 特性允许多个芯片同时被选中。

使用 selected 特性控制 m3e-filter-chip 的选中状态。点击时,会先发出一个可取消的 beforeinput 事件,随后是 input 与 change 事件。要取消选择变更,请在 beforeinput 期间调用 preventDefault。

    <m3e-icon slot="icon" name="palette"></m3e-icon>Design
  </m3e-filter-chip>

  </m3e-filter-chip>

</m3e-filter-chip-set>

使用 m3e-filter-chip-set 的 hide-selection-indicator 特性隐藏选择指示器。如果过滤芯片通过 icon 插槽带有图标,选中时该图标会被保留。

 表单关联

过滤芯片可以作为 表单关联自定义元素 (FACE)参与表单提交,将其状态贡献到表单数据中。name 特性定义了组件值在表单中提交时所用的键。芯片集的值由选中的芯片决定。你可以使用 m3e-filter-chip 的 value 控制芯片的值。否则,值派生自芯片的标签(默认插槽)。当有多个芯片被选中时,表单数据会包含多个以同一 name 为键的条目。

该组件将(芯片集自身的)disabled 状态视为仅属性控制。在运行时禁用时,它不会向 DOM 中生成 disabled 特性。

输入芯片

m3e-input-chip-set 组件让用户能够以输入芯片的形式输入、显示和管理一组离散值。它面向富有表现力、可访问的表单而设计,支持键盘导航、校验,以及与 m3e-form-field 的无缝集成。更多信息请参见 Form Field 表单容器。

使用 m3e-input-chip-set 的 input 插槽指定与该组件关联的输入元素。当在输入框上触发 change 时,芯片集会向集合中添加一个新的可移除 m3e-input-chip。用户可以按 BACKSPACE 移除芯片,或点击单个芯片上的移除按钮。如果某个芯片已聚焦,用户可以按 DELETE 移除该芯片。

当向集合中添加或移除芯片时,m3e-input-chip-set 组件会引发 change 事件。使用事件的 detail.type 判断变更类型是 "add" 还是 "remove"。事件的 detail 还包含 value 与 chip 属性。 

<m3e-form-field>
  <label slot="label" for="keywords">Keywords</label>
  <m3e-input-chip-set aria-label="Enter keywords">
    <input id="keywords" slot="input" placeholder="New keyword..." />
  </m3e-input-chip-set>
</m3e-form-field>
 预填充芯片

你可以使用 m3e-input-chip 组件为 m3e-input-chip-set 预填充芯片。使用 removable 特性控制是否呈现一个允许用户移除输入芯片的按钮。这也控制是否可以使用 BACKSPACE 通过键盘删除芯片。

Design Accessibility Motion 
<m3e-form-field>
  <label slot="label" for="keywords">Keywords</label>
  <m3e-input-chip-set aria-label="Enter keywords">
    <m3e-input-chip removable>Design</m3e-input-chip>
    <m3e-input-chip removable>Accessibility</m3e-input-chip>
    <m3e-input-chip removable>Motion</m3e-input-chip>
    <input id="keywords" slot="input" placeholder="New keyword..." />
  </m3e-input-chip-set>
</m3e-form-field>
 最大芯片数

使用 max-chips 特性控制输入框未聚焦时显示多少个芯片。当芯片数量超过该值时,组件会折叠芯片集并显示一个汇总指示器(例如 +2),而不是渲染全部芯片。

当输入框聚焦时,无论 max-chips 设置如何,都会显示所有芯片。

Design Accessibility Motion 
<m3e-form-field>
  <label slot="label" for="keywords">Keywords</label>
  <m3e-input-chip-set aria-label="Enter keywords" max-chips="1">
    <m3e-input-chip removable>Design</m3e-input-chip>
    <m3e-input-chip removable>Accessibility</m3e-input-chip>
    <m3e-input-chip removable>Motion</m3e-input-chip>
    <input id="keywords" slot="input" placeholder="New keyword..." />
  </m3e-input-chip-set>
</m3e-form-field>
 禁用

使用 m3e-input-chip-set 的 disabled 特性整体禁用芯片集,包括其对应的 input 与任何预填充的芯片。此外,禁用时无法移除芯片。

  <label slot="label" for="keywords">Keywords</label>
  <m3e-input-chip-set aria-label="Enter keywords" disabled>
    <m3e-input-chip removable>Design</m3e-input-chip>
    <m3e-input-chip removable>Accessibility</m3e-input-chip>
    <m3e-input-chip removable>Motion</m3e-input-chip>

建议芯片

 密度

芯片可感知密度,并根据 --md-sys-density-scale 与 --md-sys-density-size CSS 自定义属性调整其垂直间距。默认密度尺寸为 4dp。芯片支持低至 -3 的负密度缩放,每降低一步,视觉高度减少一个密度单位。无论视觉尺寸如何,芯片都保持 48x48dp 的最小触摸目标,以确保可靠的可访问性。

以下示例演示如何对辅助芯片应用密度。

Density -3 Density -2 Density -1 Density 0 
<m3e-assist-chip class="density-3">
  <m3e-icon slot="icon" name="stars"></m3e-icon>
  Density -3
</m3e-assist-chip>

.density-3 {
  --md-sys-density-scale: -3;
}

 无障碍

默认情况下,m3e-chip 与 m3e-chip-set 未被赋予 ARIA 角色,表示除非被显式引用或标注,它们在无障碍树中被视为中性、无语义的元素。

无论变体如何(例如过滤、输入、建议),芯片集在以垂直布局渲染时都会被标注 aria-orientation="vertical"。该特性向辅助技术传达方向流,确保屏幕阅读器用户获得清晰的空间感与可预测的导航。

默认情况下,操作芯片与建议芯片被赋予 ARIA 角色 button,表示它们是可以触发操作的可点击元素。当指定 href 时,会使用 ARIA 角色 link 而非 button,以表明该芯片提供了指向某个资源的交互式引用。此外,芯片会呈现一个对辅助技术隐藏的内部锚点,用于调用原生浏览器功能,如上下文菜单选项与工具提示。

使用 disabled 或 disabled-interactive 特性禁用时,会使用 aria-disabled="true" 向辅助技术传达该芯片已禁用。如果使用 disabled-interactive 禁用,则保留 tabindex,以传达该芯片仍可交互。

对于单选芯片集,过滤芯片集被赋予 ARIA role="radiogroup",芯片被赋予 role="radio"。对于多选,芯片集被赋予 role="group",芯片被赋予 role="button"。选中时,芯片的选中状态会通过 aria-checked(单选芯片集)与 aria-pressed(多选芯片集)反映。

输入芯片集被赋予 ARIA role="grid",芯片被赋予 role="row"。此外,输入芯片的内部内容(图标与标签)被赋予 ARIA role="gridcell",移除按钮的容器也被赋予 role="gridcell"。这种模式使辅助技术能够把输入芯片解释为结构化、可交互的行——提升通过屏幕阅读器或键盘导航的用户的清晰度、可预测性与可发现性。
