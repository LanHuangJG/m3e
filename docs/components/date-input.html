Date Input 日期输入

m3e-date-input 组件提供一个分段式输入框,用于编辑日期和/或时间值。它支持仅日期、仅时间以及日期/时间合并输入,并与 m3e-form-field、m3e-datepicker 及 m3e-timepicker 集成。每个分段都可独立编辑,以实现精确、可访问、对表单友好的交互。详情请参见 Form Field 表单容器、Datepicker 日期选择器 与 Timepicker 时间选择器。 

import "@m3e/web/date-input";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

m3e-date-input 设计为在 m3e-form-field 内部使用。下面的示例展示了这种用法。详情请参见 Form Field 表单容器。

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Field</label>
  <m3e-date-input id="field"></m3e-date-input>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
 值绑定

使用 value 特性设置或读取日期。beforeinput 与 input 仅在所有分段都已完整填充时才触发。当焦点离开控件时触发 change。

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Field</label>
  <m3e-date-input id="field" value="2026-01-01"></m3e-date-input>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
 日期字符串处理

不同浏览器对日期字符串的解析并不一致,尤其是那些形似 ISO 日期但不含时间或时区的字符串。为了在各种环境下都有可预期的行为,m3e-date-input 采用一套一致、贴合标准的解析模型,而不依赖浏览器内置的 Date.parse() 规则。

当 m3e-date-input 收到日期字符串时,会自动判断该值是否属于可安全、无歧义解析的 ISO-8601 格式之一:

  • yyyy-MM-dd —— 本地日期(不含时间与时区)
  • yyyy-MM-ddTHH:mm:ss —— 本地日期与时间
  • yyyy-MM-ddTHH:mm:ssZ —— UTC 日期与时间
  • yyyy-MM-ddTHH:mm:ss±HH:mm —— 带明确时区偏移的日期与时间

符合这些格式的字符串会被转换为本地 Date 对象,不会出现意外的时区偏移。这避免了诸如“仅日期的值被按 UTC 解析后漂移到前一天或后一天”之类的问题。如果字符串不符合这些 ISO 兼容格式之一,解析可能不明确或不受支持。为获得最可靠的结果,请使用上面列出的格式之一。

表单关联

该组件作为 表单关联自定义元素 (FACE)参与表单提交,将其状态贡献到表单数据中。name 特性定义了组件值在表单中提交时所用的键。未禁用时,value 会以 ISO 格式的字符串值提交。

该组件将 disabled 状态视为仅属性控制。在运行时禁用时,它不会向 DOM 中生成 disabled 特性。

编辑模式

使用 type 特性控制 m3e-date-input 编辑的是 date(默认)、time 还是 datetime 值。

仅编辑 time 时,值中现有的日期部分会被保留。仅编辑 date 时,现有的时间部分会被保留。

在 date 模式下创建新的 Date 时,时间默认为午夜。在 time 模式下创建新的 Date 时,日期默认为当天。

以下示例演示如何编辑时间与日期/时间值。

HH:MM MM/DD/YYYY HH:MM 
<m3e-form-field variant="outlined">
  <label slot="label" for="field1">Time Field</label>
  <m3e-date-input id="field1" type="time" value="2026-01-01T23:30:00Z"></m3e-date-input>
  <span slot="hint">HH:MM</span>
</m3e-form-field>

<m3e-form-field variant="outlined">
  <label slot="label" for="field2">Date-time Field</label>
  <m3e-date-input id="field2" type="datetime" value="2026-01-01T23:30:00Z"></m3e-date-input>
  <span slot="hint">MM/DD/YYYY HH:MM</span>
</m3e-form-field>
 日期与时间选择器

m3e-datepicker 与 m3e-timepicker 通过 for 特性与 m3e-date-input 集成,该特性通过引用输入框的 ID 把选择器绑定到输入框。详情请参见 Datepicker 日期选择器 与 Timepicker 时间选择器。

当选择器绑定到 m3e-date-input 时,输入框自身的配置优先。诸如 min-date、max-date、blackoutDates、min-time、max-time、blackoutTimes、time-format 与 show-seconds 等属性会覆盖选择器上的对应设置。这确保输入框与选择器保持一致并强制执行相同的约束。

使用 type="datetime" 时,单个 m3e-date-input 可以同时链接到 m3e-datepicker 与 m3e-timepicker,以独立选择日期与时间。

MM/DD/YYYY HH:MM MM/DD/YYYY HH:MM 
<m3e-form-field variant="outlined">
  <label slot="label" for="field1">Date Picker</label>
  <m3e-date-input id="field1"></m3e-date-input>
  <m3e-icon-button aria-label="Open calendar" slot="suffix">
    <m3e-icon name="calendar_today"></m3e-icon>
    <m3e-datepicker-toggle for="datepicker1"></m3e-datepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
<m3e-datepicker id="datepicker1" for="field1"></m3e-datepicker>

<m3e-form-field variant="outlined">
  <label slot="label" for="field2">Time Picker</label>
  <m3e-date-input id="field2" type="time"></m3e-date-input>
  <m3e-icon-button aria-label="Open time picker" slot="suffix">
    <m3e-icon name="schedule"></m3e-icon>
    <m3e-timepicker-toggle for="timepicker1"></m3e-timepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">HH:MM</span>
</m3e-form-field>
<m3e-timepicker id="timepicker1" for="field2"></m3e-timepicker>

<m3e-form-field variant="outlined">
  <label slot="label" for="field3">Datetime Picker</label>
  <m3e-date-input id="field3" type="datetime"></m3e-date-input>
  <m3e-icon-button aria-label="Open calendar" slot="suffix">
    <m3e-icon name="calendar_today"></m3e-icon>
    <m3e-datepicker-toggle for="datepicker2"></m3e-datepicker-toggle>
  </m3e-icon-button>
  <m3e-icon-button aria-label="Open time picker" slot="suffix">
    <m3e-icon name="schedule"></m3e-icon>
    <m3e-timepicker-toggle for="timepicker2"></m3e-timepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">MM/DD/YYYY HH:MM</span>
</m3e-form-field>
<m3e-datepicker id="datepicker2" for="field3"></m3e-datepicker>
<m3e-timepicker id="timepicker2" for="field3"></m3e-timepicker>
 小时格式

time-format 特性控制输入框使用的小时制。它接受 "12"(默认)、"24" 或 "auto"。

  • "12" —— 强制使用带 AM/PM 指示符的 12 小时制。
  • "24" —— 强制使用不带 AM/PM 指示符的 24 小时制。
  • "auto" —— 根据用户区域设置选择 12 小时或 24 小时制。
HH:MM MM/DD/YYYY HH:MM 
<m3e-form-field variant="outlined">
  <label slot="label" for="field1">Time Field</label>
  <m3e-date-input id="field1" type="time" time-format="24" value="2026-01-01T23:30:00Z">
  </m3e-date-input>
  <span slot="hint">HH:MM</span>
</m3e-form-field>

<m3e-form-field variant="outlined">
  <label slot="label" for="field2">Date-time Field</label>
  <m3e-date-input id="field2" type="datetime" time-format="24" value="2026-01-01T23:30:00Z">
  </m3e-date-input>
  <span slot="hint">MM/DD/YYYY HH:MM</span>
</m3e-form-field>
 秒

使用 show-seconds 特性在编辑时间时显示秒分段。

HH:MM:SS MM/DD/YYYY HH:MM:SS 
<m3e-form-field variant="outlined">
  <label slot="label" for="field1">Time Field</label>
  <m3e-date-input id="field1" type="time" show-seconds value="2026-01-01T23:30:00Z">
  </m3e-date-input>
  <span slot="hint">HH:MM:SS</span>
</m3e-form-field>

<m3e-form-field variant="outlined">
  <label slot="label" for="field2">Date-time Field</label>
  <m3e-date-input id="field2" type="datetime" show-seconds value="2026-01-01T23:30:00Z">
  </m3e-date-input>
  <span slot="hint">MM/DD/YYYY HH:MM:SS</span>
</m3e-form-field>
 禁用

使用 disabled 属性禁用输入框。当与选择器关联时,输入框禁用后选择器的开关按钮会自动禁用,以确保用户无法为一个不可编辑的值打开选择器。

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Field</label>
  <m3e-date-input id="field" value="2026-01-01" disabled></m3e-date-input>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
 只读

使用 readonly 特性阻止编辑,同时仍允许聚焦与分段导航。

与禁用类似,当与选择器关联时,输入框只读后选择器的开关按钮会自动禁用。

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Field</label>
  <m3e-date-input id="field" value="2026-01-01" readonly></m3e-date-input>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
 必填

应用 required 特性把输入框标记为必填字段。

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Field</label>
  <m3e-date-input id="field" required></m3e-date-input>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
 最小与最大日期

使用 min-date 与 max-date 特性把早于或晚于对应值的日期标记为无效。

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Field</label>
  <m3e-date-input id="field" value="2026-01-01" min-date="2026-01-01" max-date="2026-04-30">
  </m3e-date-input>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
 禁用日期

除 min-date 与 max-date 约束外,你还可以使用 blackoutDates 属性指定一个函数,用于判断某个日期是否无效。

MM/DD/YYYY 
document.querySelector("#blackout-dates").blackoutDates = (date) => isWeekend(date);
 最小与最大时间

使用 min-time 与 max-time 特性把早于或晚于对应值的时间标记为无效。

HH:MM 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Time Field</label>
  <m3e-date-input
    id="field"
    type="time"
    value="2026-01-01T13:15:00Z"
    min-time="8:15 AM"
    max-time="5:30 PM"
  ></m3e-date-input>
  <span slot="hint">HH:MM</span>
</m3e-form-field>
 禁用时段

除 min-time 与 max-time 约束外,blackoutTimes 属性让你提供一个函数,用于判断给定时间是否无效。该函数接收一个 TimeParts 对象,包含正在求值的时间的 hour、minute 与 second 值。

HH:MM 
document.querySelector("#blackout-times").blackoutTimes = (t) => t.hour < 8 || t.hour > 18;
 校验消息

使用 validationMessages 属性覆盖特定的校验消息。未指定的消息继续使用组件的默认值。

该组件使用一组校验标志来指示具体哪条规则未通过。每个标志对应一种特定的校验条件,当当前值无效时,组件会设置其中一个或多个标志。这些标志同时驱动内置校验消息以及你通过 validationMessages 提供的任何自定义消息。只有求值为 true 的标志才被视为激活。

支持的标志包括:

  • valueMissing —— 需要值时未提供值。
  • typeMismatch —— 输入框的分段只被部分填充。
  • rangeUnderflow —— 值早于 min-date 和/或 min-time。
  • rangeOverflow —— 值晚于 max-date 和/或 max-time。
  • customError —— 值落在禁用(blackout)范围内。

这些标志会被组合起来,以确定最终的校验状态以及向用户显示的消息。

国际化

日期与时间格式由用户的区域设置自动决定,无法自定义。

分段顺序遵循 Intl.DateTimeFormat().formatToParts(),确保所有区域设置都有正确的阅读顺序。分段标签(mm、dd、yyyy)由组件提供,并在各区域设置间保持一致。

无障碍

m3e-date-input 组件把每个日期与时间分段作为独立的 spinbutton 暴露给辅助技术。屏幕阅读器会朗读分段标签(月、日、年、时、分、秒)、当前值以及允许范围,确保用户在编辑值的每一部分时都能获得清晰的反馈。

键盘交互遵循原生分段输入模式。方向键对聚焦的分段进行递增或递减,数字键替换分段值,左右方向键在分段之间移动。焦点保持在组件内部。清除分段不会移动焦点,继续按删除/退格键会导航到上一个分段。

校验状态映射到标准 HTML 约束校验。必填字段为空时会报告 valueMissing,部分输入的值会报告 typeMismatch。范围约束对超出已配置 min-date、max-date、min-time 与 max-time 的值使用 rangeUnderflow 与 rangeOverflow。屏蔽日期与时间会报告为 customError。所有有效性状态都与 m3e-form-field 的错误消息集成。

该组件通过 aria-labelledby 或使用 for 的 label 元素链接到外部标签来支持无障碍命名,确保字段被辅助技术正确朗读。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/date-input.js"></script>
