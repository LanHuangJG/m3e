Datepicker 日期选择器

m3e-datepicker 组件提供一个临时性的结构化界面,可在月、年、多年视图中选择日期。它支持单日期与范围选择,强制最小/最大/禁用日期等约束,并暴露样式钩子用于高亮特殊日期状态。

import "@m3e/web/datepicker";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

使用 m3e-datepicker-toggle 打开 m3e-datepicker。该组件应嵌套在一个可点击元素内部,并把 for 特性设为要打开的选择器的 id 来建立关联。

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Field</label>
  <input autocomplete="off" id="field" />
  <m3e-icon-button slot="suffix">
    <m3e-icon name="calendar_today"></m3e-icon>
    <m3e-datepicker-toggle for="datepicker"></m3e-datepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
<m3e-datepicker id="datepicker"></m3e-datepicker>
 Date input

m3e-date-input 提供一个分段式日期输入框,可与 m3e-datepicker 直接集成。当你想要内建的解析、格式化与精确的分段编辑时,可以用它替代标准 input。

本页示例使用标准 input 来演示完整的 m3e-datepicker API。使用 m3e-date-input 时,其中许多属性并非必需,因为输入框会自行管理取值,选择器只需把选中的日期写回字段。

See Date Input 日期输入 for details.

MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Picker</label>
  <m3e-date-input id="field"></m3e-date-input>
  <m3e-icon-button aria-label="Open calendar" slot="suffix">
    <m3e-icon name="calendar_today"></m3e-icon>
    <m3e-datepicker-toggle for="datepicker"></m3e-datepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">MM/DD/YYYY</span>
</m3e-form-field>
<m3e-datepicker id="datepicker" for="field"></m3e-datepicker>
 变体

m3e-datepicker 支持三种外观变体:docked(默认)、modal 与 auto。使用 variant 属性控制选择器的呈现方式。设为 auto 时,会根据当前屏幕尺寸自动选择合适的呈现方式。

使用 modal 变体时,label 特性的值会作为模态对话框的标题文本。

本页所有示例均使用 variant="auto"。

<m3e-datepicker variant="auto"></m3e-datepicker>
 日期选择

使用 date 属性设置当前选中的日期,并监听 change 事件以响应用户的新选择。你也可以启用 clearable 属性,显示一个清除当前选择的按钮。

MM/DD/YYYY 
<!-- Form field omitted for brevity -->
<m3e-datepicker id="datepicker" date="2026-01-01" clearable></m3e-datepicker>
 
const picker = document.querySelector("#datepicker");
const field = document.querySelector("#field");
field.value = toLocaleDateString(picker.date);
picker.addEventListener("change", () => {
  field.value = toLocaleDateString(picker.date);
});
 日期字符串处理

不同浏览器对日期字符串的解析并不一致,尤其是那些形似 ISO 日期但不含时间或时区的字符串。为了在各种环境下都有可预期的行为, 采用一套一致、贴合标准的解析模型,而不依赖浏览器内置的规则。

当 m3e-datepicker 收到日期字符串时,会自动判断该值是否属于可安全、无歧义解析的 ISO-8601 格式:

  • —— 本地日期(不含时间与时区)
  • —— 本地日期与时间
  • —— UTC 日期与时间
  • —— 带明确时区偏移的日期与时间

符合上述格式的字符串会被转换为本地 Date 对象,不会出现意外的时区偏移,从而避免“仅日期的值被按 UTC 解析后漂移到前一天或后一天”的问题。如果字符串不符合这些 ISO 兼容格式,解析可能不明确或不受支持。为获得最可靠的结果,请使用上面列出的格式。

起始日期

默认情况下,日期选择器打开时定位到已选日期;未设置则定位到今天。你可以用 start-at 特性指定 m3e-datepicker 初始显示的日期。

MM/DD/YYYY 
<!-- Form field omitted for brevity -->
<m3e-datepicker id="datepicker" start-at="2026-01-01"></m3e-datepicker>
 初始视图

start-view 特性可设置日历首次打开时显示的视图,可选 month、year 或 multi-year;默认打开 month 视图。

MM/DD/YYYY 
<!-- Form field omitted for brevity -->
<m3e-datepicker id="datepicker" start-view="multi-year"></m3e-datepicker>
 日期范围

要选择日期范围而非单个日期,使用 range,或 range-start 与 range-end 特性。设置 range 或 range-start 会让日历进入范围选择模式。

MM/DD/YYYY - MM/DD/YYYY 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Date Range Field</label>
  <input autocomplete="off" id="field" />
  <m3e-icon-button slot="suffix">
    <m3e-icon name="calendar_today"></m3e-icon>
    <m3e-datepicker-toggle for="range-picker"></m3e-datepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">MM/DD/YYYY - MM/DD/YYYY</span>
</m3e-form-field>

<m3e-datepicker
  id="range-picker"
  range-start="2026-01-01"
  range-end="2026-01-09"
  start-at="2026-01-01"
></m3e-datepicker>

const picker = document.querySelector("#range-picker");
const field = document.querySelector("#field");
field.value = toLocaleDateString(picker.rangeStart) + " - " + toLocaleDateString(picker.rangeEnd);
picker.addEventListener("change", () => {
  field.value = toLocaleDateString(picker.rangeStart) + " - " + toLocaleDateString(picker.rangeEnd);
});
 最小与最大日期

使用 min-date 与 max-date 禁用日历上早于/晚于对应值的全部日期,并阻止用户把日历翻到包含最小/最大日期的月或年之外(取决于当前视图)。

MM/DD/YYYY 
<!-- Form field omitted for brevity -->
<m3e-datepicker
  id="picker1"
  start-at="2026-04-01"
  min-date="2026-01-01"
  max-date="2026-04-30"
></m3e-datepicker>
禁用日期

除 min-date 与 max-date 约束外,你还可以用 blackoutDates 属性指定一个函数,用于判断某个日期是否被禁用、无法被用户选择。

MM/DD/YYYY 
document.querySelector("#blackout-dates").blackoutDates = (date) => isWeekend(date);
 特殊日期

使用 specialDates 属性指定一个函数,用于判断某个日期是否以高亮样式展示。你可以用 、、、 与 这些 CSS 属性来设置特殊日期的样式。

MM/DD/YYYY 
document.querySelector("#special-dates").specialDates = (date) => isHoliday(date);
 国际化

m3e-datepicker 使用公历,所有日期格式化均由浏览器基于当前区域设置的 Intl API 处理。

无障碍

日期选择器带有 ARIA role="dialog",把这个选择界面标识为打开于页面之上、需要用户关注的一个独立交互区域。当选择器以模态变体显示时,还会设置 aria-modal="true",表明页面其余部分处于惰性状态,焦点被圈定在对话框内直至关闭。停靠模式下则完全省略 aria-modal,因为周边页面仍可交互,此时的界面表现为锚定浮层而非阻断式对话框。

日期选择器开关会在其父元素上添加 aria-haspopup="dialog",告知辅助技术:激活该控件将打开一个对话框。

日历具备完整的无障碍支持,为辅助技术暴露清晰的语义。头部包含导航控件,每个控件都有可通过特性自定义的无障碍标签。日历网格以 实现,每个日期单元格使用 并包含带 的可聚焦元素。选中的日期与范围边界用 标示,今天则用 标记。每个单元格包含一个视觉隐藏、跟随区域设置的完整日期字符串供屏幕阅读器朗读,可见文本只显示日数字。星期表头使用缩写标签,但同时包含视觉隐藏的全名(如“星期一”),确保朗读清晰无歧义。

  • —— 跳转到上一月的按钮的无障碍标签。
  • —— 跳转到下一月的按钮的无障碍标签。
  • —— 跳转到上一年的按钮的无障碍标签。
  • —— 跳转到下一年的按钮的无障碍标签。
  • —— 跳转到上一个 24 年区间的按钮的无障碍标签。
  • —— 跳转到下一个 24 年区间的按钮的无障碍标签。
