Dialog 对话框

m3e-dialog 组件在用户流程中呈现重要的提示、警告与操作。

import "@m3e/web/dialog";
 用法

本节提供该模块组件的用法示例与配置指引。

注意:本页展示在嵌套的 iframe 中。

  • 对话框遮罩只会覆盖当前窗口。
  • 对话框相对于当前窗口定位。
结构解析

m3e-dialog 组件通过具名插槽支持结构化组合,实现灵活的布局与富有表现力的内容呈现:

  • (default) —— 渲染对话框的主要内容。
  • header —— 渲染对话框的头部。通常用于标题、摘要或引言性上下文。
  • actions —— 渲染对话框的操作。通常包含 “OK”、“Cancel” 等按钮或自定义操作。
  • close-icon —— 渲染用于关闭对话框的按钮图标。

 打开

使用 m3e-dialog-trigger 打开对话框。该组件应嵌套在一个可点击元素内部,并把 for 特性设为要打开的对话框的 id 来建立关联。

当点击其父元素时,会打开对话框。当对话框关闭时,焦点会恢复到父元素。

或者,你可以使用 show 方法以编程方式打开对话框。

<m3e-button variant="filled">
  <m3e-dialog-trigger for="dlg">Open Dialog</m3e-dialog-trigger>
</m3e-button>
<m3e-dialog id="dlg" dismissible>
  <!-- Content omitted for brevity -->
</m3e-dialog>
 操作

关闭时,m3e-dialog 会发出 closed 事件。操作用于指定一个返回值,在对话框关闭时设置到对话框上。使用 m3e-dialog-action 组件定义一个操作。

当点击 m3e-dialog-action 的父元素时,它会把其父 m3e-dialog 的 returnValue 属性设为 return-value 特性的值,并关闭对话框。

或者,你可以使用 hide 方法以编程方式关闭对话框。

<m3e-button>
    <m3e-dialog-action return-value="ok">Close</m3e-dialog-action>
</m3e-button>
 可关闭

默认情况下,对话框不呈现关闭(或消除)按钮。使用 m3e-dialog 的 dismissible 特性控制此行为。你可以使用 close-icon 插槽更改图标,并使用 close-label 特性更改无障碍标签。

禁用关闭

该组件允许用户点击对话框的背景板或按 ESCAPE 关闭对话框,从而提供可访问的体验。发生这种情况时,会发出 cancel 事件。使用 m3e-dialog 的 disable-close 特性禁用此行为。

焦点管理

该组件通过提供焦点陷阱把焦点保持在对话框内部,从而提供可访问的体验。使用 m3e-dialog 的 no-focus-trap 特性禁用此行为。

此外,你可以使用 autofocus 特性指定对话框打开时哪个操作应获得焦点。

无障碍

m3e-dialog 呈现一个内部 dialog 元素,其标签由 header 插槽的内容提供。你可以使用 alert 特性指定是否将 ARIA role="alertdialog" 应用于内部对话框。

对话框触发器会向其父元素添加 aria-haspopup="dialog",向辅助技术表明激活该控件将打开对话框。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/dialog.js"></script>
