Drawer Container 抽屉容器

m3e-drawer-container 是一个响应式布局容器,在主内容两侧管理可折叠的左侧与右侧抽屉。 

import "@m3e/web/drawer-container";
 用法

本节提供该模块组件的用法示例与配置指引。

抽屉

m3e-drawer-container 提供 start 与 end 插槽,用于指定抽屉元素。默认插槽呈现抽屉之间的内容。start 与 end 特性控制对应抽屉是否打开。

Start drawer
Main content
End drawer
 
<m3e-drawer-container start end>
  <div slot="start">Start drawer</div>
  <div>Main content</div>
  <div slot="end">End drawer</div>
</m3e-drawer-container>
 尺寸

你可以使用 --m3e-drawer-container-width CSS 自定义属性控制抽屉宽度,也可以显式设置某个抽屉的宽度。

Start drawer
Main content
 
<m3e-drawer-container start>
  <div slot="start" style="width: 200px;">Start drawer</div>
  <div>Main content</div>
</m3e-drawer-container>
 模式

<m3e-drawer-container> 支持四种富有表现力的抽屉模式:

  • side(默认):抽屉始终显示在内容旁边。
  • push:抽屉打开时推移主内容。
  • over:抽屉覆盖在内容之上,不产生位移。
  • auto:模式根据视口大小自适应。

push 与 over 模式会在主内容之上呈现一层遮罩,焦点陷阱会把焦点保持在抽屉内,主内容变为不可交互。点击遮罩会自动关闭抽屉。

使用 start-mode 特性控制起始抽屉的行为,使用 end-mode 独立配置结束抽屉。

Start drawer
Main content
 
<m3e-drawer-container start start-mode="push">
  <div slot="start">Start drawer</div>
  <div>Main content</div>
</m3e-drawer-container>
Start drawer
Main content
 
<m3e-drawer-container start start-mode="over">
  <div slot="start">Start drawer</div>
  <div>Main content</div>
</m3e-drawer-container>
 分隔线

当 mode="side" 时,使用 start-divider 或 end-divider 以分隔线把抽屉与内容隔开。当 mode="auto" 解析为 side 时, 也会显示分隔线。

Main content
End drawer
 
<m3e-drawer-container end end-mode="side" end-divider>
  <div>Main content</div>
  <div slot="end">End drawer</div>
</m3e-drawer-container>
切换

使用 m3e-drawer-toggle 切换抽屉的打开状态。该组件应嵌套 在一个可点击元素内部,并把 for 特性设为某个抽屉的 id 来建立关联。

下面的示例演示如何使用 m3e-icon-button 切换抽屉。更多信息请参阅 Icon Button 图标按钮。

Start drawer
Main content
 
<m3e-icon-button slot="leading-icon" aria-label="Menu" toggle>
  <m3e-icon name="menu"></m3e-icon>
  <m3e-icon slot="selected" name="menu_open"></m3e-icon>
  <m3e-drawer-toggle for="nav-drawer"></m3e-drawer-toggle>
</m3e-icon-button>
<m3e-drawer-container start-mode="over">
  <div slot="start" id="nav-drawer">Start drawer</div>
  <div>Main content</div>
</m3e-drawer-container>
 无障碍

m3e-drawer-container 不会被赋予 ARIA 角色,意味着它在无障碍树中被视为中立、 无语义的元素。

每个抽屉都应被赋予合适的 ARIA 角色。对于呈现应用导航链接的起始抽屉,可考虑使用 nav 元素或 ARIA role="navigation"。当结束抽屉的内容与主内容相关、但对理解主内容并非必需时, 它可以使用 aside 元素或被赋予 ARIA role="complementary"。否则, role="region" 是一个不错的回退选择。

当把 m3e-drawer-container 用作应用的主抽屉容器时,可考虑在它的默认插槽中嵌套一个 main 元素。否则,可考虑使用一个带 ARIA role="region" 的单一 div。 

<m3e-drawer-container>
  <nav slot="start"></nav>
  <main></main>
  <aside slot="end"></aside>
</m3e-drawer-container>

抽屉切换控件使用 aria-controls 把其父元素与抽屉关联,并 动态更新 aria-expanded 以指示抽屉是否打开。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/drawer-container.js"></script>
