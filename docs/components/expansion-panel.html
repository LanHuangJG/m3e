Expansion Panel 折叠面板

@m3e/web/expansion-panel 模块提供用于在可折叠分区与协调组中组织内容的组件。它包含以下组件:

  • m3e-expansion-panel —— 一种详情-摘要视图,用于在可折叠分区中组织内容。
  • m3e-accordion —— 把多个折叠面板组织成一个协调的组。
import "@m3e/web/expansion-panel";
 用法

本节提供该模块组件的用法示例与配置指引。

独立面板

你可以使用独立的 m3e-expansion-panel 呈现一个可折叠的详情-摘要分区。 使用 header 插槽指定面板标题,使用默认插槽放置其内容。

Panel header Panel contents 
<m3e-expansion-panel>
  <span slot="header">Panel header</span>
  Panel contents
</m3e-expansion-panel>

使用 open 特性控制面板是否打开(展开)。

Panel header Panel contents 
<m3e-expansion-panel open>
  <span slot="header">Panel header</span>
  Panel contents
</m3e-expansion-panel>
 切换控件

你可以使用 toggle-position 与 toggle-direction 特性更改切换控件的位置与方向。支持的位置包括 before 与 after(默认)。支持的方向包括 vertical(默认)与 horizontal。

Panel header Panel contents 
<m3e-expansion-panel toggle-position="before" toggle-direction="horizontal">
  <span slot="header">Panel header</span>
  Panel contents
</m3e-expansion-panel>

使用 hide-toggle 特性隐藏切换控件。

Panel header Panel contents 
<m3e-expansion-panel hide-toggle>
  <span slot="header">Panel header</span>
  Panel contents
</m3e-expansion-panel>
 手风琴

使用 m3e-accordion 创建一组协调的面板。

Panel 1 I am content for the first panel Panel 2 I am content for the second panel Panel 3 I am content for the third panel 
<m3e-accordion>
  <m3e-expansion-panel open>
    <span slot="header">Panel 1</span>
    I am content for the first panel
  </m3e-expansion-panel>
  <!-- Additional panels omitted for brevity -->
</m3e-accordion>

默认情况下,一次只能打开一个面板。使用 multi 特性允许多个 面板同时打开。

Panel 1 I am content for the first panel Panel 2 I am content for the second panel Panel 3 I am content for the third panel 
<m3e-accordion multi>
  <m3e-expansion-panel open>
    <span slot="header">Panel 1</span>
    I am content for the first panel
  </m3e-expansion-panel>
  <!-- Additional panels omitted for brevity -->
</m3e-accordion>
 无障碍

折叠面板模拟原生 detail 与 summary 元素的体验。 在内部,面板的标题会被赋予 ARIA role="button" 以及带有面板内部内容包装器 ID 的 aria-controls 特性。此外, 内部标题的 aria-expanded 特性会反映面板的展开状态。

由于折叠面板的标题是按钮,请避免在 header 插槽中添加交互式控件,包括按钮与链接。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/expansion-panel.js"></script>

此外,你还必须使用一个 import map 来引入依赖。

  {
    "imports": {

生产构建请使用压缩版文件,以获得最佳加载性能。
