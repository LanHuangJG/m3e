FAB Menu

m3e-fab-menu 组件呈现一个由相关操作组成的动态菜单,从 悬浮操作按钮(FAB)优雅地展开。有关使用 悬浮操作按钮的更多信息,请参阅 FAB。 

import "@m3e/web/fab-menu";
 用法

本节提供该模块组件的用法示例与配置指引。

结构解析

m3e-fab-menu 与 m3e-fab 配合使用,创建一个在 FAB 被激活时打开的菜单。

  • 使用嵌套在 m3e-fab 内部的 m3e-fab-menu-trigger 触发菜单。
  • 使用 m3e-fab-menu-trigger 的 for 特性指定要打开的菜单。
  • 在 m3e-fab-menu 中嵌套 2-6 个 m3e-fab-menu-item 组件来指定菜单 项。
Email Message Folder 
<m3e-fab variant="primary" size="large">
  <m3e-fab-menu-trigger for="fabmenu">
    <m3e-icon name="edit"></m3e-icon>
  </m3e-fab-menu-trigger>
</m3e-fab>
<m3e-fab-menu id="fabmenu">
  <m3e-fab-menu-item>
    <m3e-icon slot="icon" name="email" filled></m3e-icon>
    Email
  </m3e-fab-menu-item>
  <m3e-fab-menu-item>
    <m3e-icon slot="icon" name="chat" filled></m3e-icon>
    Message
  </m3e-fab-menu-item>
  <m3e-fab-menu-item>
    <m3e-icon slot="icon" name="folder" filled></m3e-icon>
    Folder
  </m3e-fab-menu-item>
</m3e-fab-menu>
 变体

m3e-fab-menu 支持三种外观变体:primary(默认)、 secondary 与 tertiary。使用 variant 特性更改 外观。

Email Message Folder Email Message Folder 
<m3e-fab variant="secondary" size="large">
  <m3e-fab-menu-trigger for="fabmenu">
    <m3e-icon name="edit"></m3e-icon>
  </m3e-fab-menu-trigger>
</m3e-fab>
<m3e-fab-menu id="fabmenu" variant="secondary">
  <!-- Items omitted for brevity -->
</m3e-fab-menu>
<!-- Other variants omitted for brevity -->
 图标

使用 m3e-fab-menu-item 的 icon 插槽在菜单项标签之前呈现图标。 虽然并非必需,但下面的示例使用 @m3e/icon 中的 m3e-icon 组件,通过 Material Symbols 呈现图标。更多信息请参阅 Icon 图标。 

<m3e-fab-menu-item>
  <m3e-icon slot="icon" name="email" filled></m3e-icon>
  Email
</m3e-fab-menu-item>
 禁用

你可以使用 disabled 特性禁用某个 m3e-fab-menu-item。此外,如果 m3e-fab 被禁用,点击时不会打开 m3e-fab-menu。

Email Message Folder 
<m3e-fab-menu-item disabled>
  <m3e-icon slot="icon" name="email" filled></m3e-icon>
  Email
</m3e-fab-menu-item>
 链接

菜单项也可以通过 href 特性指定 URL,从而表现得像链接。你还可以 像原生 anchor 标签那样指定 target、rel 与 download。

Google 
<m3e-fab-menu-item href="https://www.google.com" target="_blank">
  <m3e-icon slot="icon" name="open_in_new_window" filled></m3e-icon>
  Google
</m3e-fab-menu-item>
 无障碍

FAB 菜单会被赋予 ARIA role="menu",菜单项会被赋予 role="menuitem",表示 该菜单的行为类似上下文操作列表。

m3e-fab 的 aria-controls 特性会被赋予菜单的 ID, aria-haspopup="menu" 表示该 FAB 将打开一个菜单。此外,FAB 的 aria-expanded 特性会反映菜单的打开状态。

当为某个菜单项指定 href 时,其 ARIA 角色不会改变,仍然是 menuitem。此外,该组件会呈现一个对辅助技术隐藏的内部 anchor, 用于调用原生浏览器功能,例如上下文菜单选项与工具提示。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/fab-menu.js"></script>

由于 @m3e/fab 是依赖项,你还需要为它引入一个 module 脚本。

<script type="module" src="/node_modules/@m3e/web/dist/fab.js"></script>

此外,你还必须使用一个 import map 来引入依赖。
