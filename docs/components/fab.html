FAB

m3e-fab 是一个悬浮操作按钮(FAB),用于呈现重要操作。

import "@m3e/web/fab";
 用法

本节提供该模块组件的用法示例与配置指引。

变体

FAB 有七种外观变体:primary、primary-container(默认)、 secondary、secondary-container、tertiary、 tertiary-container 与 surface。使用 variant 特性更改 外观。 

<m3e-fab variant="primary">
  <m3e-icon name="add"></m3e-icon>
</m3e-fab>
<!-- Additional variants omitted for brevity -->
 降低

使用 lowered 特性降低 FAB 的高度,以减弱强调。所有外观变体都支持 降低。 

<m3e-fab lowered variant="primary">
  <m3e-icon name="add"></m3e-icon>
</m3e-fab>
<!-- Additional variants omitted for brevity -->
 尺寸

有三种尺寸变体可用于增强或减弱强调: small、medium(默认)与 large。使用 size 特性 控制 FAB 的尺寸。 

<m3e-fab size="small">
  <m3e-icon name="add"></m3e-icon>
</m3e-fab>
<!-- Additional variants omitted for brevity -->
 禁用

使用 disabled 特性禁用 FAB。默认情况下,禁用的 FAB 无法通过 键盘获得焦点。你可以使用 disabled-interactive 特性支持 禁用控件的可聚焦性 以提升其可发现性。 

<m3e-fab disabled>
  <m3e-icon name="add"></m3e-icon>
</m3e-fab>
<m3e-fab disabled-interactive>
  <m3e-icon name="add"></m3e-icon>
</m3e-fab>
 扩展 FAB

使用 extended 特性与 label 插槽创建扩展 FAB。

Extended Small Extended Medium Extended Large 
<m3e-fab extended size="small">
  <m3e-icon name="add"></m3e-icon>
  <span slot="label">Extended</span>
</m3e-fab>
<!-- Additional sizes omitted for brevity -->
 类型

使用 type 特性控制 FAB 的行为。默认情况下,type 为 button。你可以把它改为 submit 或 reset,以便在点击时提交或重置其 父表单。提交表单时,你可以使用 name 与 value 特性指定一个值。

链接

FAB 也可以通过 href 特性指定 URL,从而表现得像链接。你还可以 像原生 anchor 标签那样指定 target、rel 与 download。

Google 
<m3e-fab extended href="https://www.google.com" target="_blank">
  <m3e-icon name="open_in_new_window"></m3e-icon>
  <span slot="label">Google</span>
</m3e-fab>
 密度

FAB 具备密度感知能力,会根据 --md-sys-density-scale 与 --md-sys-density-size 自定义 CSS 属性调整其垂直间距。默认 密度大小为 4dp。FAB 支持低至 -3 的负密度刻度,每一步都会把视觉 高度减少一个密度单位。无论视觉尺寸如何,FAB 都保持 48x48dp 的最小触摸目标,以确保 可靠的无障碍体验。

无障碍

默认情况下,FAB 会被赋予 ARIA 角色 button,表示它们是可点击并 触发操作的元素。

除非是扩展 FAB,否则应始终通过 aria-label 或 aria-labelledby 为每个 FAB 提供无障碍标签。

插槽带有 aria-hidden="true",以确保图标始终对辅助技术隐藏。

当使用 disabled 或 disabled-interactive 特性禁用时, aria-disabled="true" 会用于向辅助技术传达该 FAB 已禁用。如果 使用 disabled-interactive 禁用,则会保留 tabindex,以传达该 FAB 仍然可交互。

当指定 href 时,会使用 ARIA 角色 link 而非 button,以 传达该 FAB 提供了对资源的交互式引用。此外,该组件会呈现一个 对辅助技术隐藏的内部 anchor,用于调用原生浏览器功能,例如上下文 菜单选项与工具提示。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/fab.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",

      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
