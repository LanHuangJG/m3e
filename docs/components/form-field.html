Form Field 表单容器

m3e-form-field 是表单控件的容器,应用 Material Design 的样式与 行为。支持的控件包括 input、select、textarea 与 m3e-input-chip-set。 

import "@m3e/web/form-field";
 用法

本节提供该模块组件的用法示例与配置指引。

变体

有两种表单容器外观变体:outlined(默认)与 filled。使用 variant 特性更改外观。 

<m3e-form-field variant="outlined">
  <label slot="label" for="fld">Outlined</label>
  <input id="fld" />
</m3e-form-field>
<!-- Additional variants omitted for brevity -->
 浮动标签

当表单容器的控件为空时,标签会呈现在控件之上而非其上方。你可以使用 float-label 特性更改此行为。支持的值包括 always 与 auto(默认)。 

<m3e-form-field float-label="always">
  <label slot="label" for="fld">Always float label</label>
  <input id="fld" />
</m3e-form-field>
 提示标签

提示标签是出现在字段下标位置的附加描述性文本。使用 hint 插槽指定提示。默认情况下,字段的下标会隐藏,直到获得焦点或 字段无效时才显示。使用 hide-subscript 特性控制此行为。支持的值 包括 always、auto(默认)与 never。使用 always 会移除为字段下标保留的空间。

下面的示例演示如何使用 hint 插槽并把 hide-subscript 设为 never。

Hint text 
<m3e-form-field hide-subscript="never">
  <label slot="label" for="fld">Field w/ hint</label>
  <input id="fld" />
  <span slot="hint">Hint text</span>
</m3e-form-field>
 错误消息

错误默认隐藏,只有当用户与字段交互后——例如先聚焦再失焦——或父表单已提交后 才会显示。此行为确保验证反馈与上下文相关且不具侵入性, 只在用户可能预期时出现。

当显示错误消息时,它会占据字段下方通常用于 提示标签的同一片下标区域。为防止视觉重叠并保持清晰,只要 显示错误,提示就会自动隐藏。

Hint text 
<m3e-form-field>
  <label slot="label" for="fld5">Required field</label>
  <input id="fld5" required />
  <span slot="hint">Hint text</span>
</m3e-form-field>

默认情况下,字段控件的验证消息会呈现在字段的下标中。你可以使用 error 插槽指定 自定义错误消息。

Hint text Custom error message 
<m3e-form-field>
  <label slot="label" for="fld">Required field</label>
  <input id="fld" required />
  <span slot="hint">Hint text</span>
  <span slot="error">Custom error message</span>
</m3e-form-field>
 隐藏必填标记

默认情况下,必填字段会在字段标签旁显示一个标记。使用 hide-required-marker 特性移除它。 

<m3e-form-field hide-required-marker>
  <label slot="label" for="fld">Required field</label>
  <input id="fld" required />
</m3e-form-field>
 前缀与后缀

可以在字段控件之前或之后加入内容,作为前缀或后缀。这些内容 会渲染在包裹表单控件的同一视觉容器内,确保对齐、间距 与样式一致。

使用 prefix 与 suffix 插槽放置图标与按钮。对于文本内容,使用 prefix-text 与 suffix-text 插槽。

$ .00 
<m3e-form-field>
  <label slot="label" for="fld">Amount</label>
  <span slot="prefix-text">$</span>
  <input id="fld" type="number" placeholder="0" />
  <span slot="suffix-text">.00</span>
  <m3e-icon-button slot="suffix">
    <m3e-icon name="clear"></m3e-icon>
  </m3e-icon-button>
</m3e-form-field>
 密度

表单容器具备密度感知能力,会根据 --md-sys-density-scale 与 --md-sys-density-size 自定义 CSS 属性调整其垂直间距。默认 密度大小为 4dp。表单容器支持低至 -3 的负密度刻度,每一步都会把 视觉高度减少一个密度单位。

下面演示对 outlined 与 filled 两种变体应用密度。 

<m3e-form-field variant="outlined" class="density-3">
  <label slot="label" for="fld">Density -3</label>
  <input id="fld" />
</m3e-form-field>
<!-- Additional fields and variants omitted for brevity -->
 
.density-3 {
  --md-sys-density-scale: -3;
}
/* Additional classes omitted for brevity */
 无障碍

m3e-form-field 会把提示标签与错误消息从无障碍树中隐藏,并使用一个 视觉隐藏元素把它们呈现给辅助技术。它们的 ID 会被添加到 字段控件的 aria-describedby 特性中。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/form-field.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",

生产构建请使用压缩版文件,以获得最佳加载性能。
