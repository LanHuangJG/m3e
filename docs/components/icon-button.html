Icon Button 图标按钮

m3e-icon-button 组件是一个图标按钮,用户通过它执行辅助操作。 

import "@m3e/web/icon-button";
 用法

本节提供该模块组件的用法示例与配置指引。

变体

图标按钮有四种外观变体:filled、tonal、 outlined 与 standard(默认)。使用 variant 特性更改外观。 

<m3e-icon-button variant="filled">
    <m3e-icon name="check"></m3e-icon>
</m3e-icon-button>
<!-- Additional variants omitted for brevity -->
 形状

图标按钮有两种形状:rounded(默认)或 square。使用 shape 特性控制按钮的形状。 

<m3e-icon-button variant="filled" shape="square">
    <m3e-icon name="check"></m3e-icon>
</m3e-icon-button>
<!-- Additional variants omitted for brevity -->
 尺寸

共有五种尺寸变体,可用于增强或弱化强调: extra-small、small(默认)、medium、large 与 extra-large。使用 size 特性控制图标按钮的尺寸。 

<m3e-icon-button variant="tonal" size="extra-small">
    <m3e-icon name="add"></m3e-icon>
</m3e-icon-button>
<!-- Additional sizes omitted for brevity -->
 宽度

共有三种宽度变体,可用于增强或弱化强调:default(默认)、 narrow 与 wide。使用 width 特性控制图标按钮的 宽度。 

<m3e-icon-button variant="tonal" width="narrow">
  <m3e-icon name="add"></m3e-icon>
</m3e-icon-button>
<m3e-icon-button variant="tonal" width="wide">
  <m3e-icon name="add"></m3e-icon>
</m3e-icon-button>
 切换

使用 toggle 特性控制图标按钮是否可用于二元选择,使用 selected 特性控制选中状态。点击时会先派发一个可取消的 beforeinput 事件,随后派发 input 与 change 事件。要 取消选择变更,请在 beforeinput 期间调用 preventDefault。 

<m3e-icon-button variant="filled" toggle>
    <m3e-icon name="check"></m3e-icon>
</m3e-icon-button>
<!-- Additional variants omitted for brevity -->

你也可以使用 selected 插槽更改选中态切换按钮所呈现的图标。

 
<m3e-icon-button variant="tonal" toggle>
  <m3e-icon name="close"></m3e-icon>
  <m3e-icon slot="selected" name="check"></m3e-icon>
</m3e-icon-button>

选中时,图标按钮会改变形状。圆角按钮变为方形,方形按钮变为圆角。下面的示例演示了圆角与方形图标按钮的选中状态。



禁用

使用 disabled 特性禁用图标按钮。默认情况下,禁用的图标按钮无法通过键盘 聚焦。你可以使用 disabled-interactive 特性支持 focusability of disabled controls 以提高其可发现性。 

<m3e-icon-button variant="filled" disabled>
  <m3e-icon name="check"></m3e-icon>
</m3e-icon-button>
<m3e-icon-button variant="filled" disabled-interactive>
  <m3e-icon name="check"></m3e-icon>
</m3e-icon-button>
 类型

使用 type 特性控制图标按钮的行为。默认情况下, type 为 button。你可以将其改为 submit 或 reset,以便 在点击时提交或重置其父表单。提交表单时,你可以使用 name 与 value 特性指定值。

链接

图标按钮也可以通过 href 特性指定 URL 来表现得像链接。你还可以 像原生锚点标签那样指定 target、rel 与 download。 

<m3e-icon-button variant="tonal" href="https://www.google.com" target="_blank">
  <m3e-icon name="open_in_new_window"></m3e-icon>
</m3e-icon-button>
 密度

图标按钮感知密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整其垂直间距。默认 密度尺寸为 4dp。按钮支持低至 -3 的负密度比例,每降低一档,视觉高度减少一个密度单位。无论视觉尺寸如何,图标按钮都保持 48x48dp 的最小触摸目标,以 确保可靠的无障碍性。

下面的示例演示了将密度应用于 extra-small 与 small 尺寸的图标 按钮。 

<m3e-icon-button class="density-3" variant="filled" size="extra-small">
  <m3e-icon name="check"></m3e-icon>
</m3e-icon-button>
<!-- Additional buttons omitted for brevity -->
 
.density-3 {
  --md-sys-density-scale: -3;
}
/* Additional classes omitted for brevity */
 无障碍

默认情况下,图标按钮带有 ARIA 角色 button,表明它们是可点击并触发操作的元素。

请始终通过 aria-label 或 aria-labelledby 为每个图标 按钮提供无障碍标签。

插槽带有 aria-hidden="true",以确保图标始终对辅助技术隐藏。

当使用 disabled 或 disabled-interactive 特性禁用时, aria-disabled="true" 用于向辅助技术传达该图标按钮已 禁用。如果通过 disabled-interactive 禁用,则会保留 tabindex,以传达 该图标按钮仍可交互。

指定 href 时,会使用 ARIA 角色 link 而非 button,以 传达图标按钮提供了指向资源的可交互引用。此外,组件会呈现一个对辅助技术隐藏的内部锚点, 用于调用原生浏览器功能,如上下文菜单选项与工具提示。

对于切换型图标按钮,即使处于禁用状态,也会使用 aria-pressed 传达选中状态。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/icon-button.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",

生产构建请使用压缩版文件,以获得最佳加载性能。
