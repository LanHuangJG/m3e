Icon 图标

m3e-icon 组件让在应用中使用 Material Symbols 变得简单。它支持 outlined、rounded 与 sharp 变体,以及 fill、weight、grade 与 optical size 等可变字体特性。更多信息请参阅 Material Symbol Guide 与 Material Symbol Library 。

Material Symbols 字体是把 Material Symbols 引入应用中最简单的方式。借助 Fonts CSS API,你可以使用可变字体优化应用中的图标使用。请参阅 Can I Use's Variable Fonts 以确定你的用户浏览器是否支持可变字体。

或者,@m3e/icons 包提供 Material Symbols 的 SVG 版本,它们会自动注册到 m3e-icon。用法详见下文的 SVG 图标一节。 

import "@m3e/web/icon";
 用法

本节提供该模块组件的用法示例与配置指引。

基础图标

下面的示例演示了 m3e-icon 组件的基本用法。使用 name 特性指定要呈现的 Material Symbol 名称。 

<m3e-icon name="home"></m3e-icon>
 可变字体

下面的示例演示了如何链接一个支持 fill 的 outlined 图标可变字体。

<link
  href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0..1,0"
  rel="stylesheet"
/>
 外观变体

m3e-icon 组件支持外观变体,以及针对 fill、weight、grade 与 optical size 的细粒度排版控制。

使用 variant 特性控制图标的视觉样式。支持的取值包括: outlined(默认)、rounded 与 sharp。使用 filled 特性指定图标是填充(1)还是不填充 (0)。该特性映射到可变字体的 FILL 轴。

weight 特性调整图标笔画的粗细与浓淡。其行为类似文本中的字重,可接受 100 到 700 的取值。使用 grade 特性调整图标的笔画粗细。支持的取值包括: low、medium(默认)与 high。该特性映射到可变字体的 GRAD 轴,取值为 -25、0 或 200 之类。

optical-size 特性支持 20 到 48 的取值,用于指定图标的光学尺寸。

SVG 图标

作为可变字体的替代方案,对于偏好基于 SVG 的图标的应用,你可以使用 @m3e/icons 包。该包提供源自 @material-symbols/svg-400 的 SVG 数据,并通过内部图标注册表与现有的 m3e-icon 组件集成。 

import "@m3e/icons/outlined/search";
import "@m3e/icons/outlined/home";
import "@m3e/icons/outlined/settings";
import "@m3e/icons/outlined/favorite";
import "@m3e/icons/outlined/notifications";

图标按 Material Symbols 变体家族(outlined、rounded、 sharp)组织。你可以通过导入对应模块来注册特定图标: 

import "@m3e/icons/outlined/search";

或者一次注册整个变体家族:

import "@m3e/icons/outlined";

每个图标模块都会对 m3e-icon 所使用的内部注册表执行副作用注册。注册后,该图标即可用于渲染。如果某个图标未注册,则会回退到 Material Symbols 可变字体。

无障碍

图标带有 ARIA role="img",表明它们表示有意义的视觉内容,辅助技术应将其解释为图像。

如果图标纯属装饰,请加上 aria-hidden="true"。否则,必须使用 aria-label 或 aria-labelledby 为其添加标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/icon.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",
      "@lit/reactive-element/": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/",
      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
