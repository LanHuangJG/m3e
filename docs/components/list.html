List 列表

@m3e/web/list 模块提供富有表现力且无障碍的组件,用于组织和显示项目列表。 

import "@m3e/web/list";
 用法

本节提供该模块组件的用法示例与配置指引。

列表

要创建项目列表,请使用 m3e-list 组件,并在其中嵌套一个或多个 m3e-list-item 组件。

结构解析

m3e-list-item 组件为结构化内容块提供模块化布局。它暴露以下具名插槽:

  • (default) —— 渲染列表项的内容。
  • leading —— 渲染列表项的前置内容。
  • overline —— 渲染列表项的上标文本。
  • supporting-text —— 渲染列表项的辅助文本。
  • trailing —— 渲染列表项的后置内容。
Overline Headline Supporting text 100+ 
<m3e-list>
  <m3e-list-item>
    <m3e-icon slot="leading" name="person"></m3e-icon>
    <span slot="overline">Overline</span>
    Headline
    <span slot="supporting-text">Supporting text</span>
    <span slot="trailing">100+</span>
  </m3e-list-item>
</m3e-list>

选择列表

使用 m3e-selection-list 与 m3e-list-option 创建用于选择值的列表, 其中每个项目代表一个选项。选择列表支持与 m3e-list 相同的外观变体, m3e-list-option 支持与 m3e-list-item 相同的插槽。 不过,除非隐藏选择指示器,否则选择指示器会替换 trailing 插槽中的内容。

使用 selected 特性控制 m3e-list-option 的选中状态。点击 时,会先派发一个可取消的 beforeinput 事件,随后派发 input 与 change 事件。要取消选择变更,请在 beforeinput 期间调用 preventDefault。

表单关联

选择列表可以作为 form-associated custom element (FACE)参与表单提交,将其状态贡献到表单数据中。name 特性定义 组件值在表单中提交所用的键。列表的值由选中的选项决定。你可以使用 m3e-list-option 的 value 控制选项的值。当选中多个选项 时,表单数据会包含多个以同一 name 为键的条目。

组件将(选项自身的)disabled 状态视为仅属性(property-only) 控制。运行时禁用时,它不会向 DOM 派生 disabled 特性。

密度

列表感知密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整其垂直间距。默认 密度尺寸为 4dp。列表支持低至 -3 的负密度比例,每降低一档,视觉 高度减少一个密度单位。

下面的示例演示了将 -3 密度应用于 segmented 多选列表。

Option 1 Option 2 Option 3 
<m3e-selection-list class="density-3" variant="segmented" multi>
  <!-- Options omitted for brevity -->
</m3e-selection-list>
 
.density-3 {
  --md-sys-density-scale: -3;
}
 无障碍

列表带有 ARIA role="list",列表项带有 role="listitem",以 确保辅助技术能正确解释内容的结构与语义。

操作列表带有 ARIA role="list",列表操作带有 role="listitem",以确保辅助技术能正确解释内容的结构与 语义。每个列表操作都包含一个带有 ARIA role="button" 的嵌套可交互元素。指定 href 时,会使用 ARIA 角色 link 而非 button,以传达该列表操作提供了指向资源的可交互引用。此外, 组件会呈现一个对辅助技术隐藏的内部锚点,用于调用原生 浏览器功能,如上下文菜单选项与工具提示。使用 disabled 特性禁用时,会对嵌套可交互元素应用 aria-disabled="true", 以向辅助技术传达该操作已禁用。

选择列表带有 ARIA role="listbox",选项带有 role="option",以确保辅助技术将该部件识别为可选择列表,并向用户 暴露正确的交互模型。aria-selected 特性反映某个 选项当前是否被选中。当选项被选中时,会向辅助技术暴露 aria-selected="true";否则为 "false"。使用 disabled 特性禁用时,会对该选项应用 aria-disabled="true",以向 辅助技术传达该选项已禁用。通过 multi 特性启用多选时,会对选择列表应用 aria-multiselectable="true", 表示可以选中多个选项。

可展开列表项使用 ARIA role="listitem"> 并模拟原生 details 与 summary 元素的行为。在每个项目内部,标题被赋予 role="button"> 以及一个引用该项目内部 内容包装器的 aria-controls 特性。内容包装器被赋予 role="list">,以表示子项目的 嵌套列表。标题的 aria-expanded 特性反映该项目当前的展开或折叠状态。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/list.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
