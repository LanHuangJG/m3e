Loading Indicator 加载指示器

m3e-loading-indicator 组件用于在短暂等待时显示不确定进度。它通过 动画吸引注意、缓解感知延迟,并表明某项活动正在进行中。 

import "@m3e/web/loading-indicator";
 用法

本节提供该模块组件的用法示例与配置指引。

变体

加载指示器有两种外观变体:uncontained(默认)与 contained。使用 variant 特性更改外观。 

<m3e-loading-indicator></m3e-loading-indicator>
<m3e-loading-indicator variant="contained"></m3e-loading-indicator>
 无障碍

m3e-loading-indicator 实现 ARIA role="progressbar" 模式。默认 情况下,组件将 aria-valuemin 设为 0,将 aria-valuemax 设为 100。

请始终通过 aria-label 或 aria-labelledby 为每个 加载指示器提供无障碍标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/loading-indicator.js"></script>

生产构建请使用压缩版文件,以获得最佳加载性能。
