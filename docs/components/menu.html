Menu 菜单

m3e-menu 组件在临时表面上呈现一组选择,通常锚定到触发元素。 

import "@m3e/web/menu";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

m3e-menu 与 m3e-menu-trigger 配合使用,创建在触发器的父元素被激活时打开的菜单。使用 m3e-menu-trigger 的 for 特性指定要打开的菜单。

Menu 菜单 Item 1 Item 2 
<m3e-button>
  <m3e-menu-trigger for="menu">Menu</m3e-menu-trigger>
</m3e-button>
<m3e-menu id="menu">
  <m3e-menu-item>Item 1</m3e-menu-item>
  <m3e-menu-item>Item 2</m3e-menu-item>
</m3e-menu>
 变体

有两种外观变体:standard(默认)与 vibrant。使用 variant 特性更改外观。

Vibrant menu Item 1 Item 2 
<!-- Trigger omitted for brevity -->
<m3e-menu id="menu" variant="vibrant">
  <m3e-menu-item>Item 1</m3e-menu-item>
  <m3e-menu-item>Item 2</m3e-menu-item>
</m3e-menu>
 菜单项

<m3e-menu> 组件支持三种不同的菜单项类型,每种都针对不同的交互模式与语义角色:

  • m3e-menu-item —— 标准菜单项,通常用于导航或触发命令。
  • m3e-menu-item-checkbox —— 可切换的菜单项选项,用于多选场景。
  • m3e-menu-item-radio —— 可切换的菜单项选项,用于单选场景。
图标

所有菜单项类型都提供两个用于图标的具名插槽。使用 icon 插槽在项目标签前呈现图标,使用 trailing-icon 插槽在其后呈现图标。

Menu items with icons Redial Check voice mail Disable alerts 
<!-- Trigger omitted for brevity -->
<m3e-menu id="menu">
  <m3e-menu-item>
    <m3e-icon slot="icon" name="dialpad"></m3e-icon>
    Redial
  </m3e-menu-item>
  <m3e-menu-item>
    <m3e-icon slot="icon" name="voicemail"></m3e-icon>
    Check voice mail
  </m3e-menu-item>
  <m3e-menu-item>
    <m3e-icon slot="icon" name="notifications_off"></m3e-icon>
    Disable alerts
  </m3e-menu-item>
</m3e-menu>
禁用

使用 disabled 特性禁用菜单项。

Menu with disabled items Redial Check voice mail Disable alerts 
<!-- Trigger omitted for brevity -->
<m3e-menu id="menu">
  <m3e-menu-item disabled>
    <m3e-icon slot="icon" name="dialpad"></m3e-icon>
    Redial
  </m3e-menu-item>
  <!-- Additional items omitted for brevity -->
</m3e-menu>
复选框

使用 m3e-menu-item-checkbox 呈现支持多选的可切换菜单项。 checked 特性反映菜单项的选中状态。如果菜单项通过 icon 插槽指定了图标, 则在选中时该图标会被替换为对勾图标。

Menu with checkboxes Bold Italic Underline 
<!-- Trigger omitted for brevity -->
<m3e-menu id="menu">
  <m3e-menu-item-checkbox checked>
    <m3e-icon slot="icon" name="format_bold"></m3e-icon>
    Bold
  </m3e-menu-item-checkbox>
  <m3e-menu-item-checkbox>
    <m3e-icon slot="icon" name="format_italic"></m3e-icon>
    Italic
  </m3e-menu-item-checkbox>
  <m3e-menu-item-checkbox>
    <m3e-icon slot="icon" name="format_underlined"></m3e-icon>
    Underline
  </m3e-menu-item-checkbox>
</m3e-menu>
 单选框

使用 m3e-menu-item-radio 呈现支持单选的可切换菜单项。 checked 特性反映菜单项的选中状态。如果菜单项通过 icon 插槽指定了图标, 则在选中时该图标会被替换为对勾图标。

Menu with radios Ascending Descending 
<!-- Trigger omitted for brevity -->
<m3e-menu id="menu">
  <m3e-menu-item-radio checked>Ascending</m3e-menu-item-radio>
  <m3e-menu-item-radio>Descending</m3e-menu-item-radio>
</m3e-menu>

使用 m3e-menu-item-group 在单个 m3e-menu 内组织多组单选项目。每个分组维护各自的选择状态,使不同的单选组可以 独立共存。

Menu with radio groups Ascending Descending Alphabetical By Date 
<!-- Trigger omitted for brevity -->
<m3e-menu id="menu">
  <m3e-menu-item-group>
    <m3e-menu-item-radio checked>Ascending</m3e-menu-item-radio>
    <m3e-menu-item-radio>Descending</m3e-menu-item-radio>
  </m3e-menu-item-group>
  <m3e-divider></m3e-divider>
  <m3e-menu-item-group>
    <m3e-menu-item-radio checked>Alphabetical</m3e-menu-item-radio>
    <m3e-menu-item-radio>By Date</m3e-menu-item-radio>
  </m3e-menu-item-group>
</m3e-menu>
 子菜单

子菜单通过在 m3e-menu-item 中嵌套 m3e-menu-trigger,并使用 for 特性指定要打开的子菜单来触发。

Menu with submenus Fruits with A Grapes Olive Orange Apricot Avocado Apples Fuji Granny Smith Red Delicious 
<m3e-button>
  <m3e-menu-trigger for="menu1">Menu with submenus</m3e-menu-trigger>
</m3e-button>
<m3e-menu id="menu1">
  <m3e-menu-item>
    <m3e-menu-trigger for="submenu1">Fruits with A</m3e-menu-trigger>
  </m3e-menu-item>
  <m3e-menu-item>Grapes</m3e-menu-item>
  <m3e-menu-item>Olive</m3e-menu-item>
  <m3e-menu-item>Orange</m3e-menu-item>
</m3e-menu>
<m3e-menu id="submenu1">
  <m3e-menu-item>Apricot</m3e-menu-item>
  <m3e-menu-item>Avocado</m3e-menu-item>
  <m3e-menu-item>
    <m3e-menu-trigger for="submenu2">Apples</m3e-menu-trigger>
  </m3e-menu-item>
</m3e-menu>
<m3e-menu id="submenu2">
  <m3e-menu-item>Fuji</m3e-menu-item>
  <m3e-menu-item>Granny Smith</m3e-menu-item>
  <m3e-menu-item>Red Delicious</m3e-menu-item>

 密度

菜单感知密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整其垂直间距。默认 密度尺寸为 4dp。菜单支持低至 -3 的负密度比例,每降低一档,视觉 高度减少一个密度单位。

下面的示例演示了将密度应用于菜单。

Density -3 Item 1 Item 2 Item 3 Density -2 Item 1 Item 2 Item 3 Density -1 Item 1 Item 2 Item 3 Density 0 Item 1 Item 2 Item 3 
<!-- Trigger omitted for brevity -->
<m3e-menu id="menu" class="density-3">
  <m3e-menu-item>
    <m3e-icon slot="icon" name="stars"></m3e-icon>
    Item 1
  </m3e-menu-item>
  <!-- Additional items omitted for brevity -->
</m3e-menu>
<!-- Additional menus omitted for brevity -->
 
.density-3 {
  --md-sys-density-scale: -3;
}
/* Additional classes omitted for brevity */
 无障碍

菜单带有 ARIA role="menu",表明它们充当交互式菜单项列表的容器。

触发器通过 aria-haspopup、aria-controls 与 aria-expanded 增强其父元素,以建立与触发器菜单的关联。

菜单打开时,焦点会设到第一个启用的菜单项。关闭时,焦点返回触发器。

标准菜单项带有 ARIA role="menuitem",复选框带有 role="menuitemcheckbox",单选框带有 role="menuitemradio"。 aria-checked 特性反映项目的选中状态。

禁用的菜单项带有 aria-disabled="true",以向辅助技术传达 该项目已禁用。此外,会移除 tabindex,表示该项目不再 可聚焦。

菜单项分组带有 ARIA role="group",应使用 aria-label 或 aria-labelledby 添加标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/menu.js"></script>

此外,你还必须使用一个 import map 来引入依赖。
