Nav Bar 导航栏

m3e-nav-bar 是一个水平条,通常用于较小的设备,允许用户在 3-5 个视图之间切换。 

import "@m3e/web/nav-bar";
 用法

本节提供该模块组件的用法示例与配置指引。

模式

m3e-nav-bar 支持三种模式:compact(默认)、expanded 与 auto。在 compact 模式下,条目垂直排列并填满条内的可用空间。 展开时,条目水平排列并在条内居中。使用 auto 时, 排列方向是响应式的,由视口尺寸决定。使用 mode 特性更改 条的模式。

下面的示例演示了 compact 与 expanded 两种模式。

News Global For you Trending
News Global For you Trending 
<m3e-nav-bar mode="compact">
  <m3e-nav-item><m3e-icon slot="icon" name="news"></m3e-icon>News</m3e-nav-item>
  <m3e-nav-item><m3e-icon slot="icon" name="globe"></m3e-icon>Global</m3e-nav-item>
  <m3e-nav-item><m3e-icon slot="icon" name="star"></m3e-icon>For you</m3e-nav-item>
  <m3e-nav-item><m3e-icon slot="icon" name="newsstand"></m3e-icon>Trending</m3e-nav-item>
</m3e-nav-bar>
<br />
<m3e-nav-bar mode="expanded">
  <!-- Items omitted for brevity -->
</m3e-nav-bar>
 条目

如上所示,条目使用 m3e-nav-item 组件指定。使用默认插槽 指定条目的标签,使用 icon 插槽指定图标。 

<m3e-nav-item><m3e-icon slot="icon" name="news"></m3e-icon>News</m3e-nav-item>
 选择

m3e-nav-bar 仅支持单选。使用 selected 特性指定 m3e-nav-item 中哪个条目被选中。点击时,会先派发一个可取消的 beforeinput 事件,随后派发 input 与 change 事件。要 取消选择变更,请在 beforeinput 期间调用 preventDefault。

此外,你可以使用 selected-icon 插槽指定选中时的替代图标。使用 m3e-icon 呈现图标时,条目被选中后图标会自动填充。

News Global For you Trending 
<m3e-nav-bar>
  <m3e-nav-item selected><m3e-icon slot="icon" name="news"></m3e-icon>News</m3e-nav-item>
  <!-- Additional items omitted for brevity -->
</m3e-nav-bar>
 禁用

使用 disabled 特性禁用条目。默认情况下,禁用的条目无法通过键盘聚焦。 你可以使用 disabled-interactive 特性支持 focusability of disabled controls 以提高其可发现性。

News Global For you Trending 
<m3e-nav-bar>
  <m3e-nav-item disabled><m3e-icon slot="icon" name="news"></m3e-icon>News</m3e-nav-item>
  <m3e-nav-item disabled-interactive><m3e-icon slot="icon" name="globe"></m3e-icon>Global</m3e-nav-item>
  <!-- Additional items omitted for brevity -->
</m3e-nav-bar>
 链接

条目也可以通过 href 特性指定 URL 来表现得像链接。你还可以 像原生锚点标签那样指定 target、rel 与 download。

News 
<m3e-nav-bar>
  <m3e-nav-item href="https://www.google.com" target="_blank">
    <m3e-icon slot="icon" name="news"></m3e-icon>News
  </m3e-nav-item>
</m3e-nav-bar>
 无障碍

导航栏带有 ARIA role="navigation",表明该区域充当 导航地标,帮助辅助技术将其识别为站点或应用导航链接的容器。请始终通过 aria-label 或 aria-labelledby 提供无障碍标签。

条目带有 ARIA 角色 button,表明它们是可点击并触发操作的元素, 并使用 aria-current="true" 传达选中状态。

图标插槽带有 aria-hidden="true",以确保图标始终对辅助 技术隐藏。

当使用 disabled 或 disabled-interactive 特性禁用时, aria-disabled="true" 用于向辅助技术传达该条目已禁用。如果 通过 disabled-interactive 禁用,则会保留 tabindex,以传达该条目 仍可交互。

指定 href 时,会使用 ARIA 角色 link 而非 button,以 传达该条目提供了指向资源的可交互引用。此外,组件会呈现一个 对辅助技术隐藏的内部锚点,用于调用原生浏览器功能,如上下文 菜单选项与工具提示。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/nav-bar.js"></script>
