Nav Menu 导航菜单

m3e-nav-menu 组件是一个为较大设备上的侧边栏与抽屉优化的层级菜单。它使用户能够浏览嵌套菜单结构,并在应用视图之间无缝切换。 

import "@m3e/web/nav-menu";
 用法

本节提供该模块组件的用法示例与配置指引。

多级菜单

使用 m3e-nav-menu 与 m3e-nav-menu-item 创建多级导航菜单。

使用 m3e-nav-menu-item 的 label 插槽指定条目的标签。此外, 使用 icon 插槽在条目标签前加入图标,使用 badge 插槽 指定紧凑的状态指示器或补充文本。

要创建多级结构,请嵌套一个或多个 m3e-nav-menu-item 组件。

  <m3e-nav-menu-item open>
    <m3e-icon slot="icon" name="rocket_launch" aria-hidden="true"></m3e-icon>
    <span slot="label">Getting Started</span>
    <m3e-nav-menu-item>
      <m3e-icon slot="icon" name="widgets" aria-hidden="true"></m3e-icon>
      <span slot="label">Overview</span>
    </m3e-nav-menu-item>
    <!-- Additional items omitted for brevity -->;
  </m3e-nav-menu-item>
  <m3e-nav-menu-item>
    <span slot="label">Actions</span>
    <!-- Items omitted for brevity -->;
  </m3e-nav-menu-item>
</m3e-nav-menu>
 对顶层条目分组

你可以使用 m3e-nav-menu-item-group 对菜单中的顶层条目进行分组。使用 label 插槽指定分组的标签。使用 m3e-divider 分隔 菜单中的分组。更多信息请参阅 Divider 分隔线。

邮件 Inbox 24 Outbox Favorites Trash 个人文件夹 Family Wedding 
<m3e-nav-menu>
  <m3e-nav-menu-item-group>
    <m3e-heading slot="label" variant="label" size="large">Mail</m3e-heading>
    <m3e-nav-menu-item>
      <m3e-icon slot="icon" name="mail"></m3e-icon>
      <span slot="label">Inbox</span>
      <span slot="badge">24</span>
    </m3e-nav-menu-item>
    <!-- Additional items omitted for brevity -->
  </m3e-nav-menu-item-group>
  <m3e-divider></m3e-divider>
  <m3e-nav-menu-item-group>
    <m3e-heading slot="label" variant="label" size="large">Personal folders</m3e-heading>
    <!-- Items omitted for brevity -->;
  </m3e-nav-menu-item-group>
</m3e-nav-menu>
 禁用

使用 m3e-nav-menu-item 的 disabled 特性禁用该条目及其所有 子项。禁用带有子项的条目不会自动将其收起。

    <m3e-icon slot="icon" name="rocket_launch" aria-hidden="true"></m3e-icon>

 密度

导航菜单感知密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整其垂直间距。默认 密度尺寸为 4dp。导航菜单支持低至 -3 的负密度比例,每降低一档,视觉 高度减少一个密度单位。

下面的示例演示了将 -3 密度应用于导航菜单。

邮件 Inbox 24 Outbox Favorites Trash 个人文件夹 Family Wedding 
<m3e-nav-menu class="density-3">
  <!-- Items omitted for brevity -->;
</m3e-nav-menu>
 
.density-3 {
  --md-sys-density-scale: -3;
}
 无障碍

导航菜单带有 ARIA role="tree",条目被赋予 role="treeitem", 表示一种结构化、层级化的导航模型,支持键盘交互、语义分组 与无障碍标签。可展开条目使用 aria-expanded 表示嵌套 内容的可见性,当前条目可以使用 aria-current 标示活动页面或视图。

焦点通过 tabindex="0" 在 m3e-nav-menu 容器上管理,当前 活动条目通过 aria-activedescendant 引用,该属性指向获得焦点的 m3e-nav-menu-item 的 ID。这样可以在不移动 DOM 焦点的情况下实现游走式焦点,确保无障碍的键盘导航 与一致的屏幕阅读器反馈。

分组带有 ARIA role="group",表示其内容在导航树中构成一个语义单元,并由分组 label 插槽的内容作为标签。

图标与分隔线带有 aria-hidden="true",确保它们被视为纯装饰并从无障碍树中排除。

禁用条目会设置 aria-disabled="true",向辅助技术表明该条目不可 交互。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/nav-menu.js"></script>

此外,你还必须使用一个 import map 来引入依赖。
