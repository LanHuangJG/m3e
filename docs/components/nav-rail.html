Nav Rail 导航侧栏

m3e-nav-rail 扩展了 Nav Bar 导航栏,提供一个竖向栏, 通常用于较大的设备,允许用户在视图之间切换。 

import "@m3e/web/nav-rail";
 用法

本节提供该模块组件的用法示例与配置指引。

模式

m3e-nav-rail 支持三种模式:compact(默认)、expanded 与 auto。在紧凑模式下,条目竖向排列。展开时,条目横向排列。使用 auto 时, 方向会自适应,由视口尺寸决定。使用 mode 属性更改栏的模式。

下面的示例展示了一种常见布局。

  • m3e-icon-button 与 m3e-nav-rail-toggle 配合使用,提供一个用于在模式之间切换的 切换按钮。for 特性指定要切换的栏。
  • 扩展的 m3e-fab 会自动过渡以反映栏的模式。
  • 顶级目标使用来自 Nav Bar 导航栏 模块的 m3e-nav-item 指定。
Extended News Global For you Trending 
<m3e-nav-rail id="nav-rail">
  <m3e-icon-button toggle>
    <m3e-icon name="menu"></m3e-icon>
    <m3e-icon slot="selected" name="menu_open"></m3e-icon>
    <m3e-nav-rail-toggle for="nav-rail"></m3e-nav-rail-toggle>
  </m3e-icon-button>
  <m3e-fab size="small">
    <m3e-icon name="edit"></m3e-icon>
    <span slot="label">Extended</span>
  </m3e-fab>
  <m3e-nav-item><m3e-icon slot="icon" name="news"></m3e-icon>News</m3e-nav-item>
  <m3e-nav-item><m3e-icon slot="icon" name="globe"></m3e-icon>Global</m3e-nav-item>
  <m3e-nav-item><m3e-icon slot="icon" name="star"></m3e-icon>For you</m3e-nav-item>
  <m3e-nav-item><m3e-icon slot="icon" name="newsstand"></m3e-icon>Trending</m3e-nav-item>
</m3e-nav-rail>
 条目

如上所示,条目使用 m3e-nav-item 组件指定。使用默认插槽指定条目的标签,使用 icon 插槽指定图标。 

<m3e-nav-item><m3e-icon slot="icon" name="news"></m3e-icon>News</m3e-nav-item>
 选择

m3e-nav-rail 仅支持单选。使用 m3e-nav-item 的 selected 属性 指定栏中选中哪个条目。点击时,会先派发一个可取消的 beforeinput 事件,随后是 input 与 change 事件。要取消选择变更,请在 beforeinput 期间调用 preventDefault。

此外,你可以使用 selected-icon 插槽指定选中时的备用图标。使用 m3e-icon 呈现图标时,条目被选中后图标会自动填充。

禁用

使用 disabled 属性禁用条目。默认情况下,被禁用的条目无法通过键盘聚焦。你可以使用 disabled-interactive 特性支持 禁用控件的可聚焦性 以提升它们的可发现性。

链接

条目也可以通过 href 特性指定 URL 来表现得像链接。你还可以像原生锚点标签那样指定 target、rel 与 download。

无障碍

导航栏被赋予 ARIA role="navigation",表示该区域充当导航地标,帮助辅助技术将其识别为 站点或应用导航链接的容器。请始终通过 aria-label 或 aria-labelledby 提供 无障碍标签。

条目被赋予 ARIA 角色 button,表示它们是可点击、会触发操作的元素,并使用 aria-current="true" 传达选中状态。

图标插槽带有 aria-hidden="true",以确保图标始终对辅助技术隐藏。

使用 disabled 或 disabled-interactive 特性禁用时,会用 aria-disabled="true" 向辅助技术传达该条目已禁用。如果使用 disabled-interactive 禁用,则保留 tabindex,以传达该条目仍可交互。

指定 href 时,会使用 ARIA 角色 link 而非 button,以传达该条目 提供了指向资源的交互式引用。此外,组件会呈现一个对辅助技术隐藏的内部锚点,用于调用原生浏览器特性, 例如上下文菜单选项与工具提示。

栏切换器使用 aria-controls 将它的父元素与栏关联,并动态更新 aria-expanded 以指示栏是否已展开。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/nav-rail.js"></script>
