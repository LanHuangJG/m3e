Paginator 分页器

m3e-paginator 组件是一个紧凑、无障碍的分页控件,用于浏览分页数据集。它提供语义化的首页/上一页/ 下一页/末页导航控件,以及可选的每页条数选择器。 

import "@m3e/web/paginator";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

至少需要指定要分页的项目总数与每页条数。分别使用 m3e-paginator 组件的 length 与 page-size 特性。默认情况下,page-size 设为 50。

当用户与分页器交互时,它会派发一个 page 事件。该事件可用于更新任何关联的数据视图, 并包含以下属性:

  • pageIndex: number —— 当前页的从零开始的索引。
  • previousPageIndex: number(可选) —— 先前选中页的从零开始的索引。
  • pageSize: number | "all" —— 当前每页条数。
  • length: number —— 要分页的项目总数。
 
<m3e-paginator length="100"></m3e-paginator>
 每页条数

page-sizes 特性让你定义用户可选的每页条数选项。它接受逗号分隔的值列表, 并可以包含 "all"。默认情况下,page-sizes 设为 "5,10,25,50,100"。

当前的 page-size 始终会出现在下拉列表中,即使它未包含在 page-sizes 中。

当 page-size 设为 "all" 时,范围标签与导航操作会被隐藏。 

<m3e-paginator length="100" page-sizes="10,50,all" page-size="all"></m3e-paginator>
 导航操作

默认情况下,首页与末页按钮是隐藏的。使用 show-first-last-buttons 特性来显示它们。 

<m3e-paginator length="100" show-first-last-buttons></m3e-paginator>
 密度

分页器支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size CSS 自定义属性调整其垂直间距。默认密度尺寸为 4dp。分页器支持负密度,最低可到 -3,每一档将视觉高度 减少一个密度单位。内部表单字段接受紧凑密度(-3 与 -2)并忽略更大的值。

下面演示对分页器应用 -3 密度。

 
<m3e-paginator class="density-3" length="100" show-first-last-buttons></m3e-paginator>

.density-3 {
  --md-sys-density-scale: -3;
}
 无障碍

分页器使用 ARIA role="group" 对其子控件进行语义分组。你必须为每个 m3e-paginator 添加 aria-label 或 aria-labelledby 特性, 其标签应描述分页控件所控制的内容。

你可以使用 first-page-label、previous-page-label、next-page-label 与 last-page-label 特性更改导航操作的无障碍标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/paginator.js"></script>
