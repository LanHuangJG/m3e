Progress Indicator 进度指示器

m3e-linear-progress-indicator 与 m3e-circular-progress-indicator 组件 提供无障碍、带过渡动画的进度指示器,用于跟踪任务或流程的完成情况。 

import "@m3e/web/progress-indicator";
 用法

本节提供该模块组件的用法示例与配置指引。

圆形

使用 m3e-circular-progress-indicator 呈现进度的圆形指示器。该组件支持两种模式 (确定与不确定)以及两种外观变体(flat 与 wavy)。使用 variant 属性更改外观。

确定进度

默认情况下,圆形进度指示器是确定的。使用 value 属性指示完成百分比,使用 max 指定总步数或进度单位。此外,你可以在默认插槽中提供内容。

25 25 
<m3e-circular-progress-indicator value="25">25</m3e-circular-progress-indicator>
<m3e-circular-progress-indicator variant="wavy" value="25">25</m3e-circular-progress-indicator>
 不确定进度

使用 indeterminate 属性将模式改为不确定。在此模式下,value 与 max 会被忽略。 

<m3e-circular-progress-indicator indeterminate></m3e-circular-progress-indicator>
<m3e-circular-progress-indicator variant="wavy" indeterminate></m3e-circular-progress-indicator>
 线性

使用 m3e-linear-progress-indicator 呈现用于指示进度与活动的水平条。该组件支持四种模式: determinate(默认)、indeterminate、buffer 与 query。

使用 mode 属性更改模式。与圆形指示器一样,使用 variant 将外观设为 flat(默认)或 wavy。

确定进度

在已知操作完成百分比时使用 determinate 模式。使用 value 属性指示完成百分比, 使用 max 指定总步数或进度单位。这是默认模式。

使用 wavy 变体时,进度达到 100% 后指示器会自动过渡为扁平外观。 


<m3e-linear-progress-indicator value="25"></m3e-linear-progress-indicator>
<m3e-linear-progress-indicator variant="wavy" value="25"></m3e-linear-progress-indicator>
 不确定进度

使用 indeterminate 模式表示某事正在发生,但不传达具体的进度。在此模式下, value 与 max 会被忽略。 


<m3e-linear-progress-indicator mode="indeterminate"></m3e-linear-progress-indicator>
<m3e-linear-progress-indicator variant="wavy" mode="indeterminate"></m3e-linear-progress-indicator>
 Buffer

使用 buffer 模式表示某些活动或来自服务器的加载。在此模式下,value 决定主进度条的进度,而 buffer-value 特性用于显示缓冲进度。

与 determinate 模式一样,使用 wavy 变体时,进度达到 100% 后指示器会自动 过渡为扁平外观。 


<m3e-linear-progress-indicator mode="buffer" value="10" buffer-value="25"></m3e-linear-progress-indicator>
<m3e-linear-progress-indicator variant="wavy" mode="buffer" value="10" buffer-value="25"></m3e-linear-progress-indicator>
 Query

使用 query 模式表示实际加载开始前的预加载。在此模式下,value 与 max 会被忽略。 


<m3e-linear-progress-indicator mode="query"></m3e-linear-progress-indicator>
<m3e-linear-progress-indicator variant="wavy" mode="query"></m3e-linear-progress-indicator>
 无障碍

进度指示器实现 ARIA role="progressbar" 模式。它们把 aria-valuemin 设为 0,把 aria-valuenow 设为 value,把 aria-valuemax 设为 max。

请始终为每个进度指示器通过 aria-label 或 aria-labelledby 提供无障碍标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/progress-indicator.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",

      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",

生产构建请使用压缩版文件,以获得最佳加载性能。
