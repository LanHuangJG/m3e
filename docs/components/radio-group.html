Radio Group 单选组

m3e-radio-group 与 m3e-radio 组件支持在一组互斥选项中做单选。 

import "@m3e/web/radio-group";
 用法

本节提供该模块组件的用法示例与配置指引。

单选组

单选按钮通常放在 m3e-radio-group 内部。

 
<m3e-radio-group>
  <label><m3e-radio value="1"></m3e-radio> Option 1</label>
  <label><m3e-radio value="2"></m3e-radio> Option 2</label>
  <label><m3e-radio value="3"></m3e-radio> Option 3</label>
  <label><m3e-radio value="4"></m3e-radio> Option 4</label>
</m3e-radio-group>
 标签

使用 label 元素为单选按钮关联标签。此外,单选组也可以用 label 标注。 


<label for="radio-group">Select an option</label>
<m3e-radio-group id="radio-group">
  <label><m3e-radio value="1"></m3e-radio> Option 1</label>
  <!-- Additional radios omitted for brevity -->
</m3e-radio-group>
 表单关联

单选按钮作为 表单关联自定义元素 (FACE)参与表单提交,把自身状态贡献到表单数据中。name 特性定义单选按钮的值在表单中提交时所用的键。 当被选中且未禁用时,会提交 value(默认为 "on")。

单选按钮把 disabled 状态视为仅属性控件。运行时禁用时,它不会在 DOM 中 生成 disabled 特性。

使用单选组时,组的 name 会传播到所有嵌套的单选按钮。

禁用

使用 disabled 属性禁用单个单选按钮或整个单选组。关联的标签会自动应用样式以显示禁用状态。

下面的示例演示禁用组中的单个单选按钮。


 
<label for="radio-group">Select an option</label>
<m3e-radio-group id="radio-group">
  <label><m3e-radio disabled value="1"></m3e-radio> Option 1</label>
  <!-- Additional radios omitted for brevity -->
</m3e-radio-group>

下一个示例演示禁用整个组。


 
<label for="radio-group">Select an option</label>
<m3e-radio-group id="radio-group" disabled>
  <label><m3e-radio value="1"></m3e-radio> Option 1</label>
  <!-- Additional radios omitted for brevity -->
</m3e-radio-group>
 必填

使用单选组的 required 属性要求必须选中一个选项。关联的标签会自动应用样式以显示校验状态。

在下面的示例中,按 TAB 进入单选组,再按一次 TAB 不选择任何项离开,即可看到校验如何触发。选中一个单选按钮会重新校验。 


<label for="radio-group">Select an option</label>
<m3e-radio-group id="radio-group" required>
  <label><m3e-radio value="1"></m3e-radio> Option 1</label>
  <!-- Additional radios omitted for brevity -->
</m3e-radio-group>
 密度

单选按钮支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size CSS 自定义属性调整其垂直间距。默认密度尺寸为 4dp。单选按钮支持负密度,最低可到 -3,每一档将视觉高度 减少一个密度单位。无论视觉尺寸如何,单选按钮都保持 48x48dp 的最小触控目标,以确保可靠的无障碍体验。

下面演示对单选按钮应用密度。与每个单选按钮交互,观察密度如何影响其状态层。 

<label>
  <m3e-radio class="density-3"></m3e-radio>
  Density -3
</label>
<!-- Additional radios omitted for brevity -->

.density-3 {
  --md-sys-density-scale: -3;
}
/* Additional classes omitted for brevity */
 无障碍

每个单选组被赋予 role="radiogroup",以表明这是一组相关选项;而单个单选按钮获得 role="radio",表示它们参与了该组。这确保屏幕阅读器能向用户传达正确的上下文与选中状态。

aria-checked 特性反映某个单选按钮当前是否在其组中被选中。当单选按钮被选中时, aria-checked="true" 会暴露给辅助技术;否则为 "false"。

使用 disabled 特性禁用时,会用 aria-disabled="true" 向辅助技术传达 该单选按钮已禁用。运行时禁用时,它不会在 DOM 中生成 disabled 特性。

当单选组被禁用时,aria-disabled 不会应用于组。取而代之的是,通过为每个嵌套的单选按钮 应用 aria-disabled="true" 来反映禁用状态,确保辅助技术正确解读各选项的不可交互状态。

当使用 required 特性把单选组标记为必填时,会对该组应用 aria-required="true"。 这向辅助技术传达该选择是强制的。aria-required="true" 特性不会传播到单个单选按钮, 因为该要求适用于整个组,而非每个选项。

对于没有描述性文本内容的单选按钮与单选组,请始终通过 aria-label 或 aria-labelledby 提供无障碍标签

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/radio-group.js"></script>

此外,你还必须使用一个 import map 来引入依赖。

  {
