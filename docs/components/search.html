Search 搜索框

m3e-search-bar 与 m3e-search-view 组件提供 Material 3 表现力的搜索体验。 搜索栏提供醒目的文本输入入口,而搜索视图以包含式、停靠式或全屏配置呈现建议、历史与结果。 

import "@m3e/web/search";
 用法

本节提供该模块组件的用法示例与配置指引。

Search bar

使用 m3e-search-bar 作为搜索入口。它提供激活搜索的交互提示,但不显示结果。要呈现建议、历史或 结果,请使用 m3e-search-view,它提供完整的搜索体验。

结构解析

m3e-search-bar 暴露以下具名插槽:

  • leading —— 位于栏开头的内容,例如图标或导航提示。
  • input —— 用于捕获搜索文本的 input 元素。
  • trailing —— 对齐到栏末尾的内容,例如头像或溢出菜单。
可清除

使用 clearable 特性控制栏是否显示清除按钮。激活时,该按钮会清空输入并派发一个 clear 事件。

典型用法

下面的示例演示典型用法:带前置图标并可清除当前搜索文本的 m3e-search-bar。 

<m3e-search-bar clearable>
  <m3e-icon name="search" slot="leading"></m3e-icon>
  <input slot="input" placeholder="Search..." />
</m3e-search-bar>
 Search view

使用 m3e-search-view 显示搜索建议与结果。与仅提供入口的 m3e-search-bar 不同, 搜索视图会呈现搜索的结果。

结构解析

m3e-search-view 暴露以下具名插槽:

  • closed-leading —— 视图关闭时,呈现位于输入框之前的内容。
  • closed-trailing —— 视图关闭时,呈现位于输入框之后的内容。
  • open-leading —— 视图打开时,呈现位于输入框之前的内容。
  • open-trailing —— 视图打开时,呈现位于输入框之后的内容。
  • input —— 呈现用于捕获搜索文本的 input 元素。
  • (default) —— 视图打开时,呈现视图的结果内容。
模式

使用 mode 特性控制结果的呈现方式。支持的值包括 fullscreen、 docked(默认)与 auto,后者会根据当前视口断点选择合适的模式。

下面的示例演示默认的 docked 模式。在此模式下,搜索视图呈现为锚定到搜索栏的浮层, 让用户能在周围布局中保持上下文的同时浏览结果。

Result One Result Two Result Three 
<m3e-search-view>
  <input slot="input" placeholder="Search..." />
  <m3e-list>
    <m3e-list-item>Result One</m3e-list-item>
    <m3e-list-item>Result Two</m3e-list-item>
    <m3e-list-item>Result Three</m3e-list-item>
  </m3e-list>
</m3e-search-view>

下一个示例演示 fullscreen 模式。在此模式下,搜索视图占据整个视口,营造沉浸、专注的搜索, 并暂时替换周围的界面。

 加载结果

m3e-search-view 派发一个 query 事件,可用于加载结果。该事件在以下条件下触发:

  • input 获得焦点。可用于加载初始建议。
  • input 的值发生变化。可用于通过事件的 detail.term 属性获取与当前词条匹配的结果。

此外,当用户点击清除按钮时会派发一个 clear 事件。该操作还会先触发 query 事件, 随后是 clear,体现组件的 input → query → clear 事件序列。

隐藏搜索图标

虽然通常都会显示搜索图标,但当搜索视图关闭时,你可以使用 hide-search-icon 特性将其隐藏。

Result One Result Two Result Three 
<m3e-search-view mode="docked" hide-search-icon>
  <input slot="input" placeholder="Search..." />
  <!-- Results omitted for brevity -->
</m3e-search-view>
 无障碍

搜索栏会自动规范化其插槽中的 input,以确保跨浏览器与辅助技术的正确搜索语义。它会应用 role="searchbox"、inputmode="search" 与 type="text"(若尚未指定)。 此外,还会应用 aria-haspopup="dialog",告知辅助技术激活输入框会打开对话框,让屏幕阅读器 能够预判随之而来的上下文变化。

打开时,搜索视图的浮层区域被赋予 ARIA role="dialog",表示它是一个专用的搜索浮层。 该对话框通过 aria-labelledby 由其标题标注,让辅助技术能清晰地播报搜索上下文。 aria-modal="true" 用于表示只能与对话框中的内容交互。

搜索视图不会自动播报动态更新。相反,当搜索结果变化时,你需要负责向专用的 aria-live="polite" 元素发送简短的文本更新。这确保辅助技术能收到有意义的反馈, 而无需重新播报完整的结果列表。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/search.js"></script>
