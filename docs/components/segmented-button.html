Segmented Button 分段按钮

m3e-segmented-button 组件允许用户从一个水平组中选择一个或多个选项。 

import "@m3e/web/segmented-button";
 用法

本节提供该模块组件的用法示例与配置指引。

结构解析

分段按钮使用 m3e-segmented-button 组件定义,它充当一组可交互分段的语义容器。每个分段由 m3e-button-segment 组件表示,允许用户在统一控件中从多个相关选项中进行选择。

8 oz 12 oz 16 oz 20 oz 
<m3e-segmented-button>
  <m3e-button-segment checked>8 oz</m3e-button-segment>
  <!-- Additional segments omitted for brevity -->
</m3e-segmented-button>
 图标

使用 m3e-button-segment 的 icon 插槽在分段标签之前呈现一个图标。

选中后,分段的图标会替换为对勾图标。

Design Accessibility Motion Documentation 
<m3e-segmented-button>
  <m3e-button-segment>
    <m3e-icon slot="icon" name="palette"></m3e-icon>Design
  </m3e-button-segment>
  <!-- Additional segments omitted for brevity -->
</m3e-segmented-button>
 选择

分段按钮同时支持单选与多选模式。使用 m3e-segmented-button 的 multi 特性 允许同时选中多个分段。

使用 checked 特性控制 m3e-button-segment 的选中状态。点击时,会先派发一个 可取消的 beforeinput 事件,随后是 input 与 change 事件。要取消 选择变更,请在 beforeinput 期间调用 preventDefault。

8 oz 12 oz 16 oz 20 oz 
<m3e-segmented-button multi>
  <m3e-button-segment checked>8 oz</m3e-button-segment>
  <m3e-button-segment checked>12 oz</m3e-button-segment>
  <!-- Additional segments omitted for brevity -->
</m3e-segmented-button>
 禁用

使用 disabled 属性禁用单个分段。

Design Accessibility Motion Documentation 
<m3e-segmented-button>
  <m3e-button-segment disabled>
    <m3e-icon slot="icon" name="palette"></m3e-icon>Design
  </m3e-button-segment>
  <!-- Additional segments omitted for brevity -->
</m3e-segmented-button>

你也可以使用 m3e-segmented-button 的 disabled 特性完全禁用该按钮。

Design Accessibility Motion Documentation 
<m3e-segmented-button disabled>
  <m3e-button-segment>
    <m3e-icon slot="icon" name="palette"></m3e-icon>Design
  </m3e-button-segment>
  <!-- Additional segments omitted for brevity -->
</m3e-segmented-button>
 隐藏选择指示器

使用 m3e-segmented-button 的 hide-selection-indicator 特性隐藏选择指示器。 如果某个分段通过 icon 插槽设置了图标,该图标会在选中时保留。

Design Accessibility Motion Documentation 
<m3e-segmented-button hide-selection-indicator>
  <!-- Segments omitted for brevity -->
</m3e-segmented-button>
 表单关联

分段按钮可以作为 表单关联自定义元素 (FACE)参与表单提交,把自身状态贡献到表单数据中。name 特性定义组件的值在表单中提交时所用的键。 按钮的值由选中的分段决定。你可以使用 m3e-button-segment 的 value 控制分段的 值。选中多个分段时,表单数据会包含多个以同一 name 为键的条目。

组件把 disabled 状态(分段按钮自身的)视为仅属性控件。运行时禁用时, 它不会在 DOM 中生成 disabled 特性。

密度

分段按钮支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size CSS 自定义属性调整其垂直间距。默认密度尺寸为 4dp。分段按钮支持负密度,最低可到 -3,每一档将视觉高度 减少一个密度单位。无论视觉尺寸如何,按钮分段都保持 48x48dp 的最小触控目标,以确保可靠的无障碍体验。

下面演示对分段按钮应用密度。

  <!-- Button segments omitted for brevity -->
</m3e-segmented-button>

  --md-sys-density-scale: -3;

 无障碍

单选的分段按钮被赋予 ARIA role="radiogroup",分段被赋予 role="radio"。 对于多选,按钮被赋予 role="group",分段被赋予 role="button"。选中时,分段 的选择状态通过单选的 aria-checked 与多选的 aria-pressed 反映。

对于被禁用的单选分段按钮,aria-disabled 不会应用于按钮。取而代之的是,通过为每个嵌套分段 应用 aria-disabled="true" 来反映禁用状态,确保辅助技术正确解读各选项的不可交互状态。 对于被禁用的多选分段按钮,aria-disabled 会同时应用于按钮以及各个分段。当分段按钮在运行时 被禁用时,它不会在 DOM 中生成 disabled 特性。

请始终为每个分段按钮通过 aria-label 或 aria-labelledby 提供无障碍标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/segmented-button.js"></script>
