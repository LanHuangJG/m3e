Select 下拉选择

m3e-select 组件提供一个表单控件,用于从一组预定义选项中选取值。 

import "@m3e/web/select";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

下面的示例演示 m3e-select 与 m3e-form-field 配合使用。更多信息见 Form Field 表单容器。

要在 m3e-select 中定义可选选项,请包含一个或多个 m3e-option 元素作为其子元素。 每个 m3e-option 可以指定 value 特性,它决定选项被选中时提交的程序化值。 m3e-option 元素的文本内容表示在下拉界面中呈现给用户的标签。

Apples Oranges Bananas Grapes 
<m3e-form-field>
  <label slot="label" for="select">Favorite fruit</label>
  <m3e-select id="select">
    <m3e-option>Apples</m3e-option>
    <m3e-option>Oranges</m3e-option>
    <m3e-option>Bananas</m3e-option>
    <m3e-option>Grapes</m3e-option>
  </m3e-select>
</m3e-form-field>
 空选项

要定义一个空选项,请包含一个没有值或内容的 m3e-option。或者,把 value 特性 设为 "",并加入诸如 "None" 的描述性内容。这表示尚未选择任何有意义的值。空选项通常用于 表示用户交互之前的占位或默认状态。

None Apples Oranges Bananas Grapes 
<m3e-form-field>
  <label slot="label" for="select">Favorite fruit</label>
  <m3e-select id="select">
    <m3e-option value="">None</m3e-option>  
    <m3e-option>Apples</m3e-option>
    <m3e-option>Oranges</m3e-option>
    <m3e-option>Bananas</m3e-option>
    <m3e-option>Grapes</m3e-option>
  </m3e-select>
</m3e-form-field>
 选项组

m3e-optgroup 组件可用于把常见选项归入一个子标题之下。组的名称可以使用 label 插槽设置。

不支持嵌套组——只允许单层分组。

Grass Bulbasaur Oddish Bellsprout Water Squirtle Psyduck Horsea Fire Charmander Vulpix Flareon 
<m3e-form-field>
  <label slot="label" for="select">Pokemon</label>
  <m3e-select id="select">
    <m3e-optgroup>
      <span slot="label">Grass</span>
      <m3e-option>Bulbasaur</m3e-option>
      <m3e-option>Oddish</m3e-option>
      <m3e-option>Bellsprout</m3e-option>
    </m3e-optgroup>
    <!-- Additional option groups omitted for brevity -->
  </m3e-select>
</m3e-form-field>
 选择

下拉选择同时支持单选与多选模式。使用 multi 特性允许同时选中多个选项。

使用 selected 特性控制 m3e-option 的选中状态。点击时, m3e-select 会派发一个可取消的 beforeinput 事件,随后是 input 与 change 事件。要取消选择变更,请在 beforeinput 期间调用 preventDefault。

Extra cheese Mushroom Onion Pepperoni Sausage Tomato 
<m3e-form-field>
  <label slot="label" for="select">Toppings</label>
  <m3e-select id="select" multi>
    <m3e-option selected>Extra cheese</m3e-option>
    <m3e-option selected>Mushroom</m3e-option>
    <!-- Additional option groups omitted for brevity -->
  </m3e-select>
</m3e-form-field>
 禁用

你可以分别通过为 m3e-select 或 m3e-option 应用 disabled 特性来禁用整个下拉选择组件或单个选项。

  <label slot="label" for="select">Favorite fruit</label>
  <m3e-select id="select" disabled>
    <m3e-option selected>Apples</m3e-option>
    <!-- Additional option groups omitted for brevity -->
  </m3e-select>
</m3e-form-field>

 必填

应用 required 特性以强制选择。这确保用户必须至少选择一个选项,该字段才会被视为有效。 对于多选配置,至少选中一个选项即可满足要求。

None Apples Oranges Bananas Grapes 
<m3e-form-field>
  <label slot="label" for="select">Favorite fruit</label>
  <m3e-select id="select" required>
    <m3e-option value="">None</m3e-option>  
    <m3e-option>Apples</m3e-option>
    <!-- Additional option groups omitted for brevity -->
  </m3e-select>
</m3e-form-field>
 密度

表单字段与下拉面板支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size CSS 自定义属性调整其垂直间距。默认密度尺寸为 4dp。两者都支持 负密度,最低可到 -3,每一档将视觉高度减少一个密度单位。

下面演示通过 panel-class 特性对 m3e-form-field 与 m3e-select 的面板同时应用密度。

<m3e-form-field class="density-3">
  <label slot="label" for="select">Density -3</label>
  <m3e-select id="select" panel-class="density-3">
    <!-- Options omitted for brevity -->
  </m3e-select>
</m3e-form-field>
<!-- Additional fields omitted for brevity -->
 
.density-3 {
  --md-sys-density-scale: -3;
}

 无障碍

m3e-select 组件遵循 ARIA combobox 交互模式。下拉选择被赋予 ARIA role="combobox",而下拉面板应用 role="listbox" 向辅助技术传达其结构。

选项被赋予 ARIA role="option",表示每一项都是列表框上下文中的可选项。该角色使辅助技术 能够正确解读并播报选项,支持无障碍导航与选择行为。

选项组被赋予 ARIA role="group",表示这些分组选项在列表框中构成一个语义相关的集合。 该角色帮助辅助技术传达选项之间的结构关系,增强屏幕阅读器用户的可导航性与上下文理解。

aria-selected 特性反映某个选项当前是否被选中。当选项被选中时, aria-selected="true" 会暴露给辅助技术;否则为 "false"。

使用 disabled 特性禁用时,会用 aria-disabled="true" 向辅助技术传达 某个选项或下拉选择已禁用。当 m3e-select 在运行时被禁用时,它不会在 DOM 中生成 disabled 特性。

aria-activedescendant 特性应用于 m3e-select 元素,以指示列表框内当前活动 的选项。下拉选择不会把 DOM 焦点移到每个选项,而是保留焦点并更新 aria-activedescendant 以引用获得焦点选项的 id。这种方式保留了焦点管理, 并使辅助技术能在键盘导航期间播报活动选项,确保交互无障碍且可预测。

aria-owns 与 aria-controls 特性应用于 m3e-select 元素,以建立 与列表框浮层的显式关系。这两个特性都引用列表框容器的 id,确保辅助技术能识别触发器与 受控内容之间的关联。aria-controls 表示下拉选择管控列表框的可见性与行为,而当列表框 渲染在下拉选择的子树之外时,aria-owns 则声明 DOM 归属。

aria-expanded 特性反映列表框浮层的当前状态。当列表框打开时,会在 m3e-select 元素上设置 aria-expanded="true";折叠时设为 false。这种动态状态使屏幕阅读器 能够播报列表框是展开还是折叠,支持无障碍导航与交互。

由于 listbox 是为单项选择设计的,你应避免在 m3e-option 内放置额外的交互式 元素——例如按钮、复选框或开关。在选项中嵌套交互式控件会扰乱预期的导航,并干扰屏幕阅读器的行为。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/select.js"></script>

由于 @m3e/option 是依赖项,你还需要为它引入一个 module 脚本。

<script type="module" src="/node_modules/@m3e/web/dist/option.js"></script>

此外,你还必须使用一个 import map 来引入依赖。
