Skeleton 骨架屏

m3e-skeleton 组件提供一个加载占位界面,具备灵活的形状变体与基于动效的动画,在传达加载状态的同时保持布局稳定。它会在内容仍在加载时模仿其布局,确保在数据获取或渲染延迟期间获得流畅的用户体验。 

import "@m3e/web/skeleton";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

使用 m3e-skeleton 组件为任意顶层插槽元素生成加载占位符。该组件会为每个节点创建一个覆盖形状,匹配其几何形态,同时保留底层内容的布局。

使用 loaded 特性显示已加载的内容。



卡片头部
Card Content
Action
Card Footer
 
<m3e-skeleton>
  <m3e-card>
    <m3e-heading slot="header" variant="display" size="small">Card Header</m3e-heading>
    <div slot="content">Card Content</div>
    <div slot="actions">
      <m3e-button variant="filled">Action</m3e-button>
    </div>
    <div slot="footer">Card Footer</div>
  </m3e-card>
</m3e-skeleton>
 Shape 形状

使用 shape 属性定义应用于所有顶层插槽内容的几何形态。每个节点都会收到一个反映所选形状的对应骨架覆盖层。circular 选项会根据元素尺寸生成圆形。rounded 选项应用大多数界面与控件使用的标准圆角令牌。square 选项不设圆角,呈现锐利边缘。auto 选项读取插槽元素实际的边框圆角并精确镜像,确保骨架无需额外配置即可与卡片、按钮、图像或任意自定义组件对齐。 




<m3e-skeleton shape="circular">
  <div style="width: 100px; height: 100px"></div>
</m3e-skeleton>
<br />
<m3e-skeleton shape="rounded">
  <div style="width: 100px; height: 100px"></div>
</m3e-skeleton>
<br />
<m3e-skeleton shape="square">
  <div style="width: 100px; height: 100px"></div>
</m3e-skeleton>
<br />
<m3e-skeleton shape="auto">
  <div style="width: 100px; height: 100px; border-radius: 16px"></div>
</m3e-skeleton>
动画

使用 animation 属性控制骨架传达加载进度的方式。启用后,组件会在所有顶层插槽内容上应用动效,以表明正在获取数据。wave 选项渲染平滑的方向性扫掠,暗示工作正在进行。pulse 选项应用有节奏的淡入淡出效果,在不产生强烈方向性移动的情况下吸引注意。 




<m3e-skeleton shape="circular" animation="pulse">
  <div style="width: 100px; height: 100px"></div>
</m3e-skeleton>
<!-- Additional skeletons omitted for brevity -->

none 选项禁用动效并显示静态占位符,适用于偏好减少动态效果的环境,或需要安静加载状态的布局。 




<m3e-skeleton shape="circular" animation="none">
  <div style="width: 100px; height: 100px"></div>
</m3e-skeleton>

无障碍

骨架的颜色采用仍能可靠可见的最低感知对比度,使占位符保持微妙且不突兀。

骨架纯属视觉占位符,不应暴露任何语义角色,也不应向辅助技术自我通告。m3e-skeleton 元素保持中性,不应有 role、aria-label、aria-live 或 aria-busy。加载状态应通过给父容器应用 aria-busy="true" 来传达,确保屏幕阅读器理解内容正在加载,且不会被装饰性占位符打断。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/skeleton.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",
      "@lit/reactive-element/": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/",
      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js",
      "@m3e/web/core/anchoring": "/node_modules/@m3e/web/dist/core-anchoring.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
