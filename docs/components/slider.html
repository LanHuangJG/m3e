Slider 滑块

m3e-slider 组件让用户可以从连续或离散范围中选择一个数值。 

import "@m3e/web/slider";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

m3e-slider 允许从范围中选择值,类似 <input type="range">。它需要一个 m3e-slider-thumb,负责渲染可交互的滑块手柄、管理指针与键盘输入,并传达当前值的语义。 

<m3e-slider>
  <m3e-slider-thumb></m3e-slider-thumb>
</m3e-slider>
 选择值

默认情况下,滑块的最小值为 0,最大值为 100,滑块手柄以 1 为增量移动。这些值可以分别通过设置 min、 max 与 step 特性来更改。

除非通过 m3e-slider-thumb 的 value 特性另行指定,否则滑块手柄的值会设为最小值。当通过用户交互更改时,会先发出 beforeinput 事件,随后是 input 与 change 事件。 

<m3e-slider min="1" max="5" step="0.5">
  <m3e-slider-thumb value="1.5"></m3e-slider-thumb>
</m3e-slider>
 选择范围

通过指定两个滑块手柄,可以把 m3e-slider 转换为范围滑块。

 
<m3e-slider>
  <m3e-slider-thumb value="20"></m3e-slider-thumb>
  <m3e-slider-thumb value="80"></m3e-slider-thumb>
</m3e-slider>
 负值范围

将 min 特性设为负值即可支持负值范围。

 
<m3e-slider min="-50">
  <m3e-slider-thumb value="-20"></m3e-slider-thumb>
</m3e-slider>
 方向

默认情况下,滑块为水平方向。使用 orientation 特性可将方向改为 horizontal(默认)或 vertical。 

<m3e-slider orientation="vertical">
  <m3e-slider-thumb value="50"></m3e-slider-thumb>
</m3e-slider>
 尺寸

共有五种尺寸变体,可用于增加或减少强调: extra-small(默认)、small、medium、large 与 extra-large。使用 size 特性控制滑块的大小。 

<m3e-slider size="extra-small">
  <m3e-slider-thumb value="20"></m3e-slider-thumb>
</m3e-slider>
<!-- Additional sizes omitted for brevity -->
 标签

使用 m3e-slider 的 labelled 特性控制是否显示滑块手柄标签。 默认情况下,手柄的值会用作标签文本。你可以把 displayWith 属性设为一个根据给定值返回标签的函数,以此控制标签的格式。 

<m3e-slider labelled>
  <m3e-slider-thumb value="20"></m3e-slider-thumb>
</m3e-slider>
 刻度标记

默认情况下不显示刻度标记。使用 discrete 特性可显示它们。要让刻度标记显示,你还必须指定大于 1 的 step。 

<m3e-slider discrete step="10">
  <m3e-slider-thumb value="20"></m3e-slider-thumb>
</m3e-slider>
 禁用

可以使用 disabled 特性禁用滑块。如果启用了标签,悬停时会显示滑块手柄标签。 

<m3e-slider labelled disabled>
  <m3e-slider-thumb value="20"></m3e-slider-thumb>
</m3e-slider>

虽然不常见,但也可以禁用单个滑块手柄,同时允许另一个手柄保持启用。

 
<m3e-slider labelled>
  <m3e-slider-thumb value="20"></m3e-slider-thumb>
  <m3e-slider-thumb disabled value="80"></m3e-slider-thumb>
</m3e-slider>
 无障碍

滑块不会被赋予 ARIA 角色,这意味着除非被显式引用或标注,否则它们在无障碍树中会被视为中性的、无语义的元素。

滑块手柄会被赋予 ARIA role="slider",表明每个手柄在范围内都作为独立的值选择器运作,并通过 aria-valuemin、 aria-valuemax 与 aria-valuenow 特性传达其当前位置。

禁用时,会使用 aria-disabled 向辅助技术传达手柄虽然存在但被有意设为不可交互。

请始终通过 aria-label 或 aria-labelledby 为每个滑块手柄提供无障碍标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/slider.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
