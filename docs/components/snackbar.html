Snackbar 消息条

@m3e/web/snackbar 模块在 window(globalThis)上提供 M3eSnackbar 全局服务,用于从应用中的任意位置在屏幕底部呈现关于应用进程的简短更新。 

import "@m3e/web/snackbar";
 用法

本节提供该模块组件的用法示例与配置指引。

Snackbar 服务

使用 M3eSnackbar 服务的 open 方法打开消息条。

Delete file 
M3eSnackbar.open("File deleted");
操作

打开消息条消息时,可以包含单个操作与回调。

Delete file 
M3eSnackbar.open("File deleted", "Undo", {
  actionCallback: () => {
    // Undo logic here
  },
});
 关闭方式

消息条消息可以选择性地包含一个关闭按钮。

Delete file 
M3eSnackbar.open("File deleted", true);
 选项

打开消息条消息时,可以传入一个 SnackbarOptions 对象,其中包含以下属性。

  • duration?: number —— 自动关闭消息条前等待的时间长度,单位为毫秒。
  • closeLabel?: string —— 赋予用于关闭消息条的关闭按钮的无障碍标签。
  • actionCallback?: () => void —— 点击操作时调用的回调函数。
无障碍

消息条消息会被赋予 ARIA role="status" 与 aria-live="polite",表明它们是有礼貌的实时区域,旨在无需聚焦即可由辅助技术朗读。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/snackbar.js"></script>

此外,你还必须使用一个 import map 来引入依赖。
