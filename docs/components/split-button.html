Split Button 分裂按钮

The m3e-split-button component presents a primary action alongside a menu of related actions, uniting two buttons in a single expressive surface. 

import "@m3e/web/split-button";
 用法

本节提供该模块组件的用法示例与配置指引。

结构解析

The m3e-split-button exposes two action slots: leading-button for the primary intent, and trailing-button for invoking a menu of secondary options. The leading button executes the main action directly, while the trailing button reveals contextual alternatives via an attached menu.

the的following example illustrates use。m3e-button for the leading button, m3e-icon-button for the trailing button, and m3e-menu for presenting a menu of secondary options.

Edit Rename Copy Delete 
<m3e-split-button>
  <m3e-button slot="leading-button">
    <m3e-icon slot="icon" name="edit"></m3e-icon>Edit
  </m3e-button>
  <m3e-icon-button slot="trailing-button">
    <m3e-icon name="keyboard_arrow_down"></m3e-icon>
    <m3e-menu-trigger for="menu"></m3e-menu-trigger>
  </m3e-icon-button>
</m3e-split-button>
<m3e-menu id="menu" position-x="before">
  <m3e-menu-item>Rename</m3e-menu-item>
  <m3e-menu-item>Copy</m3e-menu-item>
  <m3e-menu-item>Delete</m3e-menu-item>
</m3e-menu>

 密度

Split buttons are density-aware and adjust their vertical spacing based on the --md-sys-density-scale and --md-sys-density-size custom CSS properties. The default density size is 4dp. Buttons and menus support negative density scales down to -3, with each step reducing the visual height by one density unit. Regardless of visual size, buttons maintain a 48x48dp minimum touch target to ensure reliable accessibility.

split 按钮的following illustrates applying -3 密度 to the 按钮s and 菜单。

Edit Rename Copy Delete 
<m3e-split-button size="extra-small" class="density-3">
  <m3e-button slot="leading-button">
    <m3e-icon slot="icon" name="edit"></m3e-icon>Edit
  </m3e-button>
  <m3e-icon-button slot="trailing-button">
    <m3e-icon name="keyboard_arrow_down"></m3e-icon>
    <m3e-menu-trigger for="menu"></m3e-menu-trigger>
  </m3e-icon-button>
</m3e-split-button>

 无障碍

By default, split buttons are given the ARIA role group, indicating a set of related user interface elements that are grouped together.

Always provide an accessible label via aria-label or aria-labelledby for each split button.

原生模块支持

The @m3e/web package uses JavaScript Modules. To use it directly in a browser without a bundler, use a module script similar to the following. 

<script type="module" src="/node_modules/@m3e/web/dist/split-button.js"></script>
