Split Button 分裂按钮

m3e-split-button 组件在呈现一个主要操作的同时,附带一个相关操作菜单,把两个按钮统一在一个富有表现力的界面中。 

import "@m3e/web/split-button";
 用法

本节提供该模块组件的用法示例与配置指引。

结构解析

m3e-split-button 暴露两个操作插槽:leading-button 用于主要意图,trailing-button 用于调用次级选项菜单。前置按钮直接执行主操作,而后置按钮则通过附加菜单展示上下文相关的备选方案。

下面的示例演示了用法:m3e-button 用于前置按钮, m3e-icon-button 用于后置按钮,m3e-menu 用于呈现次级选项菜单。

Edit Rename Copy Delete 
<m3e-split-button>
  <m3e-button slot="leading-button">
    <m3e-icon slot="icon" name="edit"></m3e-icon>Edit
  </m3e-button>
  <m3e-icon-button slot="trailing-button">
    <m3e-icon name="keyboard_arrow_down"></m3e-icon>
    <m3e-menu-trigger for="menu"></m3e-menu-trigger>
  </m3e-icon-button>
</m3e-split-button>
<m3e-menu id="menu" position-x="before">
  <m3e-menu-item>Rename</m3e-menu-item>
  <m3e-menu-item>Copy</m3e-menu-item>
  <m3e-menu-item>Delete</m3e-menu-item>
</m3e-menu>
 变体

分裂按钮有四种外观变体:filled(默认)、tonal、 outlined 与 elevated。使用 variant 特性更改外观。

  </m3e-button>

 密度

分裂按钮会感知密度,并根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整其垂直间距。默认 密度尺寸为 4dp。按钮与菜单支持低至 -3 的负密度比例,每降低一档视觉高度减少一个密度单位。无论视觉尺寸如何,按钮都保持 48x48dp 的最小触摸目标 以确保可靠的无障碍体验。

下面的示例演示了把 -3 密度应用到按钮与菜单。

Edit Rename Copy Delete 
<m3e-split-button size="extra-small" class="density-3">
  <m3e-button slot="leading-button">
    <m3e-icon slot="icon" name="edit"></m3e-icon>Edit
  </m3e-button>
  <m3e-icon-button slot="trailing-button">
    <m3e-icon name="keyboard_arrow_down"></m3e-icon>
    <m3e-menu-trigger for="menu"></m3e-menu-trigger>
  </m3e-icon-button>
</m3e-split-button>

<m3e-menu id="menu" position-x="before" class="density-3">
  <!-- Menu items omitted for brevity -->
</m3e-menu>
 
.density-3 {
  --md-sys-density-scale: -3;
}
 无障碍

默认情况下,分裂按钮会被赋予 ARIA 角色 group,表示一组被归组在一起的相关界面元素。

请始终通过 aria-label 或 aria-labelledby 为每个分裂按钮提供无障碍标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/split-button.js"></script>
