Split Pane 分割面板

m3e-split-pane 组件提供一个受 Material 3 启发的分割视图,带有可移动的拖拽手柄,支持响应式布局组合与精确的面板尺寸调整。它支持键盘交互、自适应方向以及可选的停靠点吸附,以实现一致且无障碍的内容分布。 

import "@m3e/web/split-pane";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

m3e-split-pane 暴露两个插槽:start,在布局的逻辑起始侧渲染内容;以及 end,在逻辑结束侧渲染内容。value 特性控制起始面板占用可用空间的百分比,结束面板会自动填充剩余部分。默认情况下,value 为 50%。当用户交互导致 value 变化时,会发出一个可取消的 beforeinput 事件,随后是 input 与 change 事件。这让你既能响应实时调整大小,也能在用户结束与拖拽手柄的交互时提交最终调整。 

<m3e-split-pane value="50">
  <m3e-card slot="start"></m3e-card>
  <m3e-card slot="end"></m3e-card>
</m3e-split-pane>
 方向

m3e-split-pane 支持三种方向:horizontal(默认)、 vertical 与 auto。使用 auto 时,方向是响应式的,由视口尺寸决定。使用 orientation 特性更改方向。 

<m3e-split-pane value="50" orientation="vertical">
  <m3e-card slot="start"></m3e-card>
  <m3e-card slot="end"></m3e-card>
</m3e-split-pane>
 最小与最大尺寸

使用 min 与 max 特性控制起始面板可占用的最小与最大百分比。 

<m3e-split-pane value="50" min="25" max="75">
  <m3e-card slot="start"></m3e-card>
  <m3e-card slot="end"></m3e-card>
</m3e-split-pane>
 步长

使用 step 特性控制每次键盘调整大小操作(例如按下方向键)时分割面板的 value 变化多少。 

<m3e-split-pane value="50" step="10">
  <m3e-card slot="start"></m3e-card>
  <m3e-card slot="end"></m3e-card>
</m3e-split-pane>
 停靠点

使用 detents 特性定义分割面板在调整大小期间可以吸附到的位置。分割面板可以没有停靠点、只有一个停靠点,或具有多个停靠点。停靠点会影响面板如何调整大小、如何响应拖拽手势,以及拖拽手柄在键盘交互中的行为。存在停靠点时,拖拽手柄会在用户移动它时吸附到最近的停靠点,并忽略 step;未定义停靠点时,分割面板自由调整大小,不进行吸附。

双击拖拽手柄,或在其获得焦点时按下 ENTER 或 SPACE,会切换到下一个停靠点。使用 wrap-detents 特性可让切换在到达最后一个停靠点后回绕到第一个。 

<m3e-split-pane value="50" detents="0 25 50 75 100"  wrap-detents>
  <m3e-card slot="start"></m3e-card>
  <m3e-card slot="end"></m3e-card>
</m3e-split-pane>
 禁用

使用 disabled 特性禁用调整大小。禁用时,拖拽手柄会从交互中隐藏,指针与键盘输入被忽略,分割面板保持固定在当前值。 

<m3e-split-pane value="50" disabled>
  <m3e-card slot="start"></m3e-card>
  <m3e-card slot="end"></m3e-card>
</m3e-split-pane>
 条件渲染

你可以通过从对应插槽中省略内容,或对插槽元素应用 hidden 特性,来有条件地渲染起始或结束面板。当某个插槽中所有已分配的元素都被隐藏时,分割面板会把该侧视为空,并更新布局,使可见面板完全占用可用空间,而不修改当前的 value。 

<m3e-split-pane value="50">
  <m3e-card slot="start"></m3e-card>
  <m3e-card slot="end" hidden></m3e-card>
</m3e-split-pane>
 嵌套面板

分割面板可以嵌套以创建复杂布局,让你可以通过组合多个二元分割来构建多面板工作区。 

<m3e-split-pane value="25" class="complex">
  <m3e-card slot="start"></m3e-card>
  <m3e-split-pane slot="end" value="50" orientation="vertical">
    <m3e-card slot="start"></m3e-card>
    <m3e-card slot="end"></m3e-card>
  </m3e-split-pane>
</m3e-split-pane>
 表单关联

该组件作为 表单关联自定义元素 (FACE)参与表单提交,把其状态贡献给表单数据。name 特性定义组件值在表单中提交时所用的键。未禁用时,会提交当前的 value。

该组件把 disabled 状态视为仅属性控件。在运行时禁用时,它不会把 disabled 特性写入 DOM。

无障碍

分割面板使用 ARIA role="separator",表明拖拽手柄是用于调整两个区域相对大小的可交互控件。

拖拽手柄使用 aria-controls 引用它所调整大小的面板。起始面板被包裹在一个具有稳定 ID 的内部容器元素中,拖拽手柄的 aria-controls 特性指向该容器。这让辅助技术能够理解用户调整分割面板时受影响的是哪个区域。

分割面板支持 label 特性,它直接映射到拖拽手柄的 aria-label。这让你可以为屏幕阅读器用户提供清晰、描述性的名称,例如 “Resize panels”或“Adjust split view”。

该组件通过标准 ARIA 特性暴露其方向、当前位置与尺寸约束,使辅助技术能够准确地向用户传达布局。这些特性让屏幕阅读器能够朗读分割面板的排列方式、拖拽手柄已移动的距离,以及允许的移动范围。

  • aria-orientation 传达面板是水平还是垂直排列, 帮助用户理解拖拽手柄可移动的空间方向。
  • aria-valuenow 以百分比报告拖拽手柄的当前位置,让屏幕 阅读器能够朗读起始面板的精确大小。
  • aria-valuemin 与 aria-valuemax 定义允许的最小与最大尺寸, 确保用户了解完整的移动范围以及是否还能进一步调整。
  • aria-valuetext 提供当前尺寸的人类可读描述(例如“Left pane 20%, right pane 80%”或“Top pane collapsed”),提升屏幕阅读器用户的清晰度。你可以 通过提供 valueFormatter 函数自定义此文本,从而完全控制如何 描述尺寸。这对本地化或呈现替代格式很有用。
原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/split-pane.js"></script>
