Switch 开关

m3e-switch 组件是一个可通过点击切换的开/关控件。

import "@m3e/web/switch";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

使用 m3e-switch 组件创建开关(也称为滑动开关)。使用 checked 特性表示开关是否处于“开”状态。点击时会先发出一个可取消的 beforeinput 事件,随后发出 input 与 change 事件。要 取消选中状态的变更,请在 beforeinput 期间调用 preventDefault。 

<m3e-switch checked></m3e-switch>
 标签

使用 label 元素为开关关联一个标签。

 
<label><m3e-switch></m3e-switch> Switch 1</label>
<m3e-switch id="switch2"></m3e-switch>
<label for="switch2"> Switch 2</label>
 图标

你可以用 icons 特性控制要显示的图标。支持的值包括 none(默认)、selected 与 both。 

<m3e-switch icons="selected" checked></m3e-switch>
<m3e-switch icons="both"></m3e-switch>
 表单关联

该组件作为 表单关联自定义元素 (FACE)参与表单提交,并把自身状态贡献到表单数据中。name 特性定义组件值在表单中提交时所用的键。处于选中且未禁用时,会提交 value(默认值为 "on")。

该组件将 disabled 状态视为仅属性控件。在 运行时禁用时,它不会向 DOM 中生成 disabled 特性。

禁用

使用 disabled 特性禁用开关。关联的标签会自动应用样式以 显示为禁用状态。 

<label><m3e-switch disabled></m3e-switch>Disabled Switch 1</label>
<m3e-switch id="chk3" disabled></m3e-switch>
<label for="chk3">Disabled Switch 2</label>
 密度

开关支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整自身垂直间距。默认 密度大小为 4dp。开关支持最低至 -3 的负密度比例,每降低一档,视觉 高度减少一个密度单位。无论视觉尺寸如何,开关都保持 48x48dp 的最小触摸目标,以 确保可靠的无障碍体验。

以下演示如何为开关应用密度。

 
<m3e-switch class="density-3"></m3e-switch>
<!-- Additional switches omitted for brevity -->
 
.density-3 {
  --md-sys-density-scale: -3;
}
/* Additional classes omitted for brevity */
 无障碍

开关被赋予 ARIA role="switch",与其作为二元状态切换的语义用途一致。该角色向辅助技术表明:该组件表示一个双状态控件,类似复选框,但拥有不同的交互模型。

该组件通过 aria-checked 特性管理与反映自身状态,其中 aria-checked="true" 表示开关已选中(开), aria-checked="false" 表示未选中(关)。

使用 disabled 特性禁用时,会用 aria-disabled="true" 向辅助技术传达 开关已禁用。在运行时禁用时,它不会向 DOM 中生成 disabled 特性。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/switch.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {

生产构建请使用压缩版文件,以获得最佳加载性能。
