Tabs 标签页

m3e-tabs 组件提供一个结构化的导航界面,用于把内容组织为多个不同的视图,同一时间只显示其中一个视图。 

import "@m3e/web/tabs";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

使用 m3e-tabs、m3e-tab 与 m3e-tab-panel 构建标签页视图。 m3e-tab 与 m3e-tab-panel 都必须是 m3e-tabs 的直接子元素。要 把标签与其对应的面板关联,请把 m3e-tab 上的 for 特性设为 目标 m3e-tab-panel 的 ID。

要选中某个标签,请为单个 m3e-tab 应用 selected 特性。激活标签时 会先发出一个可取消的 beforeinput 事件,随后发出 input 与 change 事件。要取消选择变更,请在 beforeinput 期间调用 preventDefault。同一时间只能选中一个标签。

标签的文本由其内容指定。你可以使用 icon 插槽在标签 文本之前渲染一个图标。

Video Photos Audio Videos Photos Audio 
<m3e-tabs>
  <m3e-tab selected for="videos">
    <m3e-icon slot="icon" name="videocam"></m3e-icon>Video
  </m3e-tab>
  <m3e-tab for="photos">
    <m3e-icon slot="icon" name="photo"></m3e-icon>Photos
  </m3e-tab>
  <m3e-tab for="audio">
    <m3e-icon slot="icon" name="music_note"></m3e-icon>Audio
  </m3e-tab>
  <m3e-tab-panel id="videos">Videos</m3e-tab-panel>
  <m3e-tab-panel id="photos">Photos</m3e-tab-panel>
  <m3e-tab-panel id="audio">Audio</m3e-tab-panel>
</m3e-tabs>
 变体

标签页有两种外观变体:primary 与 secondary(默认)。使用 m3e-tabs 的 variant 特性更改外观。

 标题栏位置

标签的标题栏可定位在面板的 before(默认)或 after 侧。使用 header-position 特性更改标题栏位置。

</m3e-tabs>

 分页

默认情况下,当标签数量超出可用的水平空间时,会出现方向性的分页控件。你可以使用 disable-pagination 特性禁用它。把它设为 auto 可在触摸设备上禁用分页控件。

密度

标签页支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整自身垂直间距。默认 密度大小为 4dp。标签页支持最低至 -3 的负密度比例,每降低一档,视觉 高度减少一个密度单位。

以下演示如何对标签页应用 -3 密度。

Video Photos Audio 
<m3e-tabs class="density-3">
  <!-- Tabs omitted for brevity -->
</m3e-tabs>
 
.density-3 {
  --md-sys-density-scale: -3;
}
 无障碍

标签页实现了 ARIA Tabs 设计模式,由 tablist、tab 与 tabpanel 角色构成。该模式支持 键盘导航、焦点管理,以及标签与其关联面板之间的无障碍关系。

m3e-tabs 组件承载一个嵌套在分页控件内部的 tablist。它包含每个 m3e-tab,并为其赋予 ARIA role="tab"。 对应的 m3e-tab-panel 元素被赋予 ARIA role="tabpanel"。每个标签通过 aria-controls 链接到其关联面板,aria-selected 特性 向辅助技术传达标签的选中状态。标签被禁用时, aria-disabled="true" 传达其非活动状态。

分页按钮被有意排除在 Tab 键顺序之外,且不支持强焦点指示器。 这能减少焦点噪音并简化键盘导航。

使用 previous-page-label 与 next-page-label 特性为分页按钮提供无障碍 标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/tabs.js"></script>
