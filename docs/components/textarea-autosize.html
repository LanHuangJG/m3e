Textarea Autosize 自适应文本域

m3e-textarea-autosize 组件会自动调整所关联 textarea 的高度以适配其内容,从而保持布局完整性与用户体验。这个非可视 元素监听输入变化并应用动态调整大小,并受可选的行数上限约束。 

import "@m3e/web/textarea-autosize";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

使用 m3e-textarea-autosize 组件可以让 textarea 自动调整大小以 适配其内容。使用 for 特性指定要自动调整大小的 textarea。以下 示例演示如何将 m3e-textarea-autosize 与 m3e-form-field 一起使用。更多信息请参阅 Form Field 表单容器。 

<m3e-form-field variant="filled">
  <label slot="label" for="field">Textarea Autosize</label>
  <textarea id="field">
    <!-- Content omitted for brevity -->
  </textarea>
</m3e-form-field>
<m3e-textarea-autosize for="field"></m3e-textarea-autosize>
 最小与最大行数

使用 min-rows 与 max-rows 特性控制 textarea 的最小与最大行数。 

<m3e-form-field variant="filled">
  <label slot="label" for="field">Textarea Autosize</label>
  <textarea id="field">
    <!-- Content omitted for brevity -->
  </textarea>
</m3e-form-field>
<m3e-textarea-autosize for="field" max-rows="5"></m3e-textarea-autosize>
 禁用

使用 disabled 属性禁用自动调整大小。

<m3e-textarea-autosize for="field" disabled></m3e-textarea-autosize>
 无障碍

该组件被赋予 ARIA role="none",表示该元素仅用于呈现,应被 辅助技术忽略。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/textarea-autosize.js"></script>

此外,你还必须使用一个 import map 来引入依赖。
