Theme 主题

m3e-theme 组件是一个非可视元素,用于向嵌套的、感知主题的元素应用动态颜色、表现力动效、 密度与强焦点指示器。 

import "@m3e/web/theme";
 用法

本节提供该模块组件的用法示例与配置指引。

配色方案

主题支持三种配色方案:light、dark 与 auto(默认)。 使用 scheme 特性指定配色方案。

使用 auto 时,主题会通过监听媒体 查询 (prefers-color-scheme: light) 与 (prefers-color-scheme: dark) 动态响应系统偏好, 根据用户环境选择合适的配色方案。

密度

使用 density 特性控制主题内各感知密度的组件的布局紧凑程度。 它会调整间距、内边距与尺寸,以获得更紧凑或更宽松的视觉节奏。

  • 有效值: -3(最紧凑)到 +1(最宽松)
  • 默认值: 0
  • 作用范围: 全局应用于主题内的所有组件

当主题以某个 density 值初始化时,会把系统令牌 --md-sys-density-scale 设为该值。感知密度的组件会使用此令牌 调整其内部布局度量。

  • 紧凑密度会减少垂直内边距与组件高度
  • 宽松密度会增大间距,以获得更舒缓的布局
  • 触摸目标仍可访问,并符合最小尺寸准则

以下示例演示 m3e-button 如何响应主题级密度调整。图中 展示了一个中等尺寸按钮,它支持的最低密度为 -2。请注意,对于该尺寸,密度 -3 与 -2 产生相同的布局行为,因为低于 支持阈值的值会被钳制为 -2。

动效

主题支持两种动效方案:standard(默认)与 expressive。这些方案 定义组件在整个系统中的动画方式,使用基于弹簧的物理效果来引导空间与效果 过渡。使用 motion 特性控制动效方案。

以下示例演示 m3e-switch 如何适应动效方案。点击表现力 示例时,请注意其弹簧效果。 

<m3e-theme motion="standard">
  <!-- Switch omitted for brevity -->
</m3e-theme>
<m3e-theme motion="expressive">
  <!-- Switch omitted for brevity -->
</m3e-theme>
无障碍

默认情况下,主题不会被赋予 ARIA 角色,表示除非被显式引用或标注,否则在无障碍树中 它们被视为中性的非语义元素。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/theme.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",

</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
