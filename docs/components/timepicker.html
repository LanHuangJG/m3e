Timepicker 时间选择器

m3e-timepicker 组件提供一个临时界面,用于通过表盘与 键盘模式选择时间。它支持 12 小时与 24 小时格式下的时、分选择,强制最小与 最大约束,并能根据可用空间在停靠与模态布局之间自适应。 

import "@m3e/web/timepicker";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

使用 m3e-timepicker-toggle 打开 m3e-timepicker。该组件应 嵌套在一个可点击元素内部,并把 for 特性设为要打开的选择器的 id 来建立关联。

HH:MM 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Time Field</label>
  <input autocomplete="off" id="field" />
  <m3e-icon-button slot="suffix">
    <m3e-icon name="schedule"></m3e-icon>
    <m3e-timepicker-toggle for="timepicker"></m3e-timepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">HH:MM</span>
</m3e-form-field>
<m3e-timepicker id="timepicker" variant="auto"></m3e-timepicker>
Time input

m3e-date-input 在配置 type="time" 时也可提供一个分段式时间输入框。它可直接与 m3e-timepicker 集成,当你想要内建的解析、格式化与精确的分段编辑时,可以用它替代 标准 input。

本页示例使用标准 input 来演示完整的 m3e-timepicker API。使用 m3e-date-input 搭配 type="time" 时,其中 许多属性并非必需,因为输入框会自行管理取值,选择器只需把选中的 时间写回字段。

详细信息请参阅 Date Input 日期输入。

HH:MM 
<m3e-form-field variant="outlined">
  <label slot="label" for="field">Time Picker</label>
  <m3e-date-input id="field" type="time"></m3e-date-input>
  <m3e-icon-button aria-label="Open time picker" slot="suffix">
    <m3e-icon name="schedule"></m3e-icon>
    <m3e-timepicker-toggle for="timepicker"></m3e-timepicker-toggle>
  </m3e-icon-button>
  <span slot="hint">HH:MM</span>
</m3e-form-field>
<m3e-timepicker id="timepicker" for="field"></m3e-timepicker>
 变体

m3e-timepicker 支持三种外观变体:docked(默认)、 modal 与 auto。使用 variant 属性控制选择器的 呈现方式。设为 auto 时,会根据当前屏幕尺寸 自动选择合适的呈现方式。

本页所有示例均使用 variant="auto"。

<m3e-timepicker variant="auto"></m3e-timepicker>
 方向

m3e-timepicker 支持三种方向:vertical(默认)、 horizontal 与 auto。使用 orientation 属性控制 选择器的方向。设为 auto 时,会根据当前屏幕尺寸自动选择 合适的方向。

通常,orientation="auto" 应与 variant="auto" 搭配使用,这样选择器 就能根据视口约束在方向与变体之间切换。

HH:MM 
<m3e-timepicker variant="auto" orientation="horizontal"></m3e-timepicker>
模式

m3e-timepicker 支持两种模式:dial(默认)与 input。使用 mode 属性设置默认模式。使用 hide-mode-toggle 属性 隐藏用于在模式之间切换的按钮。

以下示例演示如何使用 mode="input" 与 hide-mode-toggle 强制时间选择器以键盘输入模式打开,同时阻止用户切回表盘。

HH:MM 
<m3e-timepicker mode="input" hide-mode-toggle></m3e-timepicker>
 时间选择

使用 date 属性设置当前选中的时间。

只要选择器持有一个完整、有效的时间,确定按钮就会启用,包括 初始值本就有效且用户未作更改的情况。时与分字段都必须包含 有效、非空的值,选择器才能构造出时间;不完整或无效的状态会让确定按钮 保持禁用。点击确定会把当前时间提交到 date,并发出 change 事件。若 date 为 null,则使用今天的日期。

点击取消会关闭选择器且不提交任何值。当前的 date 与时间 保持不变,也不会发出 change 事件。无论选择是否完整、有效或被修改过,取消 始终是不提交的操作。

HH:MM 
<!-- Form field omitted for brevity -->
<m3e-timepicker id="timepicker" date="2026-07-13T23:30:00Z"></m3e-datepicker>
 
const picker = document.querySelector("#timepicker");
const field = document.querySelector("#field");
field.value = toLocaleTimeString(picker.date);
picker.addEventListener("change", () => {
  field.value = toLocaleTimeString(picker.date);
});
 日期字符串处理

不同浏览器对日期字符串的解析并不一致,尤其是那些形似 ISO 日期但不含时间或时区的字符串。为了在各种环境下都有可预期的行为, m3e-timepicker 采用一套一致、贴合标准的解析模型,而不依赖 浏览器内置的 Date.parse() 规则。

当 m3e-timepicker 收到日期字符串时,会自动判断该值是否匹配 以下可安全、无歧义解析的 ISO-8601 格式之一:

  • yyyy-MM-dd —— 本地日期(不含时间与时区)
  • yyyy-MM-ddTHH:mm:ss —— 本地日期与时间
  • yyyy-MM-ddTHH:mm:ssZ —— UTC 日期与时间
  • yyyy-MM-ddTHH:mm:ss±HH:mm —— 带明确时区偏移的日期与时间

符合上述格式的字符串会被转换为本地 Date 对象,不会出现意外的时区 偏移。这样可以避免“仅日期的值被按 UTC 解析后漂移到前一天或后一天”之类的问题。如果字符串不符合这些 ISO 兼容模式,解析可能不明确或 不受支持。为获得最可靠的结果,请使用上面列出的格式。

小时格式

format 属性控制时间选择器使用的小时周期。它接受 "12"(默认)、"24" 或 "auto"。

  • "12" —— 强制使用带 AM/PM 的 12 小时制。
  • "24" —— 强制使用不带 AM/PM 的 24 小时制。
  • "auto" —— 根据用户区域设置选择 12 小时制或 24 小时制。

以下示例演示不带 AM/PM 的 24 小时制。

HH:MM 
<m3e-timepicker format="24"></m3e-timepicker>
 最小与最大时间

使用 min-time 与 max-time 属性禁用选择器中早于/晚于对应值的 全部时间。

HH:MM 
<m3e-timepicker min-time="8:15 AM"  max-time="5:30 PM"></m3e-timepicker>
 禁用时段

除 min-time 与 max-time 约束外, blackoutTimes 属性还允许你提供一个函数,用于判断某个时间是否被 禁用、无法被选择。该函数接收一个 TimeParts 对象,其中包含 所评估时间的 hour、minute 与 second 值。

HH:MM 
document.querySelector("#blackout-times").blackoutTimes = (t) => t.hour < 8 || t.hour > 18;
 秒

使用 show-seconds 属性在时间选择器中显示秒分段。

HH:MM:SS 
<m3e-timepicker show-seconds></m3e-timepicker>
 按需单独使用

该包还包含 m3e-timepicker-input 与 m3e-timepicker-dial 组件, 允许你在自定义布局中使用它们,或独立于 m3e-timepicker 使用。

m3e-timepicker-input 上可以使用 for 属性,以按 ID 引用一个 m3e-timepicker-dial。使用该属性时,输入框会自动把其属性同步到 所引用的表盘,让两个组件保持同步,无需手动接线事件。

hour = , minute = 
<m3e-timepicker-input id="input" for="dial"></m3e-timepicker-input>
<m3e-timepicker-dial id="dial"></m3e-timepicker-dial>
<span id="inputValue"></span>

document.querySelector("#input").addEventListener("change", (e) => {
  const picker = e.target;
  document.querySelector("#inputValue").innerText =
    `hour = ${picker.hour ?? ""}, minute = ${picker.minute ?? ""}`;
});
无障碍

时间选择器被赋予 ARIA role="dialog",以把这个选择界面标识为打开于页面之上、需要用户关注的一个独立交互 区域。当选择器以模态变体显示时, 还会设置 aria-modal="true",表明页面其余部分处于惰性状态,焦点被 圈定在对话框内直至关闭。停靠模式下则完全省略 aria-modal,因为周边页面仍可交互,此时的界面表现为 锚定浮层而非阻断式对话框。

时间选择器开关会在其父元素上添加 aria-haspopup="dialog",告知辅助 技术:激活该控件将打开一个对话框。

原生模块支持
