TOC 目录

m3e-toc 组件用于生成层级式目录,供页内导航使用。

import "@m3e/web/toc";
 用法

本节提供该模块组件的用法示例与配置指引。

生成目录

m3e-toc 组件会扫描指定容器内的标题元素 (h1 到 h6,以及 m3e-hading),自动生成目录。它会 创建一个可导航的大纲,反映文档结构,使用户能快速在各节之间跳转。

要启用,请把 for 特性设为需要索引其标题的容器的 ID。 生成的目录会随着标题的添加、移除或重新排序而响应式更新。

带有 m3e-toc-ignore 特性的标题会被目录生成器忽略。这 通常用于页面级标题,其文本与目录的标题重复。 

<div id="d1">
  <m3e-toc for="d1">
    <span slot="overline">Overline</span>
    <span slot="title">Title</span>
  </m3e-toc>
  <div>
    <h2 id="h1">Heading 1</h2>
    <h3 id="h1.1">Heading 1.1</h3>
    <h4 id="h1.1.1">Heading 1.1.1</h4>
    <h3 id="h2">Heading 1.2</h3>
    <h2 id="h2.1">Heading 2</h2>
  </div>
</div>
 Heading 标题

使用 overline 与 title 插槽为目录提供标题内容。overline 限制为单行,title 限制为两行。若内容溢出,会被截断 并以省略号表示。 

<m3e-toc for="d1">
    <span slot="overline">Overline</span>
    <span slot="title">Title</span>
  </m3e-toc>
 最大深度

生成目录时,你可以使用 max-depth 特性控制目录中出现标题的最大深度。默认最大深度为 2。

标题深度由容器内找到的最高层级标题决定。例如,若 不存在 h1 但存在 h2,则深度从第 2 级开始。

无障碍

m3e-toc 组件带有 role="navigation" 标记,以表明其 作为导航地标的用途。

为确保辅助技术能有意义地朗读,目录应通过 aria-labelledby 同时使用 overline 与 title 进行标注。这种双重标注方式保留了富有表现力的层级——其中 overline 提供上下文框架(如“本页目录”),title 传达具体内容。

各个条目组织在一个无序列表中,并被赋予 ARIA role="link",以 向辅助技术传达其可交互性。每个条目还会获得 tabindex="-1",使其 可通过编程聚焦,而不被纳入默认的 Tab 键顺序。

活动条目会获得 aria-current="true",以表明其在文档 上下文中的当前状态。该特性有助于辅助技术传达所链接的章节当前正处于视图中, 从而提升屏幕阅读器用户的方位感与导航清晰度。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/toc.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",
      "@lit/reactive-element/": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/",
      "@m3e/web/core": "/node_modules/@m3e/web/dist/core.js",
      "@m3e/web/core/a11y": "/node_modules/@m3e/web/dist/core-a11y.js"
    }
  }
</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
