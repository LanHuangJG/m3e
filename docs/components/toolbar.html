Toolbar 工具栏

m3e-toolbar 组件用于呈现上下文操作、导航与控件。

import "@m3e/web/toolbar";
 用法

本节提供该模块组件的用法示例与配置指引。

变体

工具栏有两种外观变体:standard(默认)与 vibrant。使用 variant 特性更改外观。 

<m3e-toolbar variant="standard">
  <m3e-icon-button>
    <m3e-icon name="arrow_back"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button>
    <m3e-icon name="arrow_forward"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button width="wide" variant="filled">
    <m3e-icon name="add"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button>
    <m3e-icon name="picture_in_picture"></m3e-icon>
  </m3e-icon-button>
  <m3e-icon-button>
    <m3e-icon name="more_vert"></m3e-icon>
  </m3e-icon-button>
</m3e-toolbar>
<m3e-toolbar variant="vibrant">
  <!-- Content omitted for brevity -->
</m3e-toolbar>
 形状

有两种形状变体:square(默认)与 rounded。使用 shape 特性更改外观。 

<m3e-toolbar variant="vibrant" shape="rounded">
  <!-- Content omitted for brevity -->
</m3e-toolbar>
 海拔

使用 elevated 特性把工具栏提升为视觉上醒目的表面,使其有别于周围 布局,并传达其重要性或活动上下文。 

<m3e-toolbar variant="vibrant" shape="rounded" elevated>
  <!-- Content omitted for brevity -->
</m3e-toolbar>
 方向

默认情况下,工具栏为水平方向。使用 vertical 特性把工具栏设为 垂直方向,使其交互元素从上到下堆叠,而非从左到右。这对于 侧边面板、紧凑布局,或垂直对齐能提升清晰度与无障碍性的场景很有用。 

<m3e-toolbar variant="vibrant" shape="rounded" vertical>
  <!-- Content omitted for brevity -->
</m3e-toolbar>
 密度

工具栏支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整自身垂直间距。默认 密度大小为 4dp。工具栏支持最低至 -3 的负密度比例,每降低一档,视觉 高度减少一个密度单位。

以下演示如何对工具栏应用 -3 密度。

 
<m3e-toolbar class="density-3">
  <!-- Content omitted for brevity -->
</m3e-toolbar>
 
.density-3 {
  --md-sys-density-scale: -3;
}
 无障碍

工具栏被赋予 ARIA role="toolbar",表示该元素是一组交互控件 (通常是按钮)的容器,这些控件执行与共同上下文相关的操作。该角色 有助于辅助技术理解其中控件的分组与用途,从而提升导航性 与可发现性。

垂直方向的工具栏会被赋予 aria-orientation="vertical",以明确 向辅助技术传达其布局方向,从而提升依赖屏幕阅读器或键盘交互的用户的 导航与空间理解。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/toolbar.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",

      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "lit-html/directives/class-map.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/class-map.js",

生产构建请使用压缩版文件,以获得最佳加载性能。
