Tooltip 工具提示

@m3e/web/tooltip 模块提供普通与丰富两种工具提示组件,用于传递上下文 指引,从简单的悬停描述到锚定在控件上的多行、富有表现力的内容。 

import "@m3e/web/tooltip";
 用法

本节提供该模块组件的用法示例与配置指引。

Plain tooltip

使用 m3e-tooltip 组件定义普通工具提示,并应用 for 特性 把它与特定的界面元素关联。

Go Back 
<m3e-icon-button id="button">
  <m3e-icon name="arrow_back"></m3e-icon>
</m3e-icon-button>
<m3e-tooltip for="button">Go Back</m3e-tooltip>
 定位

默认情况下,工具提示定位在元素下方。你可以使用 position 特性控制工具提示的位置。支持的值包括 above、below(默认)、 before 与 after。before 与 after 位置可感知 BIDI,会自适应从左到右与从右到左的文本方向。

延迟

使用 show-delay 与 hide-delay 特性控制显示或隐藏工具提示的时间(以 毫秒计)。以下代码片段展示了默认延迟。 

<m3e-icon-button id="button">
  <m3e-icon name="arrow_back"></m3e-icon>
</m3e-icon-button>
<m3e-tooltip for="button" show-delay="0" hide-delay="200">Go Back</m3e-tooltip>
 禁用

使用 disabled 特性禁止工具提示显示。

<m3e-icon-button id="button">
  <m3e-icon name="arrow_back"></m3e-icon>
</m3e-icon-button>
<m3e-tooltip for="button" disabled>Go Back</m3e-tooltip>
 触摸手势

在触摸设备上,工具提示使用长按手势来显示与隐藏。这可能会与浏览器的原生 手势(如文本选择或拖拽交互)冲突。为缓解此问题,工具提示默认在 触发元素上禁用原生手势。然而,对于输入框 或可拖拽组件等特定元素,这种行为可能并不理想。

使用 touch-gestures 特性指定如何处理触摸交互:

  • auto —— 为所有元素启用触摸手势,同时保留 输入框、文本域与可拖拽元素上的浏览器原生行为。
  • on —— 普遍启用触摸手势,并无例外地禁用 所有浏览器原生手势。
  • off —— 完全禁用触摸手势,让工具提示无法在触摸设备上出现。
Rich tooltip

使用 m3e-rich-tooltip 组件定义丰富工具提示,并应用 for 特性把它与特定的界面元素关联。subhead 插槽指定 副标题内容,默认插槽指定补充文本。

New settings available Now you can adjust the uploaded image quality, and upgrade your available storage space. 
<m3e-icon-button id="button">
  <m3e-icon name="settings"></m3e-icon>
</m3e-icon-button>
<m3e-rich-tooltip for="button">
  <span slot="subhead">New settings available</span>
  Now you can adjust the uploaded image quality, and upgrade your available storage space.
</m3e-rich-tooltip>
 操作

在丰富工具提示中包含交互内容会使其升级为类似对话框的行为。该界面变为 可关闭且可通过键盘导航,并且必须通过用户在触发元素上的显式操作才能打开。

你可以使用 actions 插槽在丰富工具提示中包含操作。此外,使用 嵌套在可点击元素中的 m3e-rich-tooltip-action 组件来关闭工具提示。默认 情况下,焦点会返回触发元素。使用 m3e-rich-tooltip-action 的 disable-restore-focus 特性禁用此行为。

New settings available Now you can adjust the uploaded image quality, and upgrade your available storage space.
Learn more 
<m3e-icon-button id="button">
  <m3e-icon name="settings"></m3e-icon>
</m3e-icon-button>
<m3e-rich-tooltip for="button">
  <span slot="subhead">New settings available</span>
  Now you can adjust the uploaded image quality, and upgrade your available storage space.
  <div slot="actions">
    <m3e-button>
      <m3e-rich-tooltip-action>Learn more</m3e-rich-tooltip-action>
    </m3e-button>
  </div>
</m3e-rich-tooltip>
 定位

默认情况下,丰富工具提示定位在元素的下方且之后。你可以使用 position 特性控制工具提示的位置。支持的值包括 above-before、 above-after、below-before、below-after(默认)、before、 after、above 与 below。位置可感知 BIDI,会自适应 从左到右与从右到左的文本方向。

无障碍

普通且非交互的工具提示会添加一个 aria-describedby 描述,它引用 一个包含工具提示消息的视觉隐藏元素。这样,当用户 聚焦工具提示的触发元素时,屏幕阅读器就能朗读工具提示的内容。aria-describedby 引用的元素 并非工具提示本身,而是其内容的一份不可见副本,并始终 存在于 DOM 中。

交互式丰富工具提示会在其触发元素上添加 aria-haspopup="dialog",以正确地向辅助技术暴露一个 类似对话框的弹出层。此外,工具提示内部的浮层会被赋予 ARIA role="dialog",并自动以工具提示的 subhead 作为标签。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/tooltip.js"></script>

此外,你还必须使用一个 import map 来引入依赖。
