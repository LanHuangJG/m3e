Tree 树形控件

m3e-tree 组件以用户可导航的结构呈现层级数据,其中的嵌套 层级可按需展开与折叠。 

import "@m3e/web/tree";
 用法

本节提供该模块组件的用法示例与配置指引。

基础用法

基础树由一个 m3e-tree 组件构成,其中包含一个或多个 m3e-tree-item。 条目可以嵌套,以创建更深的层级。每个条目通过 label 插槽提供其文本。使用 open 特性控制带有嵌套子项的条目 是否展开。

<m3e-tree>
  <m3e-tree-item open>
    <span slot="label">Getting Started</span>
    <m3e-tree-item>
      <span slot="label">Overview</span>
    </m3e-tree-item>
    <m3e-tree-item>
      <span slot="label">Installation</span>
    </m3e-tree-item>
  </m3e-tree-item>
  <!-- Additional items omitted for brevity -->
</m3e-tree>

密度

树形控件支持密度,会根据 --md-sys-density-scale 与 --md-sys-density-size 这两个 CSS 自定义属性调整自身垂直间距。默认 密度大小为 4dp。树形控件支持最低至 -3 的负密度比例,每降低一档,视觉 高度减少一个密度单位。

以下演示如何对树形控件应用 -3 密度。

Getting Started 开始使用 Overview 概览 Installation 安装 
<m3e-tree class="density-3">
  <!-- Tree items omitted for brevity -->
</m3e-tree>
 
.density-3 {
  --md-sys-density-scale: -3;
}
 无障碍

树形控件被赋予 ARIA role="tree",条目被赋予 role="treeitem",表示 一种支持键盘交互、语义分组与无障碍标注的结构化层级导航模型。

可展开条目使用 aria-expanded 表示嵌套内容的可见性。被选中时, 条目的选中状态会通过 aria-selected(单选树)与 aria-checked(多选树)来体现。

焦点通过 tabindex="0" 管理在 m3e-tree 容器上,当前 活动条目通过 aria-activedescendant 引用,它指向获得焦点的 m3e-tree-item 的 ID。这样无需转移 DOM 焦点即可实现游走焦点,确保无障碍的键盘 导航与一致的屏幕阅读器反馈。

图标被赋予 aria-hidden="true",以确保它们被视为纯装饰,并被排除在 无障碍树之外。

禁用条目会设置 aria-disabled="true",向辅助技术表明该条目 不可交互。

原生模块支持

@m3e/web 包使用 JavaScript Modules。要在不借助构建工具的情况下直接在浏览器中使用,请使用类似下面的 module 脚本。 

<script type="module" src="/node_modules/@m3e/web/dist/tree.js"></script>

此外,你还必须使用一个 import map 来引入依赖。 

<script type="importmap">
  {
    "imports": {
      "tslib": "https://cdn.jsdelivr.net/npm/tslib@2.8.1/+esm",
      "lit": "https://cdn.jsdelivr.net/npm/lit@3.3.0/+esm",
      "lit/": "https://cdn.jsdelivr.net/npm/lit@3.3.0/",
      "lit-html": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/+esm",
      "lit-html/directive.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directive.js",
      "lit-html/directives/if-defined.js": "https://cdn.jsdelivr.net/npm/lit-html@3.3.0/directives/if-defined.js",
      "@lit/reactive-element": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/+esm",
      "@lit/reactive-element/": "https://cdn.jsdelivr.net/npm/@lit/reactive-element@2.0.4/",

    }

</script>

生产构建请使用压缩版文件,以获得最佳加载性能。
