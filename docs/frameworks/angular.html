Angular

M3E 不需要专门的 Angular 绑定包。Angular 对 Web Components 提供一等支持,所有 M3E 组件都可以直接在 Angular 模板中使用,无需额外的包装器。

不过,Angular 需要 CUSTOM_ELEMENTS_SCHEMA 才能识别自定义元素。请将其添加到模块定义中: 

import { NgModule, CUSTOM_ELEMENTS_SCHEMA } from "@angular/core";

@NgModule({
  declarations: [...],
  imports: [...],
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
})
export class AppModule {}
