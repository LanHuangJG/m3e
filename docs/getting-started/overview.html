Overview 概览

欢迎使用 M3E —— 一个现代、从零实现的 Material Design 3,完全以 Web Components 构建。 它提供完整、贴合规范的组件套件,具备动态颜色、表现力动效与完整的无障碍支持。

表现力组件

借助 Material 3 的设计令牌、动态颜色、形状与动效系统,打造高度可定制的 UI 元素。

统一架构

以 ESM 优先,模块化入口并支持 tree-shaking,实现最小化打包体积。

 无障碍优先

内置对无障碍标准的支持,确保为所有用户提供包容性的体验。

主题与个性化

借助 Material 3 高级主题能力,轻松让组件适配你的品牌或用户偏好。

性能优化

轻量、快速加载的组件,专为现代 Web 平台设计。

 注重安全

采用默认安全的设计模式构建,包括 XSS 安全模板、Trusted Types 兼容性,以及对严格内容安全策略(CSP)的支持。
