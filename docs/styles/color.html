Color 颜色

M3E 应用 Material Design 3 颜色系统,让你能够创建可访问且个性化的配色方案,并级联到每个组件。

设计令牌

Material Design 3 设计令牌 以 CSS 自定义属性形式实现。设计令牌是具名、与平台无关的变量,以可复用且一致的格式表达视觉设计决策 —— 例如颜色、字体排版、间距与高度。

颜色令牌使用标准前缀 --md-sys-color-* 暴露,支持配合 Material Theme Builder 使用。

静态颜色

静态颜色指预定义、贴合规范的颜色,不会自动适应系统设置。--md-sys-color-* CSS 自定义属性默认采用浅色模式的 baseline 取值。

动态颜色

动态颜色指在运行时基于单一源色生成的配色方案,可实现随系统设置自适应调整的个性化主题。

M3E 提供 Theme 主题 组件,可为嵌套的主题感知元素应用动态颜色、表现力动效、密度与强焦点指示器。该组件借助 @material/material-color-utils 库,基于内容策略生成浅色与深色变体 —— 将经过感知调校的色调映射到 Material Design 3 的标准角色,如 primary、surface 与 outline。

强制颜色

M3E 遵循 forced-colors 模式,通过动态调整组件样式,确保在高对比度环境下依然清晰、可读且语义明确。
