Density 密度

密度指 UI 元素在空间上的紧凑程度 —— 组件排列的疏密、周围留白的大小,以及在给定布局内能容纳多少内容。M3E 应用 Material Design 3 密度系统,让组件布局、间距与触摸目标适配不同场景 —— 从宽敞、适合触摸的表面,到紧凑、信息密集的环境。

设计令牌

Material Design 3 设计令牌 以 CSS 自定义属性形式实现。设计令牌是具名、与平台无关的变量,以可复用且一致的格式表达视觉设计决策 —— 例如颜色、字体排版、间距与高度。

密度令牌使用标准化的 --md-sys-density-scale 与 --md-sys-density-size CSS 自定义属性暴露。M3E 提供 Theme 主题 组件,可通过其 density 特性系统地控制 --md-sys-density-scale。

密度感知组件

以下组件支持密度缩放:autocomplete、breadcrumb、 button-group、button、checkbox、chips、fab、 form-field、icon button、list、menu、 nav menu、paginator、radio-group、segmented button、 select、split-button、switch、tabs、toolbar 与 tree。每个组件都会根据当前密度比例调整其布局、间距与触摸目标。用法示例请参阅各组件的文档。

触摸表面

触摸表面保持最小尺寸 48dp x 48dp,确保在所有密度设置下都具备可访问、易于点按的目标。该阈值与 Material Design 3 指南保持一致,即使在紧凑布局中也会强制执行,从而保证鼠标与触摸输入的交互清晰度与可用性。
