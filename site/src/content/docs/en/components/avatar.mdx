<p> The <code>m3e-avatar</code> component is a reusable identity primitive that displays visual or textual representation with consistent sizing, shape, and typography. </p>

```js
import "m3e/avatar";
```

## Usage

<p> The <code>m3e-avatar</code> component accepts multiple content types, allowing it to render textual initials, images, or icons depending on what is provided in its slot. </p>
