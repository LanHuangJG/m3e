<p> The <code>m3e-breadcrumb</code> and <code>m3e-breadcrumb-item</code> components work together to display a hierarchical navigation trail. </p>

```js
import "m3e/breadcrumb";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Anatomy

<p> To create a breadcrumb trail, place your items inside an <code>m3e-breadcrumb</code> element. Each <code>m3e-breadcrumb-item</code> represents one level in the navigation hierarchy, starting with the broadest level and ending with the most specific. The final item is treated as the current level automatically, while the earlier items describe the path that leads to it. </p>

<Demo name="en/breadcrumb/0" />

### Links

<p> Breadcrumb items can also behave like links by specifying a URL using the <code>href</code> attribute. You can also specify <code>target</code>, and <code>rel</code> similar to native anchor tags. Links are not supported for the last item in a breadcrumb because the current level is not interactive. </p>

<Demo name="en/breadcrumb/1" />

### Icons

<p> Use the <code>icon</code> slot to render an icon before the label of an item. For icon-only items, simply place an icon in the default slot. Use <code>item-label</code> to provide an accessible label to the inner button of an icon-only item. </p>
<p>When using <code>m3e-icon</code>, the icon in the current breadcrumb item will automatically be filled.</p>

<Demo name="en/breadcrumb/2" />

### Custom separators

<p> Use the <code>separator</code> slot to provide a custom visual separator. The slotted element is cloned into each item's shadow root, replacing the default separator. </p>

<Demo name="en/breadcrumb/3" />

### Wrapping

<p> Breadcrumbs do not wrap by default. When horizontal space is limited, the last item is truncated with an ellipsis. Use the <code>wrap</code> attribute if you want the breadcrumb to wrap lines instead. </p>
