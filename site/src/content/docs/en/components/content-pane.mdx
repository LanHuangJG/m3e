<p> The <code>m3e-content-pane</code> component renders a shaped surface with padding and vertical scrolling for document-like content. </p>

```js
import "m3e/content-pane";
```

## Usage

<p> Use the <code>m3e-content-pane</code> to render a shaped surface with padding and vertical scrolling for document-like content. Inline padding is automatically adjusted to provide uniform spacing by compensating for platform scrollbar width, ensuring the content remains visually centered. </p>
