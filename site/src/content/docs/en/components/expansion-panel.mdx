<p> The <code>m3e/expansion-panel</code> module provides components for organizing content in collapsible sections and coordinated groups. It includes the following components: </p>
<ul> <li> <code>m3e-expansion-panel</code> — A details-summary view for organizing content in collapsible sections. </li> <li><code>m3e-accordion</code> — Organizes multiple expansion panels into a coordinated group.</li> </ul>

```js
import "m3e/expansion-panel";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Standalone panels

<p> You can use a standalone <code>m3e-expansion-panel</code> to present a collapsible details-summary section. Use the <code>header</code> slot to specify the title of a panel and use the default slot for its content. </p>

<Demo name="en/expansion-panel/0" />

<p>Use the <code>open</code> attribute to control whether a panel is open (expanded).</p>

<Demo name="en/expansion-panel/1" />

### Toggles

<p> You can change the toggle position and direction using the <code>toggle-position</code> and <code>toggle-direction</code> attributes. Supported positions include: <code>before</code> and <code>after</code> (default). Supported directions include <code>vertical</code> (default) and <code>horizontal</code>. </p>

<Demo name="en/expansion-panel/2" />

<p>Use the <code>hide-toggle</code> attribute to hide the toggle.</p>

<Demo name="en/expansion-panel/3" />

### Accordion

<p>Use a <code>m3e-accordion</code> to create a coordinated group of panels.</p>

<Demo name="en/expansion-panel/4" />

<p> By default, only one panel can be open at a time. Use the <code>multi</code> attribute to allow multiple panels to be open at the same time. </p>

<Demo name="en/expansion-panel/5" />
