<p>The <code>m3e-heading</code> component provides expressive, accessible headings for pages and sections</p>

```js
import "m3e/heading";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Typescale variants and sizes

<p> The <code>m3e-heading</code> supports five variants: <code>display</code> (default), <code>headline</code>, <code>title</code>, and <code>label</code>. It supports three size variants: <code>large</code>, <code>medium</code> (default) and <code>small</code>. Use the <code>variant</code> and <code>size</code> attributes to change the typescale of a heading. </p>

### Emphasized typescale

<p>Use the <code>emphasized</code> attribute to control whether a heading's typescale is emphasized.</p>
