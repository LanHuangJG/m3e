<p> The <code>m3e-icon-button</code> component is an icon button users interact with to perform a supplementary action. </p>

```js
import "m3e/icon-button";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Variants

<p> There are four icon button appearance variants: <code>filled</code>, <code>tonal</code>, <code>outlined</code>, and <code>standard</code> (default). Use the <code>variant</code> attribute to change the appearance. </p>

<Demo name="en/components/icon-button/0" />

### Shapes

<p> Icon buttons can come in two shapes: <code>rounded</code> (default) or <code>square</code>. Use the <code>shape</code> attribute to control the shape of a button. </p>

<Demo name="en/components/icon-button/1" />

### Sizes

<p> There are five size variants which can be used to add or remove emphasis: <code>extra-small</code>, <code>small</code> (default), <code>medium</code>, <code>large</code>, and <code>extra-large</code>. Use the <code>size</code> attribute to control an icon button's size. </p>

<Demo name="en/components/icon-button/2" />

### Widths

<p> There are three width variants which can be used to add or remove emphasis: <code>default</code> (default), <code>narrow</code>, and <code>wide</code>. Use the <code>width</code> attribute to control an icon button's width. </p>

<Demo name="en/components/icon-button/3" />

### Toggle

<p> Use the <code>toggle</code> attribute to control whether an icon button can be used for binary selection and the <code>selected</code> attribute to control the selected state. When clicked, a cancellable <code>beforeinput</code> event is emitted followed by an <code>input</code> and <code>change</code> event. To cancel selection change, call <code>preventDefault</code> during <code>beforeinput</code>. </p>

<Demo name="en/components/icon-button/4" />

<p>You can also change the icon presented for a selected toggle button using the <code>selected</code> slot.</p>

<Demo name="en/components/icon-button/5" />

<p> When selected, icon buttons change shape. Rounded buttons become square and square buttons become rounded. The following illustrates the selected states for both rounded and square icon buttons. </p>

<Demo name="en/components/icon-button/6" />

### Disabling

<p> Use the <code>disabled</code> attribute to disable an icon button. By default, disabled icon buttons are not focusable with the keyboard. You can use the <code>disabled-interactive</code> attribute to support <a href="https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/#kbd_disabled_controls" target="_blank">focusability of disabled controls</a> to increase their discoverability. </p>

<Demo name="en/components/icon-button/7" />

### Types

<p> Use the <code>type</code> attribute to control the behavior of an icon button. By default, <code>type</code> is <code>button</code>. You can change this to <code>submit</code> or <code>reset</code> to submit or reset a parenting form when clicked. When submitting a form, you can use the <code>name</code> and <code>value</code> attributes to specify a value. </p>

### Links

<p> Icon buttons can also behave like links by specifying a URL using the <code>href</code> attribute. You can also specify <code>target</code>, <code>rel</code> and <code>download</code> similar to native anchor tags. </p>
