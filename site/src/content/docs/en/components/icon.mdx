<p> The <code>m3e-icon</code> component makes it easy to use Material Symbols in your application. It supports outlined, rounded, and sharp variants, as well as variable font features like fill, weight, grade, and optical size. For more information, see the <a href="https://developers.google.com/fonts/docs/material_symbols" target="_blank" rel="noopener noreferrer"> Material Symbol Guide </a> and <a href="https://fonts.google.com/icons" target="_blank" rel="noopener noreferrer"> Material Symbol Library </a>. </p>

<p> The Material Symbols font is the easiest way to incorporate Material Symbols into your application. Using the <a href="https://developers.google.com/fonts/docs/css2#forming_api_urls" target="_blank" rel="noopener noreferrer"> Fonts CSS API</a>, you can use variable fonts to optimize icon usage within your application. See <a href="https://caniuse.com/variable-fonts" target="_blank" rel="noopener noreferrer"> Can I Use's Variable Fonts </a> to determine whether your user's browser supports variable fonts. </p>
<p> Alternatively, the <code>m3e-icons</code> package provides SVG versions of Material Symbols that register automatically with <code>m3e-icon</code>. See the SVG Icons section below for usage details. </p>

```js
import "m3e/icon";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Variable fonts

<p>The following illustrates a link used to download a variable font for outlined icons with fill support.</p>

```html
<link
  href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:opsz,wght,FILL,GRAD@24,400,0..1,0"
  rel="stylesheet"
/>
```

### Appearance variants

<p> The <code>m3e-icon</code> component supports appearance variants and fine-grained typographic controls for fill, weight, grade, and optical size. </p>
<p> Use the <code>variant</code> attribute to control the visual style of the icon. Supported values include: <code>outlined</code> (default), <code>rounded</code>, and <code>sharp</code>. Use the <code>filled</code> attribute to specify whether the icon is filled (<code>1</code>) or unfilled (<code>0</code>). This attribute maps to the <code>FILL</code> axis of the variable font. </p>
<p> The <code>weight</code> attribute adjusts the thickness and boldness of the icon's strokes. It behaves like font weight in text accepting values from <code>100</code> to <code>700</code>. Use the <code>grade</code> attribute to adjust the stroke thickness of an icon. Supported values include: <code>low</code>, <code>medium</code> (default) and <code>high</code>. This attribute maps to the <code>GRAD</code> axis of the variable font with values like <code>-25</code>, <code>0</code>, or <code>200</code>. </p>
<p> The <code>optical-size</code> attribute supports values from <code>20</code> to <code>48</code> indicating the optical size of the icon. </p>

### SVG icons

<p> As an alternative to use of variable fonts, you can use the <code>m3e-icons</code> package for applications that prefer SVG-based icons. This package supplies SVG data sourced from <code>@material-symbols/svg-400</code> and integrates with the existing <code>m3e-icon</code> component through an internal icon registry. </p>

<Demo name="en/icon/1" />

```js
import "m3e-icons/outlined/search";
import "m3e-icons/outlined/home";
import "m3e-icons/outlined/settings";
import "m3e-icons/outlined/favorite";
import "m3e-icons/outlined/notifications";
```

<p> Icons are organized by Material Symbols variant families (<code>outlined</code>, <code>rounded</code>, <code>sharp</code>). You can register a specific icon by importing its module: </p>

```js
import "m3e-icons/outlined/search";
```

<p>Or register an entire variant family at once:</p>

```js
import "m3e-icons/outlined";
```

<p> Each icon module performs a side-effect registration with the internal registry used by <code>m3e-icon</code>. Once registered, the icon becomes available for rendering. If an icon is not registered, it will fall back to the Material Symbols variable font. </p>
