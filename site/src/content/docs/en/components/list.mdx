<p> The <code>m3e/list</code> module provides expressive, accessible components for organizing and displaying lists of items. </p>

```js
import "m3e/list";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Lists

<p> To create a list of items, use the <code>m3e-list</code> component with one or more <code>m3e-list-item</code> components nested inside it. </p>

#### Anatomy

<p> The <code>m3e-list-item</code> component provides a modular layout for structured content blocks. It exposes the following named slots: </p>
<ul> <li><code>(default)</code> — Renders the content of the list item.</li> <li><code>leading</code> — Renders the leading content of the list item.</li> <li><code>overline</code> — Renders the overline of the list item.</li> <li><code>supporting-text</code> — Renders the supporting text of the list item.</li> <li><code>trailing</code> — Renders the trailing content of the list item.</li> </ul>

#### Variants

<p> There are two appearance variants <code>standard</code> (default) and <code>segmented</code>. Use the <code>variant</code> attribute to control a list's appearance. </p>

<Demo name="en/list/2" />

#### Multiline items

<p> List items are responsive containers that automatically adapt their height and internal spacing according to the item's line count, ensuring correct layout for one-line, two-line, and three-line configurations. </p>

<Demo name="en/list/3" />

#### Media content

<p> List items automatically size and position leading and trailing media—such as videos, images, avatars, and icons—according to the item's detected line count, reserving space when needed to keep visuals consistently aligned across one-, two-, and three-line configurations. </p>

### Action lists

<p> Use the <code>m3e-action-list</code> and <code>m3e-list-action</code> to create a list where each item performs a single action. Action lists support the same appearance variants as <code>m3e-list</code> and <code>m3e-list-action</code> supports the same slots as <code>m3e-list-item</code>. </p>

#### Links

<p> List actions can also behave like links by specifying a URL using the <code>href</code> attribute. You can also specify <code>target</code>, <code>rel</code> and <code>download</code> similar to native anchor tags. </p>

<Demo name="en/list/14" />

### Nested lists

<p> Both <code>m3e-list</code> and <code>m3e-action-list</code> can use an <code>m3e-expandable-list-item</code> to present hierarchical content that can be expanded or collapsed. The <code>m3e-expandable-list-item</code> provides a disclosure-style header that toggles the visibility of a nested list, allowing related actions or items to be grouped without overwhelming the parent list. </p>
<p>Use the <code>open</code> attribute to control whether an expandable list item is open.</p>

### Selection lists

<p> Use the <code>m3e-selection-list</code> and <code>m3e-list-option</code> to create a list for selecting values, where each item performs a single option. Selection lists support the same appearance variants as <code>m3e-list</code> and <code>m3e-list-option</code> supports the same slots as <code>m3e-list-item</code>. However, the selection indicator will replaces content in the <code>trailing</code> slot unless selection indicators are hidden. </p>
<p> Use the <code>selected</code> attribute to control the selected state of a <code>m3e-list-option</code>. When clicked, a cancellable <code>beforeinput</code> event is emitted followed by an <code>input</code> and <code>change</code> event. To cancel selection change, call <code>preventDefault</code> during <code>beforeinput</code>. </p>

#### Multiple selection

<p> Selection lists support both single-select and multi-select modes. Use the <code>multi</code> attribute to allow multiple options to be selected simultaneously. </p>

#### Hiding the selection indicator

<p> Use the <code>hide-selection-indicator</code> attribute of <code>m3e-selection-list</code> to hide selection indicators. If an option has an icon via use of the <code>trailing</code> slot, the icon is presented. </p>

<Demo name="en/list/21" />

#### Disabling

<p> Individual list options can be disabled using the <code>disabled</code> attribute and can be selected and disabled. </p>

#### Form Associated

<p> Selection lists can participate in form submission as a <a href="https://html.spec.whatwg.org/multipage/custom-elements.html#custom-elements-face" target="_blank" rel="noopener noreferrer">form-associated custom element</a> (FACE), contributing its state to the form data. The <code>name</code> attribute defines the key under which the component's value is submitted in a form. The list's value is determined by selected options. You can use the <code>value</code> of a <code>m3e-list-option</code> to control a option's value. When multiple options are selected, form data will include multiple entries keyed by the same <code>name</code>. </p>
<p> The component honors the <code>disabled</code> state (on the option itself) as a <strong>property-only</strong> control. When disabled at runtime, it does <em>not</em> sprout a <code>disabled</code> attribute into the DOM. </p>
