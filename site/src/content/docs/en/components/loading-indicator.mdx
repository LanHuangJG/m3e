<p> The <code>m3e-loading-indicator</code> component shows indeterminate progress for a short wait time. It uses animation to grab attention, mitigate perceived latency, and indicate that an activity is in progress. </p>

```js
import "m3e/loading-indicator";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Variants

<p> There are two loading indicator appearance variants: <code>uncontained</code> (default) and <code>contained</code>. Use the <code>variant</code> attribute to change the appearance. </p>
