<p> The <code>m3e-paginator</code> component is a compact, accessible paginator control for navigating paged data sets. It provides semantic first/previous/next/last navigation controls and an optional page-size selector. </p>

```js
import "m3e/paginator";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Basic usage

<p> At minimum, you must specify the total number of items being paged and the page size. Use the <code>length</code> and <code>page-size</code> attributes of the <code>m3e-paginator</code> component, respectively. By default, <code>page-size</code> is set to 50. </p>
<p> When a user interacts with the paginator, it emits a <code>page</code> event. This event can be used to update any associated data view and includes the following properties: </p>
<ul> <li><strong>pageIndex</strong>: <em>number</em> — The zero-based index of the current page.</li> <li> <strong>previousPageIndex</strong>: <em>number</em> (optional) — The zero-based index of the previously selected page. </li> <li><strong>pageSize</strong>: <em>number | "all"</em> — The current page size.</li> <li><strong>length</strong>: <em>number</em> — The total number of items being paged.</li> </ul>

### Page sizes

<p> The <code>page-sizes</code> attribute lets you define which page size options are available to users. It accepts a comma-separated list of values and may include <code>"all"</code>. By default, <code>page-sizes</code> is set to <code>"5,10,25,50,100"</code>. </p>
<p> The current <code>page-size</code> will always appear in the dropdown, event if its not included in <code>page-sizes</code>. </p>
<p> When <code>page-size</code> is set to <code>"all"</code>, the range label and navigation actions are hidden. </p>

<Demo name="en/components/paginator/1" />

### Navigation actions

<p> By default, the first and last page buttons are hidden. Use the <code>show-first-last-buttons</code> attribute to show them. </p>
