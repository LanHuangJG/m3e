<p> The <code>m3e-linear-progress-indicator</code> and <code>m3e-circular-progress-indicator</code> components provide accessible, animated progress indicators for tracking the completion of tasks or processes. </p>

```js
import "m3e/progress-indicator";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Circular

<p> Use the <code>m3e-circular-progress-indicator</code> to present a circular indicator of progress and activity. This component supports two modes (determinate and indeterminate) and two appearance variants (<code>flat</code> and <code>wavy</code>). Use the <code>variant</code> attribute to change the appearance. </p>

#### Determinate

<p> By default, circular progress indicators are determinate. Use the <code>value</code> attribute to indicate completion percentage and use <code>max</code> to specify the total number of steps or units of progress. In addition, you can provide content in the default slot. </p>

<Demo name="en/progress-indicator/0" />

#### Indeterminate

<p> Use the <code>indeterminate</code> attribute to change the mode to indeterminate. In this mode, <code>value</code> and <code>max</code> are ignored. </p>

<Demo name="en/progress-indicator/1" />

### Linear

<p> Use the <code>m3e-linear-progress-indicator</code> to present a horizontal bar for indicating progress and activity. This component supports four modes: <code>determinate</code> (default), <code>indeterminate</code>, <code>buffer</code>, and <code>query</code>. </p>
<p> Use the <code>mode</code> attribute to change the mode. As with a circular indicator, use <code>variant</code> to set the appearance to either <code>flat</code> (default) or <code>wavy</code>. </p>

#### Determinate

<p> Use the <code>determinate</code> mode where the percentage of the operation complete is known. Use the <code>value</code> attribute to indicate completion percentage and use <code>max</code> to specify the total number of steps or units of progress. This is the default mode. </p>
<p> When using the <code>wavy</code> variant, the indicator transitions to the flat appearance automatically when progress reaches 100%. </p>

<Demo name="en/progress-indicator/2" />

#### Indeterminate

<p> Use the <code>indeterminate</code> mode to express that something is happening, but without conveying discrete progress. In this mode, <code>value</code> and <code>max</code> are ignored. </p>

<Demo name="en/progress-indicator/3" />

#### Buffer

<p> Use the <code>buffer</code> mode to indicate some activity or loading from the server. In this mode, <code>value</code> determines the progress of the primary bar while the <code>buffer-value</code> attribute is used to show buffering progress. </p>
<p> As with <code>determinate</code> mode, when using the <code>wavy</code> variant, the indicator transitions to the flat appearance automatically when progress reaches 100%. </p>

<Demo name="en/progress-indicator/4" />

#### Query

<p> Use the <code>query</code> mode to indicate pre-loading before the actual loading starts. In this mode, <code>value</code> and <code>max</code> are ignored. </p>

<Demo name="en/progress-indicator/5" />
