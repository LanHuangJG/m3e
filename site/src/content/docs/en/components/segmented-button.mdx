<p> The <code>m3e-segmented-button</code> component allows users to select one or more options from a horizontal group. </p>

```js
import "m3e/segmented-button";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Anatomy

<p> A segmented button is defined using the <code>m3e-segmented-button</code> component, which serves as a semantic container for a set of interactive segments. Each segment is represented by a <code>m3e-button-segment</code> component, allowing users to select from multiple related options within a unified control. </p>

<Demo name="en/segmented-button/0" />

### Icons

<p> Use the <code>icon</code> slot of the <code>m3e-button-segment</code> to present an icon before a segment's label. </p>
<p>When selected, a segments's icon is replaced with a check icon.</p>

<Demo name="en/segmented-button/1" />

### Selection

<p> Segmented buttons support both single-select and multi-select modes. Use the <code>multi</code> attribute of <code>m3e-segmented-button</code> to allow multiple segments to be selected simultaneously. </p>
<p> Use the <code>checked</code> attribute to control the selected state of a <code>m3e-button-segment</code>. When clicked, a cancellable <code>beforeinput</code> event is emitted followed by an <code>input</code> and <code>change</code> event. To cancel selection change, call <code>preventDefault</code> during <code>beforeinput</code>. </p>

<Demo name="en/segmented-button/2" />

### Disabling

<p>Use the <code>disabled</code> attribute to disable an individual segment.</p>

<Demo name="en/segmented-button/3" />

<p> You can also use the <code>disabled</code> attribute of <code>m3e-segmented-button</code> to disable the button in its entirety. </p>

<Demo name="en/segmented-button/4" />

### Hiding the selection indicator

<p> Use the <code>hide-selection-indicator</code> attribute of <code>m3e-segmented-button</code> to hide selection indicators. If a segment has an icon via use of the <code>icon</code> slot, the icon is retained upon selection. </p>

<Demo name="en/segmented-button/5" />

### Form Associated

<p> Segmented buttons can participate in form submission as a <a href="https://html.spec.whatwg.org/multipage/custom-elements.html#custom-elements-face" target="_blank" rel="noopener noreferrer">form-associated custom element</a> (FACE), contributing its state to the form data. The <code>name</code> attribute defines the key under which the component's value is submitted in a form. The button's value is determined by selected segments. You can use the <code>value</code> of a <code>m3e-button-segment</code> to control a segments's value. When multiple segments are selected, form data will include multiple entries keyed by the same <code>name</code>. </p>
<p> The component honors the <code>disabled</code> state (on the segmented button itself) as a <strong>property-only</strong> control. When disabled at runtime, it does <em>not</em> sprout a <code>disabled</code> attribute into the DOM. </p>
