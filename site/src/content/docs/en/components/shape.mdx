<p> The <code>m3e-shape</code> component allows you to use abstract shapes thoughtfully to add emphasis and decorative flair, including built-in shape morphing. </p>

```js
import "m3e/shape";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Shapes

<p> The <code>m3e-shape</code> allows you to easily use shapes from the <a href="https://m3.material.io/styles/shape" target="_blank">Material Design 3 Shape Library</a> to to add emphasis and decorative flair. </p>
<p> It supports 31 shapes, specified using the <code>name</code> attribute: <code>4-leaf-clover</code> <code>4-sided-cookie</code>, <code>6-sided-cookie</code>, <code>7-sided-cookie</code>, <code>8-leaf-clover</code>, <code>9-sided-cookie</code>, <code>12-sided-cookie</code>, <code>arch</code>, <code>arrow</code>, <code>boom</code>, <code>bun</code>, <code>burst</code>, <code>circle</code>, <code>diamond</code>, <code>fan</code>, <code>flower</code>, <code>gem</code>, <code>ghost-ish</code>, <code>heart</code>, <code>hexagon</code>, <code>oval</code>, <code>pentagon</code>, <code>pill</code>, <code>pixel-circle</code>, <code>pixel-triangle</code>, <code>puffy</code>, <code>puffy-diamond</code>, <code>semicircle</code>, <code>slanted</code>, <code>soft-boom</code>, <code>soft-burst</code>, <code>square</code>, <code>sunny</code>, <code>triangle</code>, and <code>very-sunny</code>. </p>
