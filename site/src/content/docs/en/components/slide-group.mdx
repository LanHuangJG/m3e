<p> The <code>m3e-slide-group</code> component presents directional pagination controls for navigating overflowing content. </p>

```js
import "m3e/slide-group";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Basic usage

<p> To use the <code>m3e-slide-group</code>, simply nest content inside it. When content overflows, directional pagination buttons will appear allowing the user to click to scroll its content. </p>

<Demo name="en/slide-group/0" />

### Orientation

<p> By default, scroll groups are oriented horizontally. Use the <code>vertical</code> attribute to create a vertically oriented scroll group. </p>
