<p> The <code>m3e-stepper</code> component provides a wizard-like workflow by dividing content into logical steps. </p>

```js
import "m3e/stepper";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Basic usage

<p> Use <code>m3e-stepper</code>, <code>m3e-step</code>, and <code>m3e-step-panel</code> to construct a wizard-like workflow. Both <code>m3e-step</code> and <code>m3e-step-panel</code> must be direct children of <code>m3e-stepper</code>. To associate a step with its corresponding panel, set the <code>for</code> attribute on <code>m3e-step</code> to match the ID of the target <code>m3e-step-panel</code>. </p>
<p> To select a step, apply the <code>selected</code> attribute to a single <code>m3e-step</code>. When a step is activated, a cancellable <code>beforeinput</code> event is emitted followed by an <code>input</code> and <code>change</code> event. To cancel selection change, call <code>preventDefault</code> during <code>beforeinput</code>. Only one step may be selected at a time. </p>

### Orientation

<p> The <code>m3e-stepper</code> supports three orientations: <code>horizontal</code> (default), <code>vertical</code>, and <code>auto</code>. Using <code>auto</code>, the orientation is responsive and determined by viewport size. Use the <code>orientation</code> attribute to change a stepper's orientation. </p>

<Demo name="en/components/stepper/1" />

### Header positions

<p> When using a horizontal stepper, you can control where the stepper's content is positioned using the <code>header-position</code> attribute. By default, the header is placed <code>above</code> content, but you can change it to <code>below</code> to placed it under the content. </p>

<Demo name="en/components/stepper/2" />

### Label positions

<p> When using a horizontal stepper, you can control where the step's label is positioned using the <code>label-position</code> attribute. By default, labels are placed <code>after</code> a step's icon, but you can change it to <code>below</code> to placed it under the icon. </p>

<Demo name="en/components/stepper/3" />

### Stepper buttons

<p> Panels provide an <code>actions</code> slot for placing navigation controls. The <code>m3e-stepper-previous</code>, <code>m3e-stepper-next</code>, and <code>m3e-stepper-reset</code> components can be used to navigate steps. Using the <code>m3e-stepper-reset</code> will reset the stepper and any form data. </p>

```html
<m3e-step-panel>
  <div slot="actions">
    <m3e-button><m3e-stepper-previous>Back</m3e-stepper-previous></m3e-button>
    <m3e-button><m3e-stepper-next>Next</m3e-stepper-next></m3e-button>
  </div>
</m3e-step-panel>
```

### Linear stepper

<p> The <code>linear</code> attribute can be set on <code>m3e-stepper</code> to create a linear stepper that requires the user to complete previous steps before proceeding to following steps. </p>
<p> Linear steppers require use of a <code>form</code> per step whose validity status determines whether a user can move to the next step. </p>
<p> A step is considered complete once the user transitions forward. Navigation back to an earlier step is allowed only when that step is explicitly designated as editable via the <code>editable</code> attribute. </p>

<Demo name="en/components/stepper/4" />

### Step types

<p> Use the <code>optional</code> attribute on <code>m3e-step</code> to indicate that completion is not required. When navigating away from an optional step, its nested <code>form</code> is still validated; however, an invalid state will neither block progression nor visually mark the step header as invalid. </p>
<p> For linear steppers, use the <code>editable</code> attribute on <code>m3e-step</code> to allow a user to navigate back to a previously completed step. </p>
<p> You can use the <code>completed</code> and <code>invalid</code> attributes to programmatically control whether a step is completed or invalid. </p>

### Step icons

<p> You can override icons using the <code>icon</code>, <code>done-icon</code>, <code>edit-icon</code>, and <code>error-icon</code>. </p>

### Hint and error text

<p> You can use the <code>hint</code> and <code>error</code> slots of a <code>m3e-step</code> to specify hint text or, when invalid, an error message. By default, optional steps have hint text of <code>(Optional)</code>. </p>
