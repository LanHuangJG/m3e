<p> The <code>m3e-theme</code> component is a non-visual element used to apply dynamic color, expressive motion, density, and strong focus indicators to nested, theme-aware elements. </p>

```js
import "m3e/theme";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Color

<p> Use the <code>color</code> attribute to specify a HEX color from which to derive color palettes. This will set CSS custom properties that reflect the standard Material Design 3 color palettes. For example, <code>--md-sys-color-primary</code> is set to the primary color. </p>

<Demo name="en/components/theme/0" />

### Schemes

<p> Themes support three color schemes: <code>light</code>, <code>dark</code>, and <code>auto</code> (default). Use the <code>scheme</code> attribute to specify the color scheme. </p>
<p> When <code>auto</code> is used, the theme dynamically responds to system preferences by monitoring the media queries <code>(prefers-color-scheme: light)</code> and <code>(prefers-color-scheme: dark)</code>, selecting the appropriate color scheme based on the user's environment. </p>

### Contrast

<p> Themes support three contrast levels: <code>standard</code> (default), <code>medium</code>, and <code>high</code>. Use the <code>contrast</code> attribute to control how strongly tones are separated within the theme. </p>

### Density

<p> Use the <code>density</code> attribute to control layout compactness across density-aware components within a theme. It adjusts spacing, padding, and sizing to achieve a more compact or more spacious visual rhythm. </p>
<ul> <li><strong>Valid values:</strong> <code>-3</code> (most compact) to <code>+1</code> (most spacious)</li> <li><strong>Default:</strong> <code>0</code></li> <li><strong>Scope:</strong> Applies globally to all components within the theme</li> </ul>
<p> When a theme is initialized with a <code>density</code> value, it sets the system token <code>--md-sys-density-scale</code> to reflect that value. This token is used by density-aware components to adjust their internal layout metrics. </p>
<ul> <li>Compact density reduces vertical padding and component height</li> <li>Spacious density increases spacing for relaxed layouts</li> <li>Touch targets remain accessible and compliant with minimum size guidelines</li> </ul>
<p> The following example demonstrates how <code>m3e-button</code> responds to theme-level density adjustments. A medium-sized button is shown, which supports a minimum density of <code>-2</code>. Note that densities <code>-3</code> and <code>-2</code> produce identical layout behavior for this size, as values below the supported threshold are clamped to <code>-2</code>. </p>

<Demo name="en/components/theme/3" />

### Motion

<p> Themes support two motion schemes: <code>standard</code> (default) and <code>expressive</code>. These schemes define how components animate across the system, using spring-based physics to guide spatial and effect transitions. Use the <code>motion</code> attribute to control the motion scheme. </p>
<p> The following example illustrates how the <code>m3e-switch</code> adapts to the motion scheme. Note the spring effect when clicking the expressive example. </p>

```html
<m3e-theme motion="standard">

</m3e-theme>
<m3e-theme motion="expressive">

</m3e-theme>
```
