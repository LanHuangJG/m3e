<p>The <code>m3e-toolbar</code> component presents contextual actions, navigation, and controls.</p>

```js
import "m3e/toolbar";
```

## Usage

<p>This section outlines usage examples and configuration guidance for the components in this module.</p>

### Variants

<p> There are two toolbar appearance variants: <code>standard</code> (default) and <code>vibrant</code>. Use the <code>variant</code> attribute to change the appearance. </p>

<Demo name="en/components/toolbar/0" />

### Shapes

<p> There are two shape variants: <code>square</code> (default) and <code>rounded</code>. Use the <code>shape</code> attribute to change the appearance. </p>

<Demo name="en/components/toolbar/1" />

### Elevation

<p> Use the <code>elevated</code> attribute to elevate a toolbar to a visually prominent surface, distinguishing it from the surrounding layout and signaling its importance or active context. </p>

<Demo name="en/components/toolbar/2" />

### Orientation

<p> By default, toolbar are oriented horizontally. Use the <code>vertical</code> attribute to orient the toolbar vertically, stacking its interactive elements from top to bottom rather than left to right. This is useful for side panels, compact layouts, or contexts where vertical alignment enhances clarity or accessibility. </p>

<Demo name="en/components/toolbar/3" />
