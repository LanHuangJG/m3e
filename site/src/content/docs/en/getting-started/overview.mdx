<p> Welcome to M3E, a modern, from-scratch implementation of <a href="https://m3.material.io/" target="_blank">Material Design 3</a>, built entirely with <a href="https://developer.mozilla.org/en-US/docs/Web/Web_Components" target="_blank">Web Components</a>. It provides a complete, spec-aligned component suite with dynamic color, expressive motion, and full accessibility. </p>

</m3e-card>
<m3e-card variant="outlined" class="callout">
