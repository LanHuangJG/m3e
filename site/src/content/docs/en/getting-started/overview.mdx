Welcome to M3E, a modern, from-scratch implementation of [Material Design 3](https://m3.material.io/), built
entirely with [Web Components](https://developer.mozilla.org/en-US/docs/Web/Web_Components). It provides a complete,
spec-aligned component suite with dynamic color, expressive motion, and full accessibility.

## Features

- **Expressive components** — leverage Material 3's design tokens, dynamic color, shape and motion systems.
- **Unified architecture** — ESM-first with modular entry points and tree-shaking for minimal bundles.
- **Accessibility first** — built-in support for accessibility standards.
- **Theming & personalization** — adapt components to your brand or user preferences.
