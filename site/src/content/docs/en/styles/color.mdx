<p> M3E applies the <a href="https://m3.material.io/styles/color/system/overview" target="_blank">Material Design 3 color system</a> allowing you to create accessible and personalized color schemes that cascade to every component. </p>

## Design tokens

<p> The <a href="https://m3.material.io/foundations/design-tokens/overview" target="_blank">Material Design 3 design tokens</a> are implemented as custom CSS properties. Design tokens are named, platform-agnostic variables that represent visual design decisions—such as color, typography, spacing, and elevation—in a reusable, consistent format. </p>
<p> Color tokens are surfaced using the standardized prefix <code>--md-sys-color-&#42;</code> supporting use of the <a href="https://material-foundation.github.io/material-theme-builder/" target="_blank">Material Theme Builder</a>. </p>

## Static color

<p> Static colors refer to predefined, spec-aligned colors that do not automatically adapt to system settings. The <code>--md-sys-color-&#42;</code> custom CSS properties default to the <strong>baseline</strong> values for light mode. </p>

## Dynamic color

<p> Dynamic color refers to runtime-generated color schemes derived from a single source color, allowing personalized theming that adapts to system settings. </p>
<p> M3E provides the <a href="/en/components/theme/">Theme</a> component which applies dynamic color, expressive motion, density, and strong focus indicators to nested, theme-aware elements. This component leverages the <code>@material/material-color-utils</code> library to generates light and dark variants based on the content strategy—mapping perceptually tuned tones to standard Material Design 3 roles like <i>primary</i>, <i>surface</i>, and <i>outline</i>. </p>

## Forced colors

<p> M3E honors <code>forced-colors</code> mode by dynamically adapting component styles to ensure legibility, contrast, and semantic clarity in high-contrast environments. </p>
