<p> M3E primarily applies the <a href="https://m3.material.io/styles/motion/easing-and-duration/applying-easing-and-duration" target="_blank"> Material Design 3 easing and duration </a> system to provide consistent, emotionally tuned transitions across components. A subset—including buttons, loading indicators, and switches—have adopted the <a href="https://m3.material.io/styles/motion/overview/how-it-works" target="_blank"> Material Design 3 motion physics system </a>, bringing spring-based dynamics and velocity-aware responsiveness to components where expressive motion is essential. </p>

## Design tokens

<p> The <a href="https://m3.material.io/foundations/design-tokens/overview" target="_blank">Material Design 3 design tokens</a> are implemented as custom CSS properties. Design tokens are named, platform-agnostic variables that represent visual design decisions—such as color, typography, spacing, and elevation—in a reusable, consistent format. </p>
<p> Motion tokens are surfaced using the standardized prefix <code>--md-sys-motion-&#42;</code> and are defaulted to spec-aligned values. M3E provides the <a href="/en/components/theme/">Theme</a> component which can be used to systematically control whether <strong>standard</strong> or <strong>expressive</strong> motion schemes are used through its <code>motion</code> attribute. </p>

## Reduced motion

<p> M3E honors reduced motion system settings by dynamically disabling or simplifying transitions for users who prefer minimal motion. Components respond to the <code>prefers-reduced-motion</code> media query, ensuring that expressive motion never compromises comfort or accessibility. </p>
