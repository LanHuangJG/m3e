<p> <code>m3e-avatar</code> 组件是一个可复用的身份基础元素,以一致的尺寸、形状与排版呈现视觉或文本化的身份表示。 </p>

```js
import "m3e/avatar";
```

## 用法

<p> <code>m3e-avatar</code> 组件接受多种内容类型,可根据插槽中提供的内容渲染文本首字母、图片或图标。 </p>
