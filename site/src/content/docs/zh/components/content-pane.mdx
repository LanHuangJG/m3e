<p> <code>m3e-content-pane</code> 组件渲染一个带形状的表面,为文档式内容提供内边距与垂直滚动。 </p>

```js
import "m3e/content-pane";
```

## 用法

<p> 使用 <code>m3e-content-pane</code> 渲染一个带形状的表面,为文档式内容提供内边距与垂直滚动。行内内边距会自动调整,通过补偿平台滚动条宽度来提供均匀间距,确保内容保持视觉居中。 </p>
