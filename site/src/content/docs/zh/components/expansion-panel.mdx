<p> <code>m3e/expansion-panel</code> 模块提供用于在可折叠分区与协调组中组织内容的组件。它包含以下组件: </p>
<ul> <li> <code>m3e-expansion-panel</code> —— 一种详情-摘要视图,用于在可折叠分区中组织内容。 </li> <li><code>m3e-accordion</code> —— 把多个折叠面板组织成一个协调的组。</li> </ul>

```js
import "m3e/expansion-panel";
```

## 用法

### 独立面板

<p> 你可以使用独立的 <code>m3e-expansion-panel</code> 呈现一个可折叠的详情-摘要分区。 使用 <code>header</code> 插槽指定面板标题,使用默认插槽放置其内容。 </p>

<Demo name="zh/components/expansion-panel/0" />

<p>使用 <code>open</code> 特性控制面板是否打开(展开)。</p>

<Demo name="zh/components/expansion-panel/1" />

### 切换控件

<p> 你可以使用 <code>toggle-position</code> 与 <code>toggle-direction</code> 特性更改切换控件的位置与方向。支持的位置包括 <code>before</code> 与 <code>after</code>(默认)。支持的方向包括 <code>vertical</code>(默认)与 <code>horizontal</code>。 </p>

<Demo name="zh/components/expansion-panel/2" />

<p>使用 <code>hide-toggle</code> 特性隐藏切换控件。</p>

<Demo name="zh/components/expansion-panel/3" />

### 手风琴

<p>使用 <code>m3e-accordion</code> 创建一组协调的面板。</p>

<Demo name="zh/components/expansion-panel/4" />

<p> 默认情况下,一次只能打开一个面板。使用 <code>multi</code> 特性允许多个 面板同时打开。 </p>

<Demo name="zh/components/expansion-panel/5" />
