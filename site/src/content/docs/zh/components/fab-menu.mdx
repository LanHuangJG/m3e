<p> <code>m3e-fab-menu</code> 组件呈现一个由相关操作组成的动态菜单,从 悬浮操作按钮(FAB)优雅地展开。有关使用 悬浮操作按钮的更多信息,请参阅 <a href="/zh/components/fab/">FAB</a>。 </p>

```js
import "m3e/fab-menu";
```

## 用法

### 结构解析

<p> <code>m3e-fab-menu</code> 与 <code>m3e-fab</code> 配合使用,创建一个在 FAB 被激活时打开的菜单。 </p>
<ul> <li>使用嵌套在 <code>m3e-fab</code> 内部的 <code>m3e-fab-menu-trigger</code> 触发菜单。</li> <li> 使用 <code>m3e-fab-menu-trigger</code> 的 <code>for</code> 特性指定要打开的菜单。 </li> <li> 在 <code>m3e-fab-menu</code> 中嵌套 2-6 个 <code>m3e-fab-menu-item</code> 组件来指定菜单 项。 </li> </ul>

```html
<m3e-fab variant="primary" size="large">
  <m3e-fab-menu-trigger for="fabmenu">
    <m3e-icon name="edit"></m3e-icon>
  </m3e-fab-menu-trigger>
</m3e-fab>
<m3e-fab-menu id="fabmenu">
  <m3e-fab-menu-item>
    <m3e-icon slot="icon" name="email" filled></m3e-icon>
    Email
  </m3e-fab-menu-item>
  <m3e-fab-menu-item>
    <m3e-icon slot="icon" name="chat" filled></m3e-icon>
    Message
  </m3e-fab-menu-item>
  <m3e-fab-menu-item>
    <m3e-icon slot="icon" name="folder" filled></m3e-icon>
    Folder
  </m3e-fab-menu-item>
</m3e-fab-menu>
```

### 变体

<p> <code>m3e-fab-menu</code> 支持三种外观变体:<code>primary</code>(默认)、 <code>secondary</code> 与 <code>tertiary</code>。使用 <code>variant</code> 特性更改 外观。 </p>

```html
<m3e-fab variant="secondary" size="large">
  <m3e-fab-menu-trigger for="fabmenu">
    <m3e-icon name="edit"></m3e-icon>
  </m3e-fab-menu-trigger>
</m3e-fab>
<m3e-fab-menu id="fabmenu" variant="secondary">

</m3e-fab-menu>

```

### 图标

<p> 使用 <code>m3e-fab-menu-item</code> 的 <code>icon</code> 插槽在菜单项标签之前呈现图标。 虽然并非必需,但下面的示例使用 <code>m3e/icon</code> 中的 <code>m3e-icon</code> 组件,通过 Material Symbols 呈现图标。更多信息请参阅 <a href="/zh/components/icon/">Icon 图标</a>。 </p>

```html
<m3e-fab-menu-item>
  <m3e-icon slot="icon" name="email" filled></m3e-icon>
  Email
</m3e-fab-menu-item>
```

### 禁用

<p> 你可以使用 <code>disabled</code> 特性禁用某个 <code>m3e-fab-menu-item</code>。此外,如果 <code>m3e-fab</code> 被禁用,点击时不会打开 <code>m3e-fab-menu</code>。 </p>

```html
<m3e-fab-menu-item disabled>
  <m3e-icon slot="icon" name="email" filled></m3e-icon>
  Email
</m3e-fab-menu-item>
```

### 链接

<p> 菜单项也可以通过 <code>href</code> 特性指定 URL,从而表现得像链接。你还可以 像原生 anchor 标签那样指定 <code>target</code>、<code>rel</code> 与 <code>download</code>。 </p>

```html
<m3e-fab-menu-item href="https://www.google.com" target="_blank">
  <m3e-icon slot="icon" name="open_in_new_window" filled></m3e-icon>
  Google
</m3e-fab-menu-item>
```
