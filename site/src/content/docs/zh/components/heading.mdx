<p><code>m3e-heading</code> 组件为页面与区块提供富有表现力、无障碍的标题。</p>

```js
import "m3e/heading";
```

## 用法

### 字阶变体与尺寸

<p> <code>m3e-heading</code> 支持五种变体:<code>display</code>(默认)、<code>headline</code>、 <code>title</code> 与 <code>label</code>。它支持三种尺寸变体:<code>large</code>、 <code>medium</code>(默认)与 <code>small</code>。使用 <code>variant</code> 与 <code>size</code> 特性更改标题的字阶。 </p>

### 强调字阶

<p>使用 <code>emphasized</code> 特性控制标题的字阶是否强调。</p>
