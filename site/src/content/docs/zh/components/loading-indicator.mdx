<p> <code>m3e-loading-indicator</code> 组件用于在短暂等待时显示不确定进度。它通过 动画吸引注意、缓解感知延迟,并表明某项活动正在进行中。 </p>

```js
import "m3e/loading-indicator";
```

## 用法

### 变体

<p> 加载指示器有两种外观变体:<code>uncontained</code>(默认)与 <code>contained</code>。使用 <code>variant</code> 特性更改外观。 </p>
