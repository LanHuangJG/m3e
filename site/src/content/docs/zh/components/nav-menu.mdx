<p> <code>m3e-nav-menu</code> 组件是一个为较大设备上的侧边栏与抽屉优化的层级菜单。它使用户能够浏览嵌套菜单结构,并在应用视图之间无缝切换。 </p>

```js
import "m3e/nav-menu";
```

## 用法

### 多级菜单

<p> 使用 <code>m3e-nav-menu</code> 与 <code>m3e-nav-menu-item</code> 创建多级导航菜单。 </p>
<p> 使用 <code>m3e-nav-menu-item</code> 的 <code>label</code> 插槽指定条目的标签。此外, 使用 <code>icon</code> 插槽在条目标签前加入图标,使用 <code>badge</code> 插槽 指定紧凑的状态指示器或补充文本。 </p>
<p>要创建多级结构,请嵌套一个或多个 <code>m3e-nav-menu-item</code> 组件。</p>

<Demo name="zh/nav-menu/0" />

### 对顶层条目分组

<p> 你可以使用 <code>m3e-nav-menu-item-group</code> 对菜单中的顶层条目进行分组。使用 <code>label</code> 插槽指定分组的标签。使用 <code>m3e-divider</code> 分隔 菜单中的分组。更多信息请参阅 <a href="/zh/components/divider/">Divider 分隔线</a>。 </p>

<Demo name="zh/nav-menu/1" />

### 禁用

<p> 使用 <code>m3e-nav-menu-item</code> 的 <code>disabled</code> 特性禁用该条目及其所有 子项。禁用带有子项的条目不会自动将其收起。 </p>
