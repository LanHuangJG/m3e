<p> <code>m3e-shape</code> 组件让你能够有意识地使用抽象形状来增加强调与装饰效果,包括内建的形状变形。 </p>

```js
import "m3e/shape";
```

## 用法

### 形状

<p> <code>m3e-shape</code> 让你可以轻松使用 <a href="https://m3.material.io/styles/shape" target="_blank">Material Design 3 Shape Library</a> 中的形状, 以增加强调与装饰效果。 </p>
<p> 它支持 31 种形状,通过 <code>name</code> 特性指定: <code>4-leaf-clover</code> <code>4-sided-cookie</code>, <code>6-sided-cookie</code>, <code>7-sided-cookie</code>, <code>8-leaf-clover</code>, <code>9-sided-cookie</code>, <code>12-sided-cookie</code>, <code>arch</code>, <code>arrow</code>, <code>boom</code>, <code>bun</code>, <code>burst</code>, <code>circle</code>, <code>diamond</code>, <code>fan</code>, <code>flower</code>, <code>gem</code>, <code>ghost-ish</code>, <code>heart</code>, <code>hexagon</code>, <code>oval</code>, <code>pentagon</code>, <code>pill</code>, <code>pixel-circle</code>, <code>pixel-triangle</code>, <code>puffy</code>, <code>puffy-diamond</code>, <code>semicircle</code>, <code>slanted</code>, <code>soft-boom</code>, <code>soft-burst</code>, <code>square</code>, <code>sunny</code>, <code>triangle</code>, and <code>very-sunny</code>. </p>

<Demo name="zh/components/shape/0" />

### 图像与视频

<p>把图像或视频嵌套在 <code>m3e-shape</code> 内,即可用该形状对其进行裁剪。</p>

<Demo name="zh/components/shape/1" />

### 变形

<p> 所有形状路径都被归一化为相同的点数,从而使形状可以通过 CSS <code>clip-path</code> 过渡进行变形。 </p>
