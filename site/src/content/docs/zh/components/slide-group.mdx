<p> <code>m3e-slide-group</code> 组件提供方向性分页控件,用于浏览溢出的内容。 </p>

```js
import "m3e/slide-group";
```

## 用法

### 基础用法

<p> 要使用 <code>m3e-slide-group</code>,只需把内容嵌套在其中。当内容溢出时,会出现方向性分页按钮,让用户可以点击以滚动其内容。 </p>

<Demo name="zh/components/slide-group/0" />

### 方向

<p> 默认情况下,滚动组为水平方向。使用 <code>vertical</code> 特性可创建垂直方向的滚动组。 </p>
