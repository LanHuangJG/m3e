<p> <code>m3e-split-button</code> 组件在呈现一个主要操作的同时,附带一个相关操作菜单,把两个按钮统一在一个富有表现力的界面中。 </p>

```js
import "m3e/split-button";
```

## 用法

### 结构解析

<p> <code>m3e-split-button</code> 暴露两个操作插槽:<code>leading-button</code> 用于主要意图,<code>trailing-button</code> 用于调用次级选项菜单。前置按钮直接执行主操作,而后置按钮则通过附加菜单展示上下文相关的备选方案。 </p>
<p>下面的示例演示了用法:<code>m3e-button</code> 用于前置按钮, <code>m3e-icon-button</code> 用于后置按钮,<code>m3e-menu</code> 用于呈现次级选项菜单。 </p>

### 变体

<p> 分裂按钮有四种外观变体:<code>filled</code>(默认)、<code>tonal</code>、 <code>outlined</code> 与 <code>elevated</code>。使用 <code>variant</code> 特性更改外观。 </p>

<Demo name="zh/components/split-button/1" />

### 尺寸

### 尺寸

<p> 共有五种尺寸变体,可用于增加或减少强调: <code>extra-small</code>、<code>small</code>(默认)、<code>medium</code>、<code>large</code> 与 <code>extra-large</code>。使用 <code>size</code> 特性控制分裂按钮的大小。 </p>
