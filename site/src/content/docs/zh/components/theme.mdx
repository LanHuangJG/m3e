<p> <code>m3e-theme</code> 组件是一个非可视元素,用于向嵌套的、感知主题的元素应用动态颜色、表现力动效、 密度与强焦点指示器。 </p>

```js
import "m3e/theme";
```

## 用法

### 颜色

<p> 使用 <code>color</code> 特性指定一个 HEX 颜色,并据此派生颜色调色板。这会设置 一组反映标准 Material Design 3 调色板的 CSS 自定义属性。例如, <code>--md-sys-color-primary</code> 会被设为该主色。 </p>

<Demo name="zh/components/theme/0" />

### 配色方案

<p> 主题支持三种配色方案:<code>light</code>、<code>dark</code> 与 <code>auto</code>(默认)。 使用 <code>scheme</code> 特性指定配色方案。 </p>
<p> 使用 <code>auto</code> 时,主题会通过监听媒体 查询 <code>(prefers-color-scheme: light)</code> 与 <code>(prefers-color-scheme: dark)</code> 动态响应系统偏好, 根据用户环境选择合适的配色方案。 </p>

<Demo name="zh/components/theme/1" />

### 对比度

<p> 主题支持三种对比度级别:<code>standard</code>(默认)、<code>medium</code> 与 <code>high</code>。使用 <code>contrast</code> 特性控制主题内 色调的分离强度。 </p>

### 密度

<p> 使用 <code>density</code> 特性控制主题内各感知密度的组件的布局紧凑程度。 它会调整间距、内边距与尺寸,以获得更紧凑或更宽松的视觉节奏。 </p>
<ul> <li><strong>有效值:</strong> <code>-3</code>(最紧凑)到 <code>+1</code>(最宽松)</li> <li><strong>默认值:</strong> <code>0</code></li> <li><strong>作用范围:</strong> 全局应用于主题内的所有组件</li> </ul>
<p> 当主题以某个 <code>density</code> 值初始化时,会把系统令牌 <code>--md-sys-density-scale</code> 设为该值。感知密度的组件会使用此令牌 调整其内部布局度量。 </p>
<ul> <li>紧凑密度会减少垂直内边距与组件高度</li> <li>宽松密度会增大间距,以获得更舒缓的布局</li> <li>触摸目标仍可访问,并符合最小尺寸准则</li> </ul>
<p> 以下示例演示 <code>m3e-button</code> 如何响应主题级密度调整。图中 展示了一个中等尺寸按钮,它支持的最低密度为 <code>-2</code>。请注意,对于该尺寸,密度 <code>-3</code> 与 <code>-2</code> 产生相同的布局行为,因为低于 支持阈值的值会被钳制为 <code>-2</code>。 </p>

<Demo name="zh/components/theme/3" />

### 动效

<p> 主题支持两种动效方案:<code>standard</code>(默认)与 <code>expressive</code>。这些方案 定义组件在整个系统中的动画方式,使用基于弹簧的物理效果来引导空间与效果 过渡。使用 <code>motion</code> 特性控制动效方案。 </p>
<p> 以下示例演示 <code>m3e-switch</code> 如何适应动效方案。点击表现力 示例时,请注意其弹簧效果。 </p>

```html
<m3e-theme motion="standard">

</m3e-theme>
<m3e-theme motion="expressive">

</m3e-theme>
```
