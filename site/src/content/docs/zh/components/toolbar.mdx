<p><code>m3e-toolbar</code> 组件用于呈现上下文操作、导航与控件。</p>

```js
import "m3e/toolbar";
```

## 用法

### 变体

<p> 工具栏有两种外观变体:<code>standard</code>(默认)与 <code>vibrant</code>。使用 <code>variant</code> 特性更改外观。 </p>

<Demo name="zh/components/toolbar/0" />

### 形状

<p> 有两种形状变体:<code>square</code>(默认)与 <code>rounded</code>。使用 <code>shape</code> 特性更改外观。 </p>

<Demo name="zh/components/toolbar/1" />

### 海拔

<p> 使用 <code>elevated</code> 特性把工具栏提升为视觉上醒目的表面,使其有别于周围 布局,并传达其重要性或活动上下文。 </p>

<Demo name="zh/components/toolbar/2" />

### 方向

<p> 默认情况下,工具栏为水平方向。使用 <code>vertical</code> 特性把工具栏设为 垂直方向,使其交互元素从上到下堆叠,而非从左到右。这对于 侧边面板、紧凑布局,或垂直对齐能提升清晰度与无障碍性的场景很有用。 </p>

<Demo name="zh/components/toolbar/3" />
