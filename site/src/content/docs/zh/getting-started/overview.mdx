<p> 欢迎使用 M3E —— 一个现代、从零实现的 <a href="https://m3.material.io/" target="_blank">Material Design 3</a>,完全以 <a href="https://developer.mozilla.org/en-US/docs/Web/Web_Components" target="_blank">Web Components</a> 构建。 它提供完整、贴合规范的组件套件,具备动态颜色、表现力动效与完整的无障碍支持。 </p>

</m3e-card>
<m3e-card variant="outlined" class="callout">
<m3e-heading slot="header" variant="title" size="large">统一架构</m3e-heading>

</m3e-card>
<m3e-card variant="outlined" class="callout">
<m3e-heading slot="header" variant="title" size="large">无障碍优先</m3e-heading>

<m3e-card variant="outlined" class="callout">
<m3e-heading slot="header" variant="title" size="large">主题与个性化</m3e-heading>

<m3e-heading slot="header" variant="title" size="large">性能优化</m3e-heading>

</m3e-card>
<m3e-card variant="outlined" class="callout">
<m3e-heading slot="header" variant="title" size="large">注重安全</m3e-heading>
